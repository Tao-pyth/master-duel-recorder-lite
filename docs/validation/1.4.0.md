## 自動検証で確認した契約

- OAuth通常導線はPKCEとloopback callbackを使い、通常操作では認可コードのコピー&ペーストを要求しない
- 開発者向けfallbackとして`--client-secrets`を残す
- 資格情報はOS資格情報ストアへ保存し、DB、queue、manifest、移行パックへ含めない
- YouTube投稿の既定公開範囲は`private`
- `public`投稿時はGUIで追加確認を挟む
- API失敗は利用者向け次アクションへ分類する
- DBスキーマはV16のまま変更しない

## 外部ゲート

実YouTube private投稿E2Eは、ユーザーのGoogleアカウントと配布者管理OAuth Clientを使ったブラウザ認可が必要です。この検証が完了するまで、V1.4.0は実装済みだがリリース未完了として扱います。
