# V2.5.0 Validation

## Scope

PySide6通常GUIの主要画面について、表示操作が実処理、状態依存の無効化、明確な案内、または非表示/削除に分類されていることを確認する。

## Operational Audit

| 画面 | 確認結果 |
| --- | --- |
| 録画 | 録画対象更新/保存、環境診断保存/フォルダ表示、診断確認を実処理へ接続した。録画なし戦績追加は戦績編集ダイアログと手動戦績作成へ接続した。 |
| 戦績管理 | 再生/編集/削除/YouTubeは選択状態に応じた有効化を維持した。戦績編集入口は既存ダイアログへ接続済み。 |
| 統計 | 既存の条件、タブ、統計表示を維持し、内部キー表示の追加なし。 |
| デッキ名 | 追加/保存/削除を既存カタログ操作へ接続済み。カラーは文字だけに依存しないスウォッチ表示を維持。 |
| タグ | デッキ名と同じカタログ操作契約を維持。 |
| シーズン | 追加/保存/アーカイブ/レポートを既存シーズン操作へ接続済み。 |
| テンプレート | YouTube投稿テンプレート保存へ接続済み。MP4準備やバックグラウンド状況の露出なし。 |
| 設定 | FFmpeg、音声、録画診断、YouTube、管理データ、CSV、アプリ更新の主要操作を既存サービスへ接続済み。 |
| 設定 | クリーンアンインストールを操作状態確認、削除対象確認、確認語入力付きの実処理へ接続した。 |
| レビュー | タイムラインの種別/状態/由来を日本語表示へ変更し、内部値はQt data roleへ保持した。外部再生とクリップ出力の失敗表示を利用者向けに整理した。 |
| 内部ページ | MP4準備は通常機能として提供しない旨を案内し、内部改善ページの更新/手動追加は実処理または案内へ接続した。 |
