- Master Duel PIDを対象に600.000秒のPCMを取得し、48kHz、stereo、s16le、115,200,078 bytesを確認
- 同時再生したWindows Media Playerの1kHz音源は、元音源の1kHz比34,948,122.7に対して取得音声の中央値0.9367、最大1.5376であり、他アプリ音声の混入を確認しなかった
- 仮想デスクトップ4897x4080は右端を1px補完した4898x4080として保存でき、libx264の奇数幅エラーを解消した
- Process Loopbackは無音期間を48kHzの無音PCMで補完し、FFmpeg接続、録画開始、停止要求、パイプ終了を連続した時刻基準で処理した
- Master Duelウィンドウ、1280x720、30fps、libx264 ultrafast、Process Loopbackの10秒製品録画は、映像10.833秒、音声10.410秒、末尾差0.423秒で完了した
- 同条件の30分製品録画は1,406,025,152 bytes、映像1800.866秒、音声1800.429秒、末尾差0.437秒で完了した。10秒との差は0.014秒で、累積ドリフトを確認しなかった
- 自動監視の映像判定はV0.25.0の保存済み12録画全編再生、音声経路は事前待機・同一Helper引継ぎテストで代替し、追加の実戦ログ取得は要求しなかった
