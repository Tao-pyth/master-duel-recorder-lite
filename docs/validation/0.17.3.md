## 修正理由

V0.17.2の初期3戦は自動開始3/3、盤面確定3/3、結果停止2/3でしたが、保存動画3/3が先頭から末尾まで同一のコイントス画面で静止していました。判定用`gdigrab desktop`は進行画面を取得できていた一方、録画本体の`gdigrab title=Master Duel`が3440x1440フルスクリーン画面を更新できていませんでした。

- 判定ストリームを1280x536から640x268へ軽量化
- `title=`入力への退行を防ぐ回帰テストを追加
- 座標録画では重なった別ウィンドウも映る制約をGUI診断と文書へ明記
- 自動監視の録画待機、候補録画、本録画を文言と色で区別する状態表示帯を追加
- 共通ヘッダーへ戦績管理未完了件数を追加し、全履歴を対象とするSQLite集計と録画履歴への導線を実装
