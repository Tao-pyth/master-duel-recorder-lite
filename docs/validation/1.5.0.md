## 保存契約

- `review show`は録画履歴、録画ファイル、タイムライン、戦績、YouTube投稿履歴を読み取り、ViewModelを生成する
- 現在位置マーカー追加は`RecorderApplicationService.add_review_marker`から`DuelTimelineRepository`へ委譲する
- クリップ出力は`RecorderApplicationService.export_review_clip`から`ClipExportService`へ委譲し、元録画のサイズと更新時刻を検証する
- PySide6レビューは別プロセスで起動し、起動失敗時は既存外部プレイヤーへfallbackできる
- OAuth資格情報相当値はViewModel、DB、設定、queue、manifest、ログへ保存しない
