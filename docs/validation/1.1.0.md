## 確認した契約

- YouTube OAuth資格情報はWindows資格情報ストアに保存し、設定、manifest、queue、標準出力、ログへ保存しない
- `upload.privacy_status`の既定は`private`を維持し、明示した場合だけ`unlisted`または`public`を使用する
- `youtube_uploads`は録画ID、投稿状態、試行回数、失敗理由、動画ID、視聴URLを保持する
- 同一録画の完了済み投稿は既定で重複作成しない
- 既存のcompleted prepare結果を再利用し、ない場合だけMP4準備を実行する
- クリップ出力は元録画を上書きせず、`user_data/data/exports/`配下へ保存する
- 投稿素材生成はOAuth未接続でも動作する
