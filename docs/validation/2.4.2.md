## Acceptance Criteria

- [x] `settings_visual_language` が `auto`、`ja`、`en` の非編集プルダウンとして表示され、保存時に不正値を手入力できない。
- [x] 設定タブ名が `録画設定①` / `録画設定②` を含み、診断操作は設定内から実行できる。
- [x] カラー列は白や淡色でも判別できる枠線付きスウォッチで表示される。
- [x] 録画画面の開催中シーズンは状態と名称が分かれて読める。
- [x] 主要操作ボタンにQt標準アイコンが付く。
- [x] テンプレート概要欄が画面下部の余白を利用する。
- [x] 戦績管理で選択した戦績を編集保存でき、一覧が更新される。
- [x] レビュー画面で選択した `marker` のラベルを編集保存でき、タイムラインが更新される。
