全unittestの後に行ったGUI煙試験の変更は、上表の重点15件で追加確認しています。ローカルビルドと、公開されたファイルの再取得確認は別の検証です。

通常起動試験の初回は、起動時に追加される共通カードの初期登録をfixtureが含めていなかったため全表比較で失敗しました。fixture作成時に製品の初期登録APIを使用し、既存の全カード行を厳密に比較する条件を維持して再試験に合格しています。

skip2は実シンボリックリンクを作れない環境条件です。元動画の実ファイルsymlink試験はWindowsの作成権限不足（WinError1314）、アンインストールのdirectory symlink試験も作成不能のためskipしました。実junction・hardlinkによる元動画保持試験は合格しています。symlinkの実物確認を完了したという意味ではありません。

同梱OCRの確認はゲーム素材を使わず、生成した日本語表示をCLI・GUI双方の同梱モデルで認識しています。モデル利用可、生成文字列の認識、試験用実行時データの保持を確認しました。これは日本語モデルの同梱・実行の回帰確認であり、実対戦の使用イベント認識精度を示す結果ではありません。

## Windows Qtの倍率・小画面

Windows11上のPySide6/Qt6.10.3を使用し、独立processごとに`QT_SCALE_FACTOR=1/1.5/2`を設定しました。`QT_QPA_PLATFORM=offscreen`による実Qt描画であり、実モニターのOS倍率を操作した試験ではありません。主画面は980×640、動画なしカード画面は400×480 logicalです。

人工ファイル・一時SQLite・録画なし手入力戦績と空のprocess内資格情報ストアを使用しました。現worktreeのsourceを明示し、2つのversionが3.1.0であることと、3倍率の主要source SHA一致を確認しています。実OAuth・YouTube送信・実ゲーム素材・実録画・OCRはこの撮影へ含めていません。

通常GUI起動の保存チェック完了を待ち、保存GiB/日数、投稿後削除checkbox、保護の切替、削除理由・別削除メニュー、動画なしカード使用・初動保存と統計反映を操作しました。scrollで主要操作へ到達でき、保存欄と注意書きを確認しました。ナビ左下の完了文言の文字欠けを修正後、全3倍率で解消を目視確認しています。

個別結果・PNGのサイズ/SHA・環境・撮影scriptは、Actの証拠集合`retention-act-20261015`に保存します。公開仕様には個人の保存先や実運用データの詳細を含めません。
