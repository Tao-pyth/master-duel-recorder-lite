## 1.x標準機能一覧

V2.0.1でPySide6全面移植の同等性ゲートとして固定した標準機能は次の15項目です。

- `recording_control`: 録画対象選択、録画開始・停止、自動監視、環境診断
- `manual_duel_entry`: 録画なし戦績の手動追加と簡易入力
- `history_management`: 戦績管理一覧、未完了処理、一括編集、再生、編集、削除、重複比較、更新
- `history_filter_columns`: 戦績管理のフィルター、表示列、YouTube投稿導線
- `statistics`: 全体・条件付き・先後・デッキ・コイントス・シーズン統計
- `deck_catalog`: デッキ名、説明、カラー、用途、使用回数、デッキタグ管理
- `tag_catalog`: タグ名、説明、カラー、デッキ専用タグ管理
- `season_management`: シーズン追加・更新・削除/アーカイブ、期間、レポート
- `youtube_template`: YouTube投稿テンプレートと投稿状態管理
- `prepare_queue`: MP4準備、投稿前処理キュー、準備対象選択
- `reliability`: 事前チェック、導入状態、ホットキー、トレイ、後解析導線
- `settings_recording_audio`: FFmpeg、音声、録画品質、自動判定、通知、保存先設定
- `data_protection`: 管理データ、バックアップ、復元、整合性診断、クリーンアンインストール
- `csv_and_update`: 戦績CSV入出力、アプリ更新確認、更新適用
- `dialogs`: 日付選択、FFmpeg導入、投稿、フィルター、タイムライン、戦績入力、診断、レポート

## 保存契約

- V2.0.1ではDB schema、設定形式、録画ファイル、queue、manifest、OAuth資格情報を変更しない
- 通常配布GUIは1.x相当のTkinter操作面へ戻す
- PySide6はレビュー/検証入口として残し、機能同等性ゲートを満たすまで通常入口にしない
- 本番`user_data`は検証に使用しない
