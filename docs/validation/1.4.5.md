## 外部ゲート

実YouTube private投稿E2Eは、配布EXE公開後にユーザーのGoogleアカウント、YouTubeチャンネル、OAuth同意画面の公開またはテストユーザー登録、YouTube Data API quotaが揃った状態で確認します。V1.4.5ではユーザー操作を増やさず、Windows資格情報ストアの読み取り・保存・削除経路だけを修正します。`refresh_token`、`access_token`、認可コードは配布物、設定、DB、queue、manifest、ログへ含めません。
