# V0.22.0からV0.25.0 実装計画

## 目的

V0.21.2までに録画あり・なしの戦績管理と更新排他が整いました。次の開発では機能数を増やすだけでなく、日常入力、自動録画の信頼性、長期データ保全、シーズン振り返りの順に常用品質を高めます。

## 共通原則

- 各バージョンの親Issueを閉じる前に、対応する全子Issueと完了条件を確認する
- 設計契約、Repository・サービス、GUI、異常系、検証・文書の順に進める
- 実装前にDB移行、失敗時動作、ユーザーデータ保護を確定する
- GUIだけでなくサービス層でも入力検証、排他、権限制御を強制する
- 既存の録画、戦績、シーズン、統計、管理データJSONとの互換性をテストする
- 各バージョンでRuff、全単体テスト、GUI描画、CLI/GUI EXE、両スモーク、Windows CIを実行する
- V1.0.0にはユーザーの明示指示があるまで変更しない

## V0.22.0 戦績入力体験

親Issue: #276

1. #277で簡易入力の必須項目、保存状態、詳細入力への遷移を決める
2. #278と#279で前回値、開催中シーズン、デッキ・タグ頻度の候補サービスを作る
3. #280と#281で録画終了後と初期画面からの簡易入力を実装する
4. #282と#283で未完了戦績の検索と連続処理を実装する
5. #284と#285でトランザクション付き一括更新とGUIを実装する
6. #286と#287で保存済みフィルターの永続化とGUIを実装する
7. #288でE2E、アクセシビリティ、文書、配布物を検証する

重要な設計判断:

- 候補値は提案に留め、利用者の確認なしに確定しない
- 簡易入力の既定状態は確定済みとするが、必須値不足ではdraftとして後回しできる
- 一括編集は全件成功または全件ロールバックとし、各`duel_id`へ監査履歴を残す
- 保存済みフィルターは名称と安定IDを持ち、削除済み候補を参照しても起動を妨げない

## V0.23.0 自動監視信頼性

親Issue: #289

1. #290で状態、イベント、タイムアウト、操作許可表を確定する
2. #291と#292で状態管理とGUI制御を単一状態機械へ統合する
3. #293と#294でイベント別検出器と共通解析パイプラインを整備する
4. #295でイベント別の適合率、再現率、遅延評価を実装する
5. #296と#297で診断レポートと表示階層を改善する
6. #298でWindows通知を追加する
7. #299と#300で異常系と実戦E2E基準を更新する
8. #301で実戦証拠、文書、配布物を検証する
9. #330で数値診断から初期3戦・調整後10戦の連続成功を機械集計する

重要な設計判断:

- GUIとサービスの操作可否は同じ状態機械から決定する
- オフラインとライブの差はフレーム取得アダプターだけに限定する
- 診断には画像、BMP、ウィンドウタイトル、絶対動画パスを保存しない
- 合格判定はイベント別指標と実戦連続試験を併用し、全体閾値の単純低下で済ませない

## V0.24.0 データ保全

親Issue: #302

1. #303で保護対象、除外対象、形式、保持上限、作成契機を決める
2. #304から#306で原子的バックアップ、自動作成、世代管理を実装する
3. #307と#308で復元前プレビューとロールバック可能な復元を実装する
4. #309と#310で統合診断と録画ファイル再関連付けを実装する
5. #311と#312で重複候補の検出と利用者による解決を実装する
6. #313で設定画面へデータ保全ダッシュボードを追加する
7. #314で障害注入、文書、配布物を検証する

重要な設計判断:

- 録画ファイルはバックアップ対象外とし、DB・設定等の管理データを保護する
- バックアップ作成に失敗した場合、移行・取込・初期化・復元を開始しない
- 復元候補は別接続・別パスで検証し、現DBを退避してから切り替える
- 診断と重複検出は候補提示までとし、自動修復・自動統合を行わない

## V0.25.0 シーズンレポート

親Issue: #315

1. #316で母集団、比較対象、分母、少数標本表示を確定する
2. #317から#320でシーズン比較、デッキ・先後、コイントス、推移集計を実装する
3. #321で終了・アーカイブ時のレポート確認フローを実装する
4. #322と#323で比較中心の画面と振り返りメモを実装する
5. #324と#325で単一HTML出力と安全な保存GUIを実装する
6. #326と#327で集計一致、描画、出力、E2E、文書、配布物を検証する

重要な設計判断:

- 統計ページとシーズンレポートは同じ集計Repositoryと除外規則を利用する
- 少数標本は数値を隠さず、件数と注意表示を併記する
- 統計値はライブ集計を正とし、古いスナップショットを永続化しない
- HTMLは単独閲覧可能とし、外部CDN、ゲーム画像、秘密情報、絶対パスを含めない

## バージョン間依存

- V0.22.0はV0.21.2の統合戦績管理と更新排他を前提とする
- V0.23.0はV0.22.0の入力処理中も状態機械の操作許可に従うよう統合する
- V0.24.0はV0.22.0で増える保存済みフィルター等もバックアップ対象へ含める
- V0.25.0はV0.22.0の入力品質とV0.24.0のバックアップを前提に、レポートメモ・出力を保護する
