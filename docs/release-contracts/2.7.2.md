# V2.7.2 Release Contract

## Release Goal

V2.7.1公開後に報告された録画画面の致命的な操作不整合を修正し、手動録画開始、停止、自動監視開始・停止を画面状態と一致して操作できる状態へ戻す。

## Scope

- 録画画面をサービスの録画状態と操作状態へ定期同期する。
- 手動録画中は録画開始を無効化し、停止を有効化する。
- 自動監視中は自動監視開始ボタンを自動監視停止へ切り替える。
- 停止ボタンは、手動録画中は手動録画停止、自動監視中は自動監視停止へ振り分ける。
- 録画状態詳細の内部英語値を日本語表示へ置き換える。
- バージョン情報とリリースノートをV2.7.2へ更新する。

## Non-Scope

- 録画方式、FFmpegコマンド、録画保存先生成の変更。
- DB schema変更、DB migration。
- 設定ファイルschema変更。
- 自動判定、プリロール、レビュー、統計、戦績管理の機能追加。
- OBS Plugin、OBS WebSocket、OAuth、直接アップロード。
- `user_data/`、録画ファイル、SQLite DB、queue、manifest、OAuth資格情報、ログの削除、初期化、上書き。

## Acceptance Gate

- 録画画面は手動録画開始後に「手動録画中」を表示し、録画ID、保存先、経過時間を更新する。
- 手動録画中は録画開始ボタンが無効、停止ボタンが有効、自動監視開始ボタンが無効になる。
- 停止操作後は停止中表示へ戻り、録画開始と自動監視開始が再度有効になる。
- 自動監視中は自動監視ボタンが「自動監視停止」になり、停止ボタンでも自動監視停止へ到達できる。
- 録画状態詳細に `recording` などの内部英語値を表示しない。
- SQLite schema、設定schema、録画ファイル、queue、manifest、OAuth資格情報を変更しない。
- Ruff、対象pytest、PySide6録画画面smokeに合格する。
