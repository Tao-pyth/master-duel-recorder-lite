## Release Goal

現行機能をPySide6 UIで管理・表示できる状態へ移植する。通常入口切替は、15標準機能、DB入りruntime、配布GUI smoke、CLI/GUI/updater EXEスモークが通った後の最終判定にする。

## Acceptance Criteria

- PySide6 smoke contractに要求widget 51個がすべて含まれる。
- `failed_standard_operation_checks` が空になる。
- DB入りruntimeで既存戦績、録画履歴、デッキ、タグ、シーズン、統計、YouTube投稿状態、設定、データ保全を表示できる。
- 統計の推移単位はPySide6統計画面の「勝利数・勝率推移」内条件として表示し、既定値を日単位にする。
- DB schema、設定形式、録画、queue、manifest、OAuth資格情報を変更しない。
- 通常入口切替を行う場合は、配布GUI smokeと3 EXE smokeが成功している。

## Test Requirements

- `python -m master_duel_recorder_lite.pyside_gui --smoke-test`

- 3 EXE smoke

- 設定形式変更
- 録画ファイル、queue、manifest、OAuth資格情報の削除、初期化、形式変更
- OBS Plugin / OBS WebSocket依存追加
- 外部YouTube private投稿E2Eの新規必須化
- Tkinter互換モジュールの削除
