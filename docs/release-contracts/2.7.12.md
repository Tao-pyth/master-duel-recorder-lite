# V2.7.12 Release Contract

## Release Goal
採用済み3案目の「上部絞り込み→全幅一覧→下部編集」を通常GUIへ実装し、未完了戦績を安全に連続確認できるようにする。

## Target Version
target_version: v2.7.12。既存戦績管理のUI改革であり新しい中核録画機能ではないためFix更新。baseline v2.7.11。

## Scope
1. 操作を全体/絞り込み/選択に分離。上部更新・手動追加・その他、期間/デッキ/詳細条件/未完了のみ、全幅一覧、下部編集。
2. 単一選択で下部の共通項目と展開詳細を編集。録画付き・録画なし・未作成の全種を既存サービスで保存。状態/引分/コインを含む全値を保持。
3. 未完了の再クリック解除、他条件保持、未保存保護、次の未完了、複数選択/一括編集、0件状態。
4. 再生/レビュー・削除・YouTube・重複・列説明/列表示・全既存フィルターを適切なメニューへ接続。

## Non-Scope
全アプリのナビ刷新、録画方式、DB/設定形式/移行、API/CLI、アップロード機能拡張、集計、clip、実ユーザーデータ編集。未完了の意味変更と保存時の無条件confirmed化はしない。

## Chosen Approach
通常GUIに専用下部編集widgetモジュールを追加。snapshotでdirty判定、既存DuelRecordValuesとexpected_revisionで保存。表の識別子と選択/スクロールを維持。未保存状態は保存/破棄/取消で遷移を制御。全体refreshの背景通知はdirty入力を上書きしない。一般項目は常設、詳細フィルター/編集項目を折畳む。単一選択の操作と一括編集を切り替える。基本表示列は日時・デッキ・勝敗・先後・コイン・種別・状態とし他列も表示メニューから到達可能。

## Acceptance Criteria
- [ ] AC1: 3案目と同じ上下関係と横幅重視。未選択時編集欄なし、単一選択時は下部、複数選択時は件数と一括編集。980x640/1180x760/1440x1024および150/200%相当で操作が重ならず到達できる。
- [ ] AC2: 未完了のみは固定ラベルでON/OFFし、期間/デッキ/保存済み条件/詳細条件を保持。0件表示と全条件解除が明確。未完了は既存status定義を維持。
- [ ] AC3: 手動/録画付き/未作成の戦績を下部で保存できる。自分デッキ自由入力、勝敗(引分含む)、先後、コイン、確認状態、相手デッキ、種別、シーズン、タグ、メモがラウンドトリップする。
- [ ] AC4: 未保存で別行/複数選択/条件変更/更新/他画面/次へ/終了する際に保存/破棄/取消。取消は元選択・条件・入力を保持。保存失敗/競合/書込禁止では入力を失わず成功としない。
- [ ] AC5: 保存成功後の一覧/件数/選択/スクロールが整合。次の未完了は現在の条件で巡回し、最後/0件を案内。背景の一覧更新とレビューからの保存通知でdirty入力を消さない。
- [ ] AC6: 一括編集、録画再生/レビュー、削除確認、YouTube、重複、列説明、非表示列、全詳細フィルターに到達できる。複数選択を単一対象操作へ誤接続しない。
- [ ] AC7: Ruff、ResourceWarningをエラー化した全unittest、隔離DB実widget回帰、通常Windows日本語GUI画像確認。3EXE build/smoke、公開7asset/hash/再取得3EXEsmoke、Issue/Milestone closureを確認。

## Rejected Alternatives
1案目/2案目、上部ボタン並替のみ、全機能削減、未完了の定義変更、UIにDB処理を直接追加する方式。

## Risks
小画面の高さは表と編集欄のsplitter/scrollで調整し、保存を到達可能にする。編集中の行識別子を固定、revision競合を維持。データのテストは一時領域でのみ実行。

## Deferred Solution Queue Intake
全既存残件Keep。3案目の全ナビ再編は戦績管理と独立のため実施せず。新規Queue追記なし。
