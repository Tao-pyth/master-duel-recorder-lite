# V2.7.21 Release Contract

## Decision
2026-10-11ユーザーが推奨3点の実装とGitHub反映・正式Release公開を明示。Issue登録・commit/push/tag/配布公開と検証まで許可範囲。Orientの採用対象を次へ限定し、候補全体へ広げない。

## Release Goal
数値・日付を読み取りやすくし、一覧へ表示面積を返し、自分デッキと相手名から相性を探せる。

## Target Version
baseline v2.7.20、target_version v2.7.21。既存統計中核機能の改善でFix更新。正式Release、main、ローカル版、tagは9ff6b6aの2.7.20で一致。

## Scope
1. 統計表の数値右揃え、適正列幅、数値としての並び替え、勝率補助バー、母数を近くに保持。10戦未満の参考表示は既存シーズンレポートの閾値へ合わせる。
2. Chart日付ラベルを文字幅で配置、両端を完全表示し中間は重なりを避ける。日週月の既存計算維持。
3. 上部サマリー/期間・種別欄を圧縮。条件後を主、全体は全期間/全種別の比較値。既存条件と自動更新を保つ。
4. 相性一覧だけの自分デッキ選択、相手名部分検索、相手未設定の表示切替、最低対戦数、解除。表示件数/母集団/未設定件数を明示。既存Dashboardから読み取り、DB/schema変更なし。表示名と真の未設定を区別するフラグを集計モデルへ後方互換な末尾既定値として追加。

## Non-Scope
期間プリセット/シーズンの共通条件追加、8タブ統合、先後1行化、マトリクス、ドリルダウン、コイン等の新グラフ、録画/投稿機能変更。実行時DB/設定/queue/ログ/秘密情報/録画を変更しない。

## Chosen Approach
Qt既存widgetを限定変更。表ソート中の更新は一時停止し行混在を防ぐ。初期順は既存順、選択ソートは更新後に復元。Chartは描画のみ。相性局所条件は上部カード・他タブに作用せず、文字正規化を含む名称検索で選ぶ。未設定は削除せず初期は表示して切替可。入力条件はセッション内だけ、保存形式変更なし。主表示の24pxと通常文字を維持し、比較値の強弱（18px）と余白/行構成を調整する。

## Acceptance Criteria
- AC1: 統計全表で件数/勝率が右揃え。2と10、9.1%と100%を数値順で比較でき、更新/絞込後も同一行の名称/勝敗が混ざらない。初期のシーズン開催順・推移順を保持。
- AC2: 勝率バーは数値を遮らず、対戦数と10戦未満の参考表示を確認できる。0戦の率は「-」で0%と区別。
- AC3: 多数日（90日）、少数/1点、週/月で日付矩形が文字幅以上、外枠内、重なりなし。棒と累積率の値を変更しない。
- AC4: 1180x760と980x640の実widgetで上部高さを従来より圧縮し相性表高さが増える。タイトル/全体比較/条件後/先後/条件操作が見切れず、ページ横スクロール不要。長名はtooltip/表横スクロールで確認可能。
- AC5: 期間/種別の共通条件は既存全タブへ作用、全体カードは全件。空欄と実名「未設定」を区別し、折畳は空欄だけに作用。相性局所条件はカード・他表を変えず、表示合計と共通母集団を別表示。自分/検索/未設定/最低件数の組合せ・0件・解除・共通条件変更で正しい行/件数。
- AC6: 重点GUI/統計テスト、Ruff、ResourceWarningエラー扱いの全unittest、日本語画面確認、3EXE build/smoke合格。版/文書が一致し、実運用データ保護を検証。
- RC1: 対象だけcommitしmainへ通常fast-forward push。main CI成功後同一commitにv2.7.21タグ。英語commit本文に初心者向け日本語説明。
- RC2: Windows Release CIがテスト/build/3EXE smoke/公開asset検証/再取得smokeまで成功。latest v2.7.21、draft/prerelease=false、公開7assetのSHA/bytesと集約SHA一致。
- RC3: 対象Issues/Milestoneを検証証拠付きでclose、Obsidian Act/次baseline入口を記録。独立#629とユーザーAGENTS編集を維持。

## Rejected Alternatives
全面置換、色のみの強弱、少数勝率の確実性断定、未設定削除、カード母集団への局所条件混入、文字列ソート、保存形式変更を採らない。

## Risks
sort中の行混在、検索と母集団の誤認、小画面での見切れ、日付重なり、未知率と0%の混同を重点テストする。少数閾値は統計的信頼性保証ではない。

## Deferred Solution Queue Intake
既存の競合差別化/シーズンレポート残部はKeep。本依頼と重複なし。マトリクス/先後横比較等は今回非対象でOrient候補を保持し、今回別queue追加しない。#629は独立。

## Implementation Handoff
- W1 数値・日付表示: AC1-3。chart/table helperと専用GUIテスト。
- W2 上部圧縮: AC4-5。statistics page/refreshと回帰テスト。
- W3 相性絞込: AC5。page/refreshの局所表示、検索/0件/解除/共通条件組合せの実GUIテスト。
- W4 公開・文書・保護: AC6/RC1-3。W1-3後に統合検証、既存main直公開運用、版/設計/操作/変更履歴/検証文書、3EXE/正式Release、closure。
