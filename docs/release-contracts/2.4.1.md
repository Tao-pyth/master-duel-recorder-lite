# V2.4.1 Release Contract

## Release Goal

PySide6通常GUIで、日常操作に不要な内部処理表示を減らし、設定・録画・戦績管理の導線と文言を利用者向けに整理し、1.x相当の戦績フィルターを実操作として担保する。

## Scope

- テンプレート画面からMP4準備一覧、準備一覧更新、選択録画をMP4準備へ追加、バックグラウンド処理表示を外す。
- YouTube投稿導線では、投稿時に必要なMP4準備が内部で行われることを短く説明する。
- 左ナビから信頼性ページを外し、設定内の「録画診断・信頼性」相当タブへ統合する。
- 録画画面から診断・信頼性確認へ到達できる導線を残す。
- 設定の「表示」タブを「戦績表示設定」へ変更する。
- 戦績表示設定の対象名を内部キーではなく日本語で表示する。
- デッキ名、タグ、戦績表示設定のカラー表示をスウォッチ基準へ揃える。
- デッキ/タグのカラー選択ボタンを、選択中の色と操作意味が分かる表示へ整える。
- 録画画面の開催中シーズン表示と左下ステータスを、短い状態名と補足説明へ整理する。
- 戦績管理フィルターで、期間、シーズン、デッキ、タグ、コイン、登録元を実クエリへ接続する。
- 保存済み条件と複数タグについて、V1.x同等の復旧または代替方針を明記して検証する。
- 表を持つ主要ページで、行選択や更新により表が不自然に拡大しない共通レイアウト契約を追加する。
- PySide6 smoke contractと回帰テストを更新する。
- README、設計文書、Release Notes、Validation、Version MetadataをV2.4.1へ更新する。

## Non Scope

- SQLite schema migration
- 設定形式 migration
- 録画ファイル、queue、manifest、OAuth資格情報の削除、上書き、初期化
- MP4準備処理、YouTube投稿サービス、upload queueの内部仕様変更
- 全ページ共通ヘルプセンター、オンボーディング、チュートリアルの新設
- 主要ナビ全体の再設計
- 高度な動画レビュー、波形、サムネイル、クリップ範囲エディタ
- 競合録画ツールとの差別化機能
- OBS Plugin / OBS WebSocket依存追加

## Acceptance Criteria

- テンプレート画面にMP4準備機能が利用者向け機能として露出しない。
- YouTube投稿導線で、MP4準備が投稿時の内部処理であることが分かる。
- 左ナビから「信頼性」が外れ、設定内に録画診断・信頼性の入口がある。
- 録画画面から診断・信頼性確認へ到達できる。
- 設定タブ名が「戦績表示設定」になっている。
- 戦績表示設定の対象名が日本語で表示され、内部キーが利用者向けセル値として露出しない。
- デッキ名、タグ、戦績表示設定のカラー表示はスウォッチで確認でき、色コードや「色」文字を主要表示にしない。
- カラー選択ボタンは、選択中の色と操作意味が分かる。
- 録画画面の開催中シーズン表示は、未確認、なし、開催中、取得失敗を区別する。
- 左下ステータスは正常時に「準備OK」相当の表記を出し、注意/要確認時は根拠を確認できる。
- 戦績管理フィルターで、期間、シーズン、デッキ、タグ、コイン、登録元が一覧結果へ反映される。
- 保存済み条件と複数タグについて、復旧結果または代替方針がテストと文書で確認できる。
- 表を持つ主要ページで、行選択や更新後に表が不自然に拡大しない。
- SQLite schema、設定形式、録画ファイル、queue、manifest、OAuth資格情報を変更しない。
- `pyproject.toml`、`master_duel_recorder_lite.__version__`、docsが`2.4.1`で一致する。

## Required Validation

- `python -m ruff check .`
- `python -m pytest`
- PySide6 GUI smoke for record, history, decks, tags, template, settings
- PySide6 smoke screenshot review for table height, status text, color swatches, settings tabs
- `python scripts/verify_release_tag.py v2.4.1`
- Windows EXE build
- CLI/GUI/updater EXE smoke
- GitHub Actions CI
- GitHub Release `v2.4.1`
- 公開asset検証とダウンロード後スモーク
