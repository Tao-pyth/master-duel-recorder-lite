# V2.7.11 Release Contract


## Inputs
- [Issue #641](https://github.com/Tao-pyth/master-duel-recorder-lite/issues/641) と既存シーズンレポート仕様。

## Release Goal / Target Version
target_version: v2.7.11。現行PySide6のシーズン「レポート」から既存詳細集計の閲覧とHTML保存を行えるようにする。既存提供機能への接続改善のためFix更新。

## Scope / Implementation Handoff
1 Issue: レポートdialogを閲覧専用で実装し、概要/比較/保存済みメモ、デッキ先後/コイン先後、日/週推移を表示。現行サービスのSeasonReportを利用する。HTML保存は保存先を明示し、既存ファイルは確認後のみ上書き。保存直前に同一シーズンを再集計し、表示も同じ内容へ更新。保存後に出力先パスを案内。

## Non-Scope
集計式、DB/設定形式、録画方式、比較シーズン選択、メモ編集、別画面からの入口、clip/投稿素材/外部投稿、利用者既存データの変更。

## Chosen Approach
専用PySide6 dialogモジュールへ表示/保存操作を分離。基本画面は既存ボタンから呼び出す。QTextEditのplain textと読み取り専用QTableWidgetを利用。保存先はQFileDialogで選択し、上書きは明示QMessageBox確認。既存get_season_report/export_season_reportを再利用。

## Acceptance Criteria / Test Requirements
- [ ] 未選択/取得失敗で具体的案内。選択IDを固定し別シーズンを混ぜない。
- [ ] 2戦1勝、0戦、少数標本、比較あり/なし、日/週推移、内訳、保存済み日本語メモが既存サービスに一致。
- [ ] 閲覧専用でDB/メモを変更しない。980px級画面で閉じる/HTML保存へ到達。
- [ ] 保存直前に再集計。新規出力、取消、既存出力の拒否/許可、無効拡張子、取得/出力失敗を正しく扱う。失敗で成功表示しない。
- [ ] Ruff/全unittest、通常GUIとHTML、3EXE build/smoke、公開7asset hash/再取得3EXEsmoke、Issue/Milestone closureまで完了。

## Rejected Alternatives / Risks
HTMLをQtへそのまま埋め込む方式はSVG/CSS描画差を避けるため不採用。新しい集計や保存形式を作らず、既存生成時点の集計契約を守る。出力ファイルはユーザーの指定先で既存内容の確認なし上書きをしない。

## Deferred Solution Queue Intake
既存監査・タイムラインの過去完了は保持。#620の閲覧/出力はPromote、比較/編集/他画面導線と他候補はKeep。#629の不足は独立修正を止めない。
