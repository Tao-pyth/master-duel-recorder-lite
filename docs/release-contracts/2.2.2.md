# V2.2.2 Release Contract

## Release Goal

V2.2.1で不足していたPySide6設定画面をV1.x時期の構成に近い密度へ戻し、アプリ更新タブを状態表示と実行可能条件つきの操作へ復旧する。

## Baseline And Target

- baseline_version: V2.2.1
- target_version: V2.2.2
- Issue: [#570](https://github.com/Tao-pyth/master-duel-recorder-lite/issues/570)
- Milestone: [V2.2.2](https://github.com/Tao-pyth/master-duel-recorder-lite/milestone/78)

## Contract Matrix

| Area | Status | Requirement |
| --- | --- | --- |
| Implementation | required | PySide6設定画面へV1.x相当の設定カテゴリ、操作入口、更新タブ状態制御を復旧する |
| Tests | required | GUI契約、app update、version、Ruff、全テスト、EXE smoke、公開Release asset検証 |
| Database | not-required | SQLite schemaは変更しない |
| Database Migration | not-required | DB移行は行わない |
| Configuration | not-required | 設定形式は変更しない |
| Configuration Migration | not-required | 設定移行は行わない |
| API | not-required | 外部API仕様は変更しない |
| CLI | not-required | CLIコマンド仕様は変更しない |
| UI | required | 設定タブとアプリ更新タブの表示密度、状態表示、操作可否を復旧する |
| README | required | 現在状態にV2.2.2 Hotfixを反映する |
| Architecture Docs | not-required | 既存V1.x baseline文書を参照する |
| User Docs | required | Release notesへユーザー向け変更を記録する |
| CHANGELOG | required | `docs/release-notes.md` へV2.2.2を追加する |
| Version Metadata | required | `pyproject.toml` と `master_duel_recorder_lite.__version__` を2.2.2へ揃える |
| CI | required | GitHub CIを通す |
| Packaging | required | CLI/GUI/updater EXEと各SHA-256をReleaseへ添付する |
| Release Notes | required | `docs/releases/2.2.2.md` と validationを作成する |
| Backward Compatibility | required | 既存user_data、SQLite、録画、queue、manifest、OAuth資格情報を保持する |

## Acceptance Criteria

- 設定画面で録画設定、YouTube連携、管理データ、CSV入出力、表示、アプリ更新の入口が確認できる。
- 設定読み書きは既存の設定管理テーブルに従い、検出設定と録画設定のキーを取り違えない。
- アプリ更新タブは現在バージョン、確認中、最新、更新候補あり、確認失敗を区別する。
- ダウンロードして更新ボタンは、更新候補がある場合だけ有効化される。
- スクリーンショットまたはUI確認結果を `docs/validation/2.2.2.md` に残す。
- V2.2.2通常ReleaseにCLI/GUI/updater EXE、各SHA-256、SHA256SUMSが揃う。
- `python scripts/verify_release_assets.py v2.2.2` が成功する。

## Test Requirements

- `python -m ruff check .`
- `python -m pytest`
- `python -m master_duel_recorder_lite.pyside_gui --smoke-test --smoke-page settings --smoke-output build/v2.2.2-settings-smoke.json --smoke-screenshot build/v2.2.2-settings-smoke.png`
- `python scripts/build_windows_exe.py`
- `powershell -ExecutionPolicy Bypass -File scripts/smoke_windows_exe.ps1 -ExePath dist/master-duel-recorder-lite.exe -ExpectedVersion 2.2.2`
- `powershell -ExecutionPolicy Bypass -File scripts/smoke_windows_gui.ps1 -ExePath dist/master-duel-recorder-lite-gui.exe -ExpectedVersion 2.2.2`
- `powershell -ExecutionPolicy Bypass -File scripts/smoke_windows_updater.ps1 -ExePath dist/master-duel-recorder-lite-updater.exe -ExpectedVersion 2.2.2`
- `python scripts/verify_release_assets.py v2.2.2`

## Non Goals

- DB schema変更
- 設定形式変更
- 録画ファイル、queue、manifest、OAuth資格情報の変更
- Runtime data保存先移行の実行
- YouTube OAuth資格情報の画面・設定・DB保存
