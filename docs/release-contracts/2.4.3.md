# V2.4.3 Release Contract

## Release Goal

レビュー画面の「選択位置をクリップ出力」で、FFmpegが一時出力ファイルの形式を判定できず失敗する問題を修正する。

## Scope

- `ClipExportService` がFFmpegへ渡す一時出力ファイル名を `.mp4` 末尾にする。
- 既存の原子的な一時出力から最終ファイルへ置換する安全設計は維持する。
- FFmpeg commandの出力引数が `.mp4` 末尾になることを単体テストで固定する。
- クリップ出力成功時の最終出力名は従来どおり `.mp4` とする。

## Non-Scope

- クリップ範囲編集UI。
- codec不一致時の再エンコードfallback。
- エラー文の大幅なUI改善。
- SQLite schema、設定形式、録画ファイル、YouTube投稿履歴、OAuth資格情報、prepare queue、manifestの変更。

## Acceptance Criteria

- [ ] FFmpegへ渡す一時出力パスが `.mp4` で終わる。
- [ ] 最終出力ファイルも `.mp4` で作成される。
- [ ] 失敗時に元録画を変更しない既存契約を維持する。
- [ ] `tests/test_clip_export.py` に一時出力名の回帰テストを追加する。
- [ ] `python -m pytest tests/test_clip_export.py tests/test_review_viewmodel.py tests/test_application.py` が成功する。
- [ ] `python -m pytest` が成功する。
- [ ] `python -m ruff check src tests scripts` が成功する。
- [ ] Windows EXE release workflowで公開資産検証とダウンロード後スモークが成功する。
