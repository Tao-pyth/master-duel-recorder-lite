# V2.7.15 Release Contract

## Decision / Release Goal
保存済み録画・デッキ・タグが再起動なしで一覧/候補へ反映され、アプリ内レビューを閉じた後に録画付き戦績を削除できる。

## Target Version
baseline v2.7.14、target_version v2.7.15。既存動作の修正でありFixを1増やす。

## Scope
W1 録画完了後の戦績一覧同期、W2 カタログ保存後の管理一覧と関連候補同期、W3 レビューのメディア/ウィンドウ寿命管理。関連回帰、文書、配布検証を含む。

## Non-Scope
DB/設定形式、録画方式、外部プレーヤー制御、統計新指標、一般的なプロセス強制終了、未確認の管理一覧障害の推測修正、実利用データ変更。

## Chosen Approach
既存GUI timerを利用して録画完了の変更を取りこぼさず検知し、GUI threadで更新する。編集時は保留し保存/破棄後に再取得する。カタログ保存成功後に関連候補を更新し、自由入力と選択/フィルターを保持する。レビューにメディアの所有とclose処理を設け、stopとsource解除、親画面の保持参照除去、メイン終了時の全レビュー解放を行う。既存削除の退避/rollbackを維持する。

## Acceptance Criteria
- AC1: 手動・自動録画の完了が一覧表示中にも反映される。短時間の録画や連続完了を取りこぼさず、変化がないtimerで全一覧再取得を繰り返さない。
- AC2: 録画完了による更新はフィルター・選択・未保存戦績を保護し、保留した更新は保存/破棄後に反映される。
- AC3: 新規デッキ/タグは管理一覧、戦績の絞り込み候補、録画のデッキ候補へ自動反映される。保存失敗時に偽の項目を表示しない。自由入力/選択/用途フィルターを維持する。
- AC4: 再生中、一時停止、再生終了後、複数レビューのclose時にメディアを解放し、親の保持参照を除く。メイン終了でも全レビューを解放する。
- AC5: Windows上の合成動画でclose後のファイル削除権限とサービス経由の履歴削除を確認する。同一動画の別レビューが開いている間は使用中となることを区別し、他のロック時は既存エラーとデータ保護を維持する。
- AC6: Ruff、関連回帰、全unittest、3EXE build/smokeに合格。版情報・リリースノート・文書一致。公開後のtag/commit/latest/7assets/hash/再取得3EXEsmoke/CI/Issue・Milestone closureを確認して正式完了する。

## Rejected Alternatives
全画面再構築、全プロセス強制終了、DB刷新は原因に対して過剰。再起動だけの回避策は採用しない。

## Risks
Qt close後の非同期破棄、GUI timerと監視threadの競合、候補変更の再入シグナル、削除時の実ファイルロック。実widget・隔離DBと合成動画で確認する。

## Deferred Solution Queue Intake
既存Queueの完了項目は変更不要。競合差別化とシーズン比較・メモ編集の残件はKeep。今回の修正への取り込みなし。

## Implementation Handoff
W1: 背景は録画完了履歴が手動更新まで見えないこと。変更通知/保留を追加しAC1-2を実widgetとサービス境界で検証。依存なし。録画方式は変更しない。
W2: 背景はカタログ保存後に他画面候補が古いこと。保存成功時の候補更新と選択保護、AC3の成功/失敗/自由入力回帰。依存なし。フィルター解除を勝手に行わない。
W3: 背景はclose後のPlayingStateとWinError32。所有・停止・source解除・参照除去・メインcloseを実装しAC4-5を実動画と複数ウィンドウで検証。配布検証AC6はW1-3完了に依存。

## Release Contract
required: Implementation, Tests, UI, README, Architecture Docs, User Docs, CHANGELOG, Version Metadata, Commit, Push, Tag, Build, CI, Packaging, GitHub Release, Artifact Publish, Published Verification, Release Notes, Backward Compatibility, Issue/Milestone closure。
not-required: Database, Database Migration, Configuration, Configuration Migration, API, CLI, PR / Merge（既存main fast-forward公開方式）。needs-investigationなし。
実行時データは保護し、テストと配布スモークは隔離する。外部公開の許可はRelease Contract自体から推定しない。既存の許可範囲を照合し、未許可ならローカル準備を完了して公開直前に確認する。
