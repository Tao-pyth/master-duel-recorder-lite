# V2.4.2 Release Contract

## Release Goal

V2.4.1公開後に確認されたPySide6通常GUIの実操作欠落と視認性問題を修正する。戦績編集とレビュー画面マーカー編集を実際に保存できる状態へ戻し、設定画面と録画/テンプレート画面の操作密度を調整する。

## Scope

- 設定画面の `visual_language` を自由入力から非編集プルダウンへ変更する。
- `録画設定` と `録画診断・信頼性` を `録画設定①` / `録画設定②` として再分配し、設定画面の縦スクロールを抑える。
- 戦績表示設定、デッキ名、タグのカラー表示を枠線付きスウォッチへ改善する。
- 録画画面の開催中シーズン表示を読み取りやすい表示へ変更する。
- 主要操作ボタンへQt標準アイコンを付与する。
- テンプレート画面の概要欄を画面下部の余白まで広げる。
- 戦績管理の編集ボタンから実際の戦績編集ダイアログを開き、主要フィールドを保存できるようにする。
- レビュー画面のマーカーラベルを編集して保存できるようにする。

## Non-Scope

- DB schema変更。
- 録画ファイル、queue、manifest、OAuth資格情報の移行や初期化。
- YouTube直接アップロード機能の拡張。
- 全画面・全ボタンの完全なアイコンデザイン統一。
- ヘルプ導線の体系化。
- レビュー画面でのイベント時刻やイベント種別の編集。

## Acceptance Criteria

- `settings_visual_language` が `auto`、`ja`、`en` の非編集プルダウンとして表示され、保存時に不正値を手入力できない。
- 設定タブ名が `録画設定①` / `録画設定②` を含み、旧 `録画診断・信頼性` 単独タブに依存しない。
- 録画診断・信頼性の状態更新と初回導入確認は設定内から実行できる。
- カラー列は空文字のままでも白や淡色を識別できる枠線付きスウォッチで表示される。
- 録画画面の開催中シーズンは状態と名称が分かれて読める。
- 主要操作ボタンにアイコンが付く。
- テンプレート概要欄が固定的に小さくならず、ページ下部の余白を利用する。
- 戦績管理で選択した行の戦績を編集し、保存後に一覧が更新される。
- レビュー画面で選択した `marker` のラベルを編集し、保存後にタイムラインが更新される。
- 既存のV2.4.1 smoke contract、標準GUI契約、データ保護契約が壊れない。
