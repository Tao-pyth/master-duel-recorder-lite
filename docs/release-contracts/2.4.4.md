# V2.4.4 Release Contract

## Release Goal

レビュー画面のクリップ出力拡張子エラーを修正し、Release asset検証をGitHub Actions認証対応にして、正式Release workflowを成功させる。

## Scope

- `ClipExportService` がFFmpegへ渡す一時出力ファイル名を `.mp4` 末尾にする。
- `scripts/verify_release_assets.py` が `GITHUB_TOKEN` または `GH_TOKEN` を使用してGitHub APIを読む。
- クリップ出力とRelease asset検証の回帰テストを追加する。
- V2.4.4としてversion metadata、release notes、validationを更新する。

## Non-Scope

- クリップ範囲編集UI。
- codec不一致時の再エンコードfallback。
- エラー文の大幅なUI改善。
- SQLite schema、設定形式、録画ファイル、YouTube投稿履歴、OAuth資格情報、prepare queue、manifestの変更。

## Acceptance Criteria

- [ ] FFmpegへ渡す一時出力パスが `.mp4` で終わる。
- [ ] 最終出力ファイルも `.mp4` で作成される。
- [ ] Release asset検証がGitHub Actions上で認証ヘッダーを利用できる。
- [ ] `python -m pytest tests/test_clip_export.py tests/test_release_tooling.py tests/test_review_viewmodel.py tests/test_application.py` が成功する。
- [ ] `python -m pytest` が成功する。
- [ ] `python -m ruff check src tests scripts` が成功する。
- [ ] Windows EXE release workflowで公開資産検証とダウンロード後スモークが成功する。
