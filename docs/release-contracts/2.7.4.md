# Release Contract 2.7.4

## Summary

V2.7.4 delivers the battle history and review editing workflow improvements requested after V2.7.3. The release stays within V2.7.x and does not introduce database or configuration migrations.

## Scope

- Enable the battle history bulk edit button with a real multi-record update workflow.
- Restore deck inputs in the battle editor as editable candidate selectors.
- Widen and localize the battle editor dialog.
- Add review-screen tabs for marker editing and battle input.
- Allow battle result editing from the review screen while keeping video context visible.
- Add candidate timeline event confirm/reject controls.
- Treat manual marker data as type plus description, while keeping automatic labels protected.
- Hide timeline source/origin from the normal review table.
- Explain clip export range and add an Explorer-open action after export.
- Unify major button icons with one line-icon style inspired by Pictogrammers Material Design Icons.

## Non-Scope

- No SQLite schema migration.
- No runtime data deletion or initialization.
- No OAuth or direct upload expansion.
- No OBS dependency.
- No V2.8.0 or later version bump.

## Required Evidence

- Focused unit tests for bulk edit, review marker/status display, clip range messaging, and GUI contracts.
- GUI smoke outputs for history and review-related contracts.
- Real-device launch and functional connection check using an isolated V2.7.4 validation data directory.
- Version metadata updated to `2.7.4`.
- Release notes and validation notes updated.
- Commit, push, tag, GitHub Release, attached artifacts, and published verification completed.

## Release Execution

- Commit: required.
- Push: required.
- PR / Merge: not required; this repository releases directly from `main`.
- Tag: required, `v2.7.4`.
- Build: required for CLI, GUI, and updater artifacts.
- GitHub Release: required.
- Artifact Publish: required.
- Published Verification: required.
- Issue/Milestone closure: required when matching open GitHub Issues or Milestones exist; otherwise record as not applicable.

## Acceptance Criteria

- Bulk edit applies only checked fields to selected battle records and confirms target count before save.
- Deck fields support both known deck selection and free text.
- Battle editor is wide enough for normal Japanese labels and values, and buttons are Japanese.
- Review screen contains marker-edit and battle-input tabs.
- Review screen battle input saves through existing application services.
- Candidate timeline events can be confirmed or rejected from the review screen.
- Manual markers can be edited as type plus description.
- Automatic detection labels are not overwritten by normal marker editing.
- Review timeline no longer exposes source/origin as a normal column.
- Clip export UI states the selected-position range behavior and can open the output folder.
- Public GitHub Release artifacts download and verify as V2.7.4.
