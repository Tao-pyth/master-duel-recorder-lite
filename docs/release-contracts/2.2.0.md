# V2.2.0 Release Contract

## Release Goal

PySide6 GUIで不足しているカレンダーピック、カラー表示、統計グラフ、表の列幅・選択色を改善し、戦績・統計・カタログを日常的に読み取りやすくする。

## Baseline And Target

- baseline_version: V2.1.1
- target_version: V2.2.0
- Issue: [#566](https://github.com/Tao-pyth/master-duel-recorder-lite/issues/566)
- Milestone: [V2.2.0](https://github.com/Tao-pyth/master-duel-recorder-lite/milestone/76)

## Acceptance Criteria

- 統計画面の開始日・終了日はカレンダーポップアップ付きで、`yyyy-MM-dd`形式で表示される。
- 統計推移は棒と線の視覚的なグラフとして表示され、0件時も空白にならない。
- 戦績管理表は主要列が固定幅/伸縮の意図を持ち、横スクロール込みで長いデッキ名や相手デッキ名を読み取りやすい。
- 表の選択色は強すぎず、文字の可読性を維持する。
- デッキ/タグのカラー列は実際の色見本を表示し、文字だけに依存しない。
- smoke contractにUI改善契約が追加され、テストで欠落が検出できる。
- スクリーンショット確認またはUI確認結果が `docs/validation/2.2.0.md` に残っている。

## Test Requirements

- `python -m pytest tests/test_pyside_gui.py tests/test_v201_gui_recovery.py`
- `python -m master_duel_recorder_lite.pyside_gui --smoke-test --smoke-output build/pyside-ui-usability-smoke.json --smoke-screenshot build/pyside-ui-usability-smoke.png`
- `python -m ruff check .`
- スクリーンショットを目視確認し、統計グラフ、カレンダー入力、表の列幅/選択色/カラー表示に破綻がないことを記録する。

## Non Goals

- 設定形式変更
- 録画ファイル、queue、manifest、OAuth資格情報の削除、初期化、形式変更
- OBS Plugin / OBS WebSocket依存追加
- Tkinter互換モジュールの削除
- 外部アップロードやOAuth導線の拡張
