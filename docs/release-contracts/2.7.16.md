# V2.7.16 Release Contract

## Decision / Release Goal
映像を見ながら戦績・マーカーを編集し、追加画面領域を映像へ優先配分する。

## Target Version
baseline v2.7.15、target_version v2.7.16。既存機能のレイアウト改善でFix更新。

## Scope
W1: 左映像・操作/右編集の2ペイン、初期戦績タブ、フォームとマーカー操作の再配置、補助情報省略。
W2: 実widget/合成動画/隔離DB回帰、設計/操作文書、版更新と正式配布検証。

## Non-Scope
録画方式、DB/設定schema、認証、戦績/マーカーの保存形式、他画面の再設計、新機能、実行時データ変更。

## Chosen Approach
左はstretch=1、右は固定幅（約400論理px、実widget検証で必要十分に調整）。動画の高さ上限を除去しKeepAspectRatioを明示。右内に縦スクロール、戦績保存は下端へ固定。選択ボタンは項目ごと、対戦種別/シーズン/デッキ/タグは1項目1行。マーカー6操作は2列。タブ順は戦績入力→マーカー編集。明示initial_tab=marker互換は維持。概要は省略表示+全文tooltip。

## Acceptance Criteria
- AC1: 左右2ペイン、既定戦績タブ、左右同時表示。通常レビューと戦績編集入口を確認。
- AC2: 1120x960と1120x780で旧画面と同一サイズ比較。16:9映像の実効面積が増える。960x640でも操作可能。
- AC3: KeepAspectRatio、横拡大分は左へ、右幅一定。tab切替前後のvideo.geometry一致。16:9と4:3合成動画の枠内表示確認。
- AC4: 長いデッキ・season・ファイル名で画面幅が強制拡張されない。右フォームを縦スクロールでき保存へ到達。100/150/200%相当の実widget確認。
- AC5: 実動画再生/停止/seek、外部で開く、marker追加/編集/候補確定却下/clip導線、戦績全フィールド保存と再読込、親への保存通知、close解放を確認。隔離DBを使用。
- AC6: Ruff、関連回帰、全unittest、3EXE build/smoke、版情報・文書一致。main/tag/latest Release/公開7asset/hash/再取得3EXE smoke/CI成功、Issue・Milestone closureを証拠化。

## Rejected Alternatives
右の比率拡大、動画のみの上限変更、今回不要な可変splitter追加を採用しない。

## Risks
Qt sizeHint、スクロール内最小幅、DPI、tab最大minimum、動画backend。実widget/合成動画で検証する。

## Deferred Solution Queue Intake
既存競合差別化・シーズン比較等はKeep。今回のScopeと無関係。追加なし。

## Implementation Handoff
W1: 背景は上下構成の映像圧迫。上記UIのみ再配置。AC1-4が完了条件。寸法/タブ/長文/DPIがTest Requirements。依存なし。
W2: 背景は既存機能と配布品質の保護。W1に依存。AC5-6とAC1-4の証拠を実widget、隔離サービス、合成動画で残し正式公開まで行う。

## Release Contract
required: Implementation, Tests, UI, README, Architecture Docs, User Docs, CHANGELOG, Version Metadata, Commit, Push, Tag, Build, CI, Packaging, GitHub Release, Artifact Publish, Published Verification, Release Notes, Backward Compatibility, Issue/Milestone closure。
not-required: Database, Database Migration, Configuration, Configuration Migration, API, CLI, PR / Merge（既存main fast-forward運用）。needs-investigationなし。
リリースCIの3EXE build/smoke、公開asset hash検証、再取得smokeを配布証拠とする。外部公開許可は既存Project Knowledgeの2026-09-08包括承認と今回のloop依頼の範囲内。AGENTS.md既存差分と実利用データを保護。
