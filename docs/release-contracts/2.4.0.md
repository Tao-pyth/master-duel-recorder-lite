# V2.4.0 Release Contract

## Release Goal

通常GUIから録画済み対戦を選び、アプリ内で動画確認、タイムライン参照、現在位置マーカー、クリップ書き出し準備まで到達できる状態にする。

## Scope

- 戦績管理`history_play`から通常GUI内レビューウィンドウを開く。
- `.mp4`と`.mkv`の安全な録画参照をアプリ内再生に渡す。
- 再生/一時停止、シーク、現在位置表示を提供する。
- タイムラインイベントクリックで動画位置を`elapsed_ms`へ移動する。
- 現在位置マーカー追加と選択位置中心のクリップ出力を既存Application Service経由で実行する。
- Qt Multimedia不可、未対応形式、再生エラー時は外部プレイヤーへfallbackする。
- README、設計文書、release notes、validation、version metadataをV2.4.0へ更新する。
- テスト、GUI smoke、ビルド、GitHub Release、公開asset検証を完了する。

## Non Scope

- DB schema migration
- 設定migration
- 録画処理、検出処理、queue、manifest、OAuth資格情報の変更
- 高度なタイムライン編集、波形、サムネイル、クリップ範囲エディタ
- Tkinter GUIの同一プロセス埋め込み

## Acceptance Criteria

- 通常GUIの戦績管理から録画レビュー画面へ到達できる。
- レビュー画面で動画再生、再生/一時停止、シーク、現在位置表示ができる。
- タイムライン一覧が経過、種別、状態、ラベル、由来を表示する。
- タイムラインイベント選択で動画位置が移動する。
- 現在位置マーカー追加とクリップ出力が既存サービス経由で実行される。
- Qt Multimedia不可、未対応形式、再生エラー時に外部プレイヤーへfallbackする。
- SQLite schema、設定形式、録画ファイル、queue、manifest、OAuth資格情報を変更しない。
- `pyproject.toml`、`master_duel_recorder_lite.__version__`、docsが`2.4.0`で一致する。
- `v2.4.0` tagとGitHub Releaseが作成され、公開assetを取得できる。

## Required Validation

- `python -m ruff check .`
- `python -m pytest`
- `python -m master_duel_recorder_lite.pyside_gui --smoke-test --smoke-page history --smoke-output build/v2.4.0-history-smoke.json --smoke-screenshot build/v2.4.0-history-smoke.png`
- `python scripts/verify_release_tag.py v2.4.0`
- Windows EXE release workflow
- 公開asset検証とダウンロード後スモーク
