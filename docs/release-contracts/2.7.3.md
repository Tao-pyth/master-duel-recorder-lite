# V2.7.3 Release Contract

## Release Goal

V2.7.2実機検証で残った、自動監視開始直後に停止できない不具合を緊急修正する。

## Scope

- `watch_starting`中でも自動監視停止を受け付ける。
- `watch_starting -> stopping`の状態遷移を正規の停止経路として許可する。
- PySide6録画画面で、自動監視開始中の停止操作が可能であることを表示とボタン状態へ反映する。
- `stop_watch()`が開始前診断中や監視準備中でも状態遷移エラーを出さず停止要求を処理する。
- 回帰テスト、PySide6契約テスト、実機GUI検証を追加または実施する。
- バージョン情報とリリースノートをV2.7.3へ更新する。

## Non-Scope

- 録画方式、FFmpegコマンド、保存先生成は変更しない。
- Master Duelの画面判定ロジック、ROI、信頼度閾値は変更しない。
- プリロール、音声録音、YouTube、戦績DB、統計、レビュー画面は変更しない。
- SQLite schema、設定schema、既存録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- OBS PluginとOBS WebSocketへの依存は追加しない。

## Acceptance Criteria

- [ ] `watch_starting`中に`OperationAction.STOP_WATCH`が許可される。
- [ ] `watch_starting -> stopping -> idle`の遷移が成功する。
- [ ] 自動監視開始直後のPySide6録画画面で、停止操作または自動監視停止操作が可能になる。
- [ ] `stop_watch()`を`watch_starting`中に呼んでも不正状態遷移にならない。
- [ ] 実機GUIで「自動監視開始」押下後に停止要求を受け付けることを確認する。
- [ ] SQLite schema、設定schema、録画ファイル、queue、manifest、OAuth資格情報を変更しない。
- [ ] Ruff、対象pytest、全pytest、PySide6録画画面smoke、Windows EXE build、3 EXE smokeに合格する。
