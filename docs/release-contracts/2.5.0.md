# V2.5.0 Release Contract

## Release Goal

PySide6通常GUIの全主要画面について、表示されている操作が実処理、明確な無効状態、または利用者向け案内へ接続されていることを確認し、未接続・誤解を招く操作・内部実装文言の露出を減らす。

## Classification

| Area | Classification | Expected Evidence |
| --- | --- | --- |
| Implementation | required | PySide6主要画面の操作契約を監査し、確認された未接続/誤案内/無効状態不足を修正する |
| Tests | required | GUI smoke、回帰テスト、操作契約テストを追加または更新する |
| Database | not-required | SQLite schema変更なし |
| Database Migration | not-required | migration追加なし |
| Configuration | not-required | 設定形式変更なし |
| Configuration Migration | not-required | migration追加なし |
| API | not-required | 外部API契約変更なし |
| CLI | not-required | CLI機能変更なし |
| UI | required | 録画、戦績管理、統計、デッキ名、タグ、シーズン、テンプレート、設定、レビュー関連導線の操作契約を確認する |
| README | required | 必要に応じて通常GUIの品質確認範囲を更新する |
| Architecture Docs | required | GUI操作契約または検証方針の短い設計メモを追加/更新する |
| User Docs | required | 利用者に見える変更があればリリース文書へ記録する |
| CHANGELOG | required | `docs/release-notes.md` にV2.5.0を追加する |
| Version Metadata | required | `pyproject.toml` と `src/master_duel_recorder_lite/__init__.py` を `2.5.0` へ更新する |
| Commit | required | 英語本文と初心者向け日本語説明を含むcommit |
| Push | required | mainへ反映 |
| PR / Merge | not-required | ローカルmainへのfast-forward/直接push運用を許容する |
| Tag | required | `v2.5.0` |
| Build | required | Windows CLI/GUI/updater EXE build |
| CI | required | GitHub Actions CI success |
| Packaging | required | 3 EXEとSHA-256 |
| GitHub Release | required | GitHub Release `v2.5.0` |
| Artifact Publish | required | CLI/GUI/updater EXEとSHA-256をRelease assetへ添付 |
| Published Verification | required | 公開asset検証とダウンロード後EXE smoke |
| Release Notes | required | V2.5.0変更点、検証、互換性を記録 |
| Backward Compatibility | required | 既存DB、設定、録画、OAuth資格情報、queue、manifestを保持 |

## Acceptance Gate

- GUIに表示される主要操作が、未実装の仮メッセージだけで終わらない。
- 操作不能な状態は、押せない状態、ツールチップ、または具体的な案内で表現される。
- 内部キーや実装者向け文言が、通常利用者向けの主要画面に露出しない。
- 既存の録画、戦績、統計、デッキ、タグ、シーズン、テンプレート、設定、レビュー導線を壊さない。
- DB schema、設定形式、録画ファイル、YouTube投稿履歴、OAuth資格情報、prepare queue、manifestを変更しない。
