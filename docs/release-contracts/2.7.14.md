# V2.7.14 Release Contract

## Release Goal
長い説明があってもデッキ/タグの名前を優先して識別できる一覧へ修正。
## Target Version
v2.7.14（Fix）、baseline v2.7.13。
## Scope / Chosen Approach
色を名前に併設し説明を同セル下段に小さく表示。独立した色/説明列を廃止。名前最低220px、折返しなし、長文は省略＋tooltip、右フォームで全文。デッキ副列コンパクト。フィルターの対象を明示（非表示も含むためデッキは用途・表示）。
## Non-Scope
DB/API/設定/録画変更、シーズン列刷新、その他のフィードバック、実ユーザーデータ編集。
## Acceptance Criteria
- AC1: デッキは名前/使用回数/用途/履歴・統計、タグは名前/用途。色アイコン＋名前＋小さい説明、全データ保存/検索/編集状態は維持。
- AC2: 32件以上・長い名前/説明でも名前列220px以上、文字の縦折り返しなし。980x640/1180x760/1440x1024・100/150/200%で実画像と文字表示を確認。全列は横スクロールで到達可能。
- AC3: 表示専用回帰と既存5widget回帰、Ruff/全unittest成功。名前/説明全文tooltipと検索、選択/保存が正しい。
- AC4: 版情報/README/文書/release notes、commit/main/tag一致、Main/Release CI成功、正式7asset/hash/再取得3EXEsmoke、Issue/Milestone closure。
## Rejected Alternatives
列を手動調整する案はデータ依存を解消しない。編集欄撤去は採用構成と不一致。
## Risks
極端な長文は省略と全文参照を併用。表示専用delegateで選択色/アイコンを保持。
## Deferred Solution Queue Intake
既存項目Keep。
## Implementation Handoff
W1: 一覧セルと列幅の修正・32件長文回帰・画像・公開（AC1-4）。背景は実データで名前が読めない問題。Issue登録後実装。依存なし。データ形式は対象外。
## Release Contract
required: Implementation, Tests, UI, README, Architecture Docs, User Docs, CHANGELOG, Version Metadata, Commit, Push, Tag, Build, CI, Packaging, GitHub Release, Artifact Publish, Published Verification, Release Notes, Backward Compatibility, Issue/Milestone closure。
not-required: Database, Database Migration, Configuration, Configuration Migration, API, CLI, PR（既存main fast-forward公開）。needs-investigationなし。
