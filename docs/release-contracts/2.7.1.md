# V2.7.1 Release Contract

## Release Goal

V2.7.0公開直後の実操作レビューで確認されたPySide6 GUIの視覚品質問題を修正し、ボタン、表、統計グラフ、色設定、シーズン入力を迷わず使える状態にする。

## Scope

- 主要ボタンのQt標準アイコンを、アプリ内で描画する線画アイコンへ置き換える。
- 統計画面の勝利数・勝率推移グラフで、文字被りを防ぐ余白を確保する。
- 戦績管理などの表の行高を固定し、選択や操作後に行が膨らまないようにする。
- 設定の戦績表示色テーブルから、色変更操作を直接実行できるようにする。
- シーズン入力を、名前1行、種別・開始日・終了日1行へ整理し、入力幅を揃える。
- シーズン一覧の種別を日本語表示にする。
- バージョン情報とリリースノートをV2.7.1へ更新する。

## Non-Scope

- DB schema変更、DB migration。
- 設定ファイルschema変更。
- 録画、検出、レビュータイムライン、クリップ出力の機能追加。
- OBS Plugin、OBS WebSocket、OAuth、直接アップロード。
- `user_data/`、録画ファイル、SQLite DB、queue、manifest、OAuth資格情報、ログの削除、初期化、上書き。
- 外部アイコンパッケージや画像アセットの追加。
- 画面全体の大規模リデザイン。

## Acceptance Gate

- 主要操作ボタンはQt標準アイコンではなく、統一された線画アイコンを表示する。
- 統計グラフの上部ラベル、X軸ラベル、凡例が重ならない。
- 表の行高は選択、更新、ボタン押下後も固定される。
- 戦績表示色テーブルに「変更」列があり、色選択ダイアログから既存UI設定へ保存できる。
- シーズン入力は、名前が単独行、種別・開始日・終了日が同一行で、3入力の幅が揃う。
- シーズン一覧の種別は「ランク戦」「イベント」「カスタム」と表示され、`ranked`や`event`を表示しない。
- SQLite schema、設定schema、録画ファイル、queue、manifest、OAuth資格情報を変更しない。
- Ruff、対象pytest、PySide6 GUI smokeに合格する。
