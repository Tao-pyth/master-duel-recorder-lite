# Release Contract 2.7.8

Issue: [#630](https://github.com/Tao-pyth/master-duel-recorder-lite/issues/630)。Milestone: [V2.7.8 録画画面Hotfix](https://github.com/Tao-pyth/master-duel-recorder-lite/milestone/90)。

## Scope

録画ページに必要な高さを保ち、狭いウィンドウでも縦スクロールで各操作へ到達できるようにする。自動監視ボタンと判定詳細の重なり、状態帯の圧縮、診断表の行欠けを修正する。録画・検出・初期値保存の意味、設定形式、DB、実行時データは変更しない。

## Acceptance Criteria

- 最小980×640、初期1180×760、1180×790、1180×1000で操作領域が交差せず、親領域に収まる。
- 停止、監視開始中、監視待機中、自動/手動録画中、停止処理中の状態帯と操作が読める。
- 初期値入力を保持し、既存のスナップショット契約を維持する。
- 診断行を読め、スクロール後に録画操作へ戻れる。
- 実Qt widgetの回帰検証が修正前に失敗し、修正後に合格する。日本語フォントと100/150/200%相当の描画条件を確認する。
- Ruff、全unittest、関連録画回帰、CLI/GUI/updaterビルドとsmokeに合格する。
- 公開後にtag、version、Release、assetのSHA256、ダウンロード後smokeを確認する。
