# V2.2.1 Release Contract

## Release Goal

配布資産なしの通常Releaseが存在してもアプリ内更新が壊れないようにし、V2.2.1通常ReleaseにはCLI/GUI/updater EXEとSHA-256を必ず揃えて公開する。

## Baseline And Target

- baseline_version: V2.2.0
- target_version: V2.2.1
- Issue: [#568](https://github.com/Tao-pyth/master-duel-recorder-lite/issues/568)
- Milestone: [V2.2.1](https://github.com/Tao-pyth/master-duel-recorder-lite/milestone/77)

## Contract Matrix

| Area | Status | Requirement |
| --- | --- | --- |
| Implementation | required | 更新確認をRelease一覧から配布可能安定版を選ぶ方式へ変更する |
| Tests | required | app update、release tooling、version、Ruff、EXE smoke、公開Release asset検証 |
| Database | not-required | SQLite schemaは変更しない |
| Database Migration | not-required | DB移行は行わない |
| Configuration | not-required | 設定形式は変更しない |
| Configuration Migration | not-required | 設定移行は行わない |
| API | not-required | 外部API仕様は変更しない |
| CLI | not-required | CLIコマンド仕様は変更しない |
| UI | not-required | 画面機能は変更しない |
| README | required | 更新確認の最新状態を反映する |
| Architecture Docs | required | アプリ更新設計にRelease一覧選択を反映する |
| User Docs | not-required | 新操作は追加しない |
| CHANGELOG | required | `docs/release-notes.md` へV2.2.1を追加する |
| Version Metadata | required | `pyproject.toml` と `master_duel_recorder_lite.__version__` を2.2.1へ揃える |
| CI | required | GitHub CIを通す |
| Packaging | required | CLI/GUI/updater EXEと各SHA-256をReleaseへ添付する |
| Release Notes | required | `docs/releases/2.2.1.md` と validationを作成する |
| Backward Compatibility | required | 既存user_data、SQLite、録画、queue、manifest、OAuth資格情報を保持する |

## Acceptance Criteria

- 資産なしReleaseが最新に存在しても、更新確認は配布可能な最新安定版を選ぶ。
- 配布可能Releaseが存在しない場合は、例外ではなく「利用可能な更新なし」と扱う。
- V2.2.1通常ReleaseにCLI/GUI/updater EXE、各SHA-256、SHA256SUMSが揃う。
- `python scripts/verify_release_assets.py v2.2.1` が成功する。

## Test Requirements

- `python -m pytest tests/test_app_update.py tests/test_release_tooling.py tests/test_version.py`
- `python -m ruff check .`
- `python scripts/build_windows_exe.py`
- `powershell -ExecutionPolicy Bypass -File scripts/smoke_windows_exe.ps1 -ExePath dist/master-duel-recorder-lite.exe -ExpectedVersion 2.2.1`
- `powershell -ExecutionPolicy Bypass -File scripts/smoke_windows_gui.ps1 -ExePath dist/master-duel-recorder-lite-gui.exe -ExpectedVersion 2.2.1`
- `powershell -ExecutionPolicy Bypass -File scripts/smoke_windows_updater.ps1 -ExePath dist/master-duel-recorder-lite-updater.exe -ExpectedVersion 2.2.1`
- `python scripts/verify_release_assets.py v2.2.1`

## Non Goals

- DB schema変更
- 設定形式変更
- 録画ファイル、queue、manifest、OAuth資格情報の変更
- UI機能追加
