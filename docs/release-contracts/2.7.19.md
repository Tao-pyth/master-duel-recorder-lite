# V2.7.19 Release Contract

## Decision / Release Goal
統計を開催日順と対戦種別で比較し、何を絞り込むか分かる画面にする。
## Target Version
baseline v2.7.18 / target v2.7.19。既存統計の改善でFix更新。
## Scope / Acceptance Criteria
#656: シーズン開始日DESC・同日season_id DESC、未設定末尾。名前順/登録順が異なるfixture、同日/アーカイブ/期間を検証。
#657: 対戦種別5値内訳と任意フィルター、GUI種別別タブと勝敗選択の置換。全体カードは全件、他カードとタブは期間×種別を適用。勝敗を含む集計であると明示。既存resultフィルター互換を維持。
## Test Requirements
種別5値と不正値拒否、勝敗/引分の母数、下書き/失敗録画/非表示デッキ除外、期間×種別、全体独立、各タブ・空状態・解除を単体/実widget検証。開催日/同日順、未設定とアーカイブを検証。日本語画面確認。Ruff/全unittest/版整合。
## Non-Scope / Compatibility
DB・設定schema変更、実利用データ更新、録画方式変更、統計以外のGUI再設計は対象外。既存保存値を読み取り、データ移行不要。StatisticsDashboard/Rowの追加フィールドは既存呼出互換を維持。
## User Decision
任意質問へ「対戦種別の絞り込みに置き換える（推奨）」の回答。シーズンは開始日の新しい順と提示済み。
## Release Contract
required: Implementation, Tests, UI, README, User Docs, CHANGELOG, Version Metadata, Commit, Push, Tag, Build, CI, Packaging, GitHub Release, Artifact Publish, Published Verification, Release Notes, Backward Compatibility, Issue/Milestone closure。
not-required: Database/Configuration変更・移行、API/CLIコマンド変更、PR/Merge（既存main直接公開方式）。needs-investigationなし。
3EXE build/smoke、正式Release、公開7asset/hash/再取得3EXE smokeをRelease CIで検証。既存包括承認を継承。
## Tracking / Handoff
#656、#657 / Milestone101。#656の集計順、#657の読み取りと種別集計・UIを順に実装。既存AGENTS.md変更を保護。
