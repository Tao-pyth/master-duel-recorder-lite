# V2.7.0 Release Contract

## Release Goal

アプリ内レビュー画面に視覚タイムラインMVPを追加し、録画内の重要位置を表形式だけでなく動画の流れに沿って把握・選択・シークできるようにする。V2.4.0で完了済みの動画再生、タイムライン一覧、マーカー、clip exportを再実装せず、既存レビュー機能の上に小さく拡張する。

## Scope

- レビュー画面に、録画長に対する現在位置、選択位置、タイムラインイベント位置を示す視覚タイムラインバーを追加する。
- `duel_start`、手動マーカー、タイムラインイベント、clip candidate相当の位置を識別できる表示にする。
- 視覚タイムライン上のイベントをクリックまたは選択したとき、既存の動画シークとタイムライン一覧選択へ接続する。
- 表形式タイムラインと視覚タイムラインの選択状態を同期する。
- 再生中の現在位置表示を視覚タイムラインへ反映する。
- Qt Multimediaが利用できない場合、または外部プレイヤーfallback時に、視覚タイムライン機能が保存データを変更しないようにする。
- 既存の `RecorderApplicationService` / ViewModel境界を維持し、GUIからSQLiteや録画ファイルを直接操作しない。
- 視覚タイムラインMVPの設計判断、操作説明、検証結果をドキュメントに残す。

## Non-Scope

- クリップ範囲エディタの本実装。
- 開始/終了ハンドル、範囲プレビュー、出力前確認の高度化。
- 波形生成、サムネイル生成、プレビュー画像キャッシュ。
- 実録画codec差異の網羅検証。
- 長時間バックグラウンド録画、任意クリップ保存。
- DB schema変更、DB migration。
- 設定形式変更、設定migration。
- OBS Plugin、OBS WebSocket連携。
- 直接アップロード、OAuth連携、YouTube連携本体。
- 既存録画ファイル、queue、manifest、OAuth資格情報の変更。

## Acceptance Gate

- レビュー画面で、録画長に対する現在位置とタイムラインイベント位置が視覚的に分かる。
- 視覚タイムライン上のイベントを選択すると、動画再生位置が該当時刻へ移動する。
- 表形式タイムラインでイベントを選択した場合も、視覚タイムライン側の選択位置が一致する。
- 再生中またはシーク後、現在位置表示が視覚タイムライン上で更新される。
- `duel_start`、手動マーカー、通常イベント、clip candidate相当の位置を混同しない表示またはtooltipを持つ。
- 録画長が不明、イベントが空、イベント時刻が録画範囲外、Qt Multimediaが利用できない場合でも、レビュー画面が保存データを変更せず分かる形で扱う。
- GUIはSQLite、録画ファイル、FFmpegを直接操作せず、既存サービス境界を維持する。
- クリップ範囲エディタ、波形/サムネイル、DB schema、設定形式、長時間バックグラウンド録画、任意クリップ保存、OAuth、queue、manifestを変更しない。
- Ruff、対象単体テスト、GUI smoke、CLI/GUI/updater EXE build、CI、公開Release asset検証、ダウンロード後EXE smokeに合格する。
