# V2.1.1 Release Contract

## Release Goal

V2.1.0公開後にPySide6 GUIが初期・簡略UIへ戻っている回帰を修正し、
`docs/assets/tkinter-ui-baseline-1.5.2-rich` のリッチUI基準に近い画面構成、
情報量、操作導線、状態表示を復旧する。

## Baseline And Target

- baseline_version: V2.1.0
- target_version: V2.1.1
- Issue: [#564](https://github.com/Tao-pyth/master-duel-recorder-lite/issues/564)
- Milestone: [V2.1.1](https://github.com/Tao-pyth/master-duel-recorder-lite/milestone/75)

## Acceptance Criteria

- 録画画面が画像2相当の構成になり、画像1のような簡略UIを完成扱いしない。
- 主要9画面と内部2画面が `docs/assets/tkinter-ui-baseline-1.5.2-rich` の情報量と主要導線を持つ。
- PySide6 smoke contractにrich baseline、rich UI section、内部ページの確認項目が含まれる。
- `failed_standard_operation_checks` が空になる。
- smoke screenshotで録画対象、状態表示、環境診断、アクティビティ、戦績管理表、統計、設定タブが確認できる。
- DB schema、設定形式、録画、queue、manifest、OAuth資格情報を変更しない。

## Test Requirements

- `python -m pytest tests/test_v201_gui_recovery.py`
- `python -m master_duel_recorder_lite.pyside_gui --smoke-test --smoke-output <path> --smoke-screenshot <path>`
- `ruff check .`

## Non Goals

- 新機能追加
- SQLite schema変更
- 設定形式変更
- 録画ファイル、queue、manifest、OAuth資格情報の削除、初期化、形式変更
- OBS Plugin / OBS WebSocket依存追加
- Tkinter互換モジュールの削除
