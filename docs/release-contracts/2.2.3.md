# V2.2.3 Release Contract

## Release Goal

V2.2.2後に報告されたPySide6戦績管理ハブの実操作品質を復旧し、主要ボタンが反応し、一覧が日本語で読め、期間をカレンダーピックで指定でき、主要操作・補助操作・危険操作の違いが分かる状態にする。

## Acceptance Criteria

- 戦績管理の主要ボタンをクリックしたとき、実処理、ダイアログ、無効状態、または明確な案内のいずれかが発生し、無反応にならない。
- 行選択が必要な操作は、未選択時に無効表示され、選択時に有効化される。
- 削除など危険操作は、確認後だけ実行され、キャンセル時にDB、録画、queue、manifest、OAuth資格情報を変更しない。
- 戦績管理一覧に `win`、`loss`、`first`、`second`、`heads`、`tails`、`ranked`、`event`、`other` が利用者向けセル値として表示されない。
- 戦績管理画面で開始日・終了日をカレンダーポップアップから選択でき、期間指定を解除できる。
- 戦績管理ツールバーで、主要操作、補助操作、危険操作の違いが視覚的に分かる。
- GUI smokeまたはテストが、ボタン未接続、内部コード露出、日付ピッカー欠落を検出できる。
- V2.2.3通常ReleaseにCLI/GUI/updater EXE、各SHA-256、SHA256SUMSが揃う。
- `python scripts/verify_release_assets.py v2.2.3` が成功する。
