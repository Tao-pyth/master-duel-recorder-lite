# master-duel-recorder-lite v0.19.0

ランクやイベントの期間を戦績へ関連付けるシーズン管理と、録画履歴・デッキ管理・統計の改善を提供するマイナーリリースです。

## 主な変更

- シーズンの追加、編集、アーカイブ、未参照時の削除、説明、レポートメモ
- 対戦記録へのシーズン割り当てと期間外警告、シーズン別ライブ集計
- 録画履歴のシーズン、自分デッキ、相手デッキ、複数タグフィルター
- デッキカラー、相手デッキ専用、履歴・統計候補の非表示フラグ
- カレンダー日付入力、先攻・後攻勝率、デッキ別全体、デッキ先後別
- 利用状態をアイコン、状態名、コントラストのある色で表示

## 復旧機能の撤去

期待どおりの修復を保証できず管理負担となっていた復旧GUI、CLI、サービス、修復モジュールを撤去しました。未完了録画は`failed`へ確定し、録画ファイル、失敗コード、エラー、診断を保持します。`status --json`はスキーマ版2となり、`recovery`項目を含みません。

## データ移行

SQLiteはv8へ更新します。移行前にDBバックアップを作成します。v7で旧復旧成果物だけを録画保存先内の退避領域へ移し、DB移行成功後に削除します。通常録画と同一のファイルは削除せず、移行失敗時は退避ファイルとDBを復元します。v8でシーズン、デッキ安定ID、カラー・用途フラグを追加し、既存のデッキ名と対戦記録を保持します。

詳細は[リリースノート](../release-notes.md)を参照してください。
