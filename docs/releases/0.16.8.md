# master-duel-recorder-lite v0.16.8

手動録画の開始処理中にGUIがWindowsから「応答なし」と判定される問題を修正するリリースです。

## 主な修正

- 環境診断、対象再取得、FFmpeg準備をサービスロック外で実行
- GUIのバックグラウンド操作中は同期状態ポーリングを停止
- 開始中の二重開始、自動監視、停止、終了を安全に拒否
- 開始失敗後の再試行を保証

録画形式、判定条件、設定、既存録画、履歴DBは変更しません。

6秒遅延する実Tk GUI試験で100ミリ秒間隔の処理が60回継続し、5.5秒時点のWindows `IsHungAppWindow`がfalseであることを確認しました。
