# V2.4.1: PySide6 UI情報設計Hotfix

## 概要

V2.4.1では、PySide6通常GUIの画面責務を整理し、日常操作に不要な内部処理表示を主要導線から外した。テンプレート画面は投稿テンプレート編集へ絞り、信頼性確認は設定内の「録画診断・信頼性」へ統合する。戦績管理フィルターは1.x相当の主要条件を実クエリへ接続する。DB schema、設定形式、録画処理、YouTube投稿処理、queue、manifest、OAuth資格情報は変更しない。

## 変更点

- テンプレート画面からMP4準備一覧、準備一覧更新、選択録画をMP4準備へ追加、バックグラウンド処理表示を外した。
- YouTube投稿導線では、動画形式の準備を投稿時の内部処理として扱う説明へ変更した。
- 主要ナビから信頼性を外し、設定内の「録画診断・信頼性」タブへ統合した。
- 録画画面から設定内の録画診断へ移動する導線を追加した。
- 録画画面の開催中シーズン表示と左下ステータスを短い状態名へ整理した。
- 設定の「表示」タブを「戦績表示設定」へ変更し、色設定の対象名を日本語化した。
- デッキ名、タグ、戦績表示設定のカラー表示をスウォッチ基準へ統一した。
- 戦績管理フィルターで、期間、シーズン、デッキ、タグ、コイン、登録元を一覧クエリへ反映した。
- 保存済み条件を選択した場合は既存条件をクエリへ変換し、複数タグ条件も保存済み条件経由で復旧できるようにした。
- カタログ系テーブルの高さを安定させ、選択や更新で不自然に拡大しない契約を追加した。
- GUI smoke contract、README、設計文書、リリースノート、バージョン情報をV2.4.1へ更新した。
