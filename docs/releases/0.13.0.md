# master-duel-recorder-lite v0.13.0

録画履歴からローカル動画を再生し、保存場所を開けるようにしたリリースです。

## GUI

「録画履歴」で録画を選択し、「再生」または「保存場所を開く」を実行します。履歴行のダブルクリックでもWindows既定プレイヤーを起動できます。

## CLI

```powershell
.\master-duel-recorder-lite.exe history play RECORDING_ID
.\master-duel-recorder-lite.exe history reveal RECORDING_ID
```

録画保存領域外、欠損、空、未対応形式のファイルは開きません。録画、履歴DB、設定、その他の`user_data/`を変更しない読み取り操作です。
