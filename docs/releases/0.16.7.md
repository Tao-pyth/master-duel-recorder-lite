# master-duel-recorder-lite v0.16.7

Windows GUIから録画を開始した際に、録画用FFmpegのコマンドプロンプトが表示される問題を修正するリリースです。

## 主な修正

- 長時間録画用FFmpegを`CREATE_NO_WINDOW`で起動
- Windows重大エラーダイアログの抑止を録画経路へ適用
- GUIとCLIの手動録画を画面イベント判定から分離
- 手動録画から同一ウィンドウに対する判定用FFmpegの追加取得を排除
- 手動録画開始時にMaster Duelウィンドウを再取得
- FFmpegの標準入力による正常停止と標準エラー収集を維持
- Windows以外では従来の起動動作を維持

SmartScreenやUACの確認画面はWindowsのセキュリティ機能であるため、本変更の対象外です。録画形式、設定、既存録画、履歴DBは変更しません。

実Master Duelウィンドウをパッケージ版CLIで3秒手動録画し、判定処理0・破棄0、43,543 bytes、終了コード0を確認しました。
