# V1.4.2: 更新EXE起動検証とOAuth診断hotfix

V1.4.2では、V1.4.1検証で見つかった更新後GUI EXEの起動失敗リスクと、YouTube OAuth token交換HTTP 400の原因が利用者に伝わらない問題を修正します。配布ビルドには新しいYouTube OAuth `client_id`だけを同梱し、`client_secret`やtoken類は引き続き保存、同梱、ログ出力しません。

## 主な変更

- アプリ更新で取得したGUI EXEを、置換前に隔離した`LOCALAPPDATA`で起動スモーク
- 起動スモーク失敗、スモーク結果なし、期待バージョン不一致、実行時データ作成を更新適用前に拒否
- GitHub Release公開後、公開済みCLI/GUI assetを再ダウンロードしてスモーク
- YouTube OAuth token交換HTTP 400のGoogle応答本文を読み取り、秘匿済み診断と原因別の確認事項を表示
- V1.4.2 releaseビルドへ新しいYouTube OAuth `client_id`だけを同梱

## 検証

- `python -m ruff check .`
- `python -m unittest discover -s tests`
- `python -m master_duel_recorder_lite --version`
- `python -m master_duel_recorder_lite.gui --smoke-test --smoke-output build\gui-smoke-1.4.2.json`
- `python scripts\verify_release_tag.py v1.4.2`
- `python scripts\build_windows_exe.py --require-youtube-oauth-client`
- `scripts\smoke_windows_exe.ps1 -ExePath dist\master-duel-recorder-lite.exe -ExpectedVersion 1.4.2`
- `scripts\smoke_windows_gui.ps1 -ExePath dist\master-duel-recorder-lite-gui.exe -ExpectedVersion 1.4.2`
- 更新取得後のGUI EXE事前スモーク
- OAuth asset安全性確認、`client_id`のみ同梱し、`client_secret`とtoken類を含めない

## 外部検証

- 実YouTube private投稿E2Eは、V1.4.2正式更新で配布EXEを取得した後に、ユーザーのGoogleアカウントと配布者管理OAuth Clientを使って確認します
- OAuth同意画面、テストユーザー、redirect URI、API有効化の制約で失敗した場合は、V1.4.2の追跡Issueに表示診断と結果を記録します
