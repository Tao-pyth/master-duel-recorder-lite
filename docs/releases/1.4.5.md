# V1.4.5: YouTube OAuth資格情報ストアhotfix

V1.4.5では、V1.4.4配布EXEでYouTube OAuth認可は完了するものの、保存済み資格情報をEXE側が読めずにGUIの`接続確認`や投稿ダイアログが未連携扱いになる問題を修正します。ユーザー操作は増やさず、Windows資格情報ストアに保存したOAuth資格情報をCLI/GUIの同じ経路で読めるようにします。

## 対象Issue

- #466: 配布EXEからYouTube OAuth資格情報ストアを確実に読み書きする

## 変更内容

- `WindowsCredentialStore`をWindows Credential APIの直接呼び出しへ変更
- PyInstaller EXEで`win32cred`の読み取り・削除失敗が未連携や削除成功として隠れないよう修正
- 資格情報が存在しない状態、Windows API失敗、保存済みJSON不正を区別
- 既存のUTF-16 CredentialBlobと新規UTF-8保存の両方を読める互換性を維持
- CLI EXEスモークへ、隔離したCredential targetでのYouTube OAuth資格情報読み取り・削除検証を追加
- README、アップロード準備設計、Windows EXE配布設計、リリースノートをV1.4.5へ更新
