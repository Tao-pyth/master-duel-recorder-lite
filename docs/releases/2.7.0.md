# V2.7.0: 視覚タイムラインMVP

V2.7.0では、アプリ内レビュー画面に視覚タイムラインMVPを追加した。録画内の現在位置、選択位置、重要イベントを動画の流れに沿って把握し、重要場面へすばやく移動できるようにする。

## 変更内容

- レビューViewModelへ、既存タイムラインから作る視覚タイムライン表示データを追加した。
- PySide6レビュー画面に `review_visual_timeline` Widgetを追加した。
- 視覚タイムライン上のイベント選択を既存の動画シークへ接続した。
- 表形式タイムライン選択時に、視覚タイムライン側の選択位置も更新するようにした。
- 再生中またはシーク後の現在位置を、視覚タイムライン上へ反映するようにした。
- `duel_start`、手動マーカー、候補イベント、通常イベントの表示種別を分けた。
- 録画長不明、イベントなし、範囲外イベント、Qt Multimedia fallback時も保存データを変更しない。

## 互換性

- SQLite schema、設定形式、既存録画ファイル、YouTube投稿履歴、OAuth資格情報、queue、manifestは変更しない。
- 既存の動画再生、表形式タイムライン、現在位置マーカー、選択位置中心のクリップ出力は維持する。
- クリップ範囲エディタ、波形/サムネイル、長時間バックグラウンド録画、任意クリップ保存、直接アップロード、OAuth連携は対象外とする。
