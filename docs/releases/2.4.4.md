# V2.4.4: レビュークリップ出力とRelease検証Hotfix

V2.4.4では、レビュー画面の「選択位置をクリップ出力」でFFmpegが一時出力ファイルの形式を判定できず失敗する問題を修正し、Release asset検証をGitHub Actions認証に対応させた。

## 変更内容

- `ClipExportService` がFFmpegへ渡す一時出力ファイル名を `.partial.mp4` 形式に変更した。
- FFmpegへ渡す出力パスが `.mp4` 末尾になることを回帰テストで固定した。
- Release asset検証スクリプトが `GITHUB_TOKEN` / `GH_TOKEN` を使ってGitHub APIを読むようにした。
- 最終出力ファイル名、元録画非破壊、成功時だけ最終ファイルへ置換する契約を維持した。

## 互換性

- SQLite schema、設定形式、録画ファイル、YouTube投稿履歴、OAuth資格情報、prepare queue、manifestは変更しない。
- Review画面とCLIのクリップ出力入口は変更しない。
