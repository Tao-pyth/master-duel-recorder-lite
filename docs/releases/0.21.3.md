# master-duel-recorder-lite v0.21.3

V0.21.3は、V0.22.0からV0.25.0までの開発計画とGitHub追跡単位を確定する計画更新リリースです。

## 主な変更

- V0.22.0「戦績入力体験」の実装順と完了条件を策定
- V0.23.0「自動監視信頼性」の状態機械、評価、診断、通知、実戦検証を策定
- V0.24.0「データ保全」のバックアップ、復元、診断、再関連付け、重複検出を策定
- V0.25.0「シーズンレポート」の比較分析、推移、振り返り、HTML出力を策定
- Milestone 44 - 47、Issue #276 - #327、対応バージョンラベルを登録
- 詳細実装計画書とロードマップ、README、運用文書を更新

本版では次期機能の実装を行わず、V0.21.2の機能動作を維持します。V1.0.0には更新していません。
