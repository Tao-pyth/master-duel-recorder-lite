# V2.1.1: PySide6 rich UI回帰修正

Release date: 2026-08-23

## 概要

V2.1.1では、V2.1.0公開後のPySide6 GUIが初期・簡略UIへ戻っていた回帰を修正した。新機能追加ではなく、`docs/assets/tkinter-ui-baseline-1.5.2-rich` を基準に、画面構成、情報量、操作導線、状態表示を復旧するFixである。

## 変更内容

- 録画画面に、録画対象、録画状態、経過表示、録画なし戦績追加、環境診断、アクティビティを同じ操作面へ戻した。
- 戦績管理に、ツールバー、フィルター、10列の履歴一覧、YouTube投稿導線を戻した。
- 統計に、全体勝率、条件適用後、先後別サマリー、条件、タブ付き集計表を戻した。
- デッキ名、タグ、シーズン、テンプレート、信頼性、設定を、rich baseline相当の編集フォーム、表、状態表示、タブ構成へ戻した。
- MP4準備と改善を内部ページとして保持し、smoke contractから確認できるようにした。
- PySide6 smoke contractへrich baseline画像11件、rich UI section、内部ページを確認する項目を追加した。

## 非変更

- SQLite schemaは変更しない。
- 設定形式は変更しない。
- 録画ファイル、queue、manifest、OAuth資格情報は削除、初期化、形式変更しない。
- OBS Plugin / OBS WebSocket依存は追加しない。
- Tkinter互換モジュールは削除しない。

## 検証

- Ruff: 合格
- 重点テスト: 合格
- PySide6 GUI smoke: 合格
- 全単体テスト: 587 collected、584 passed、3 skipped
- スクリーンショット比較: `build/pyside-rich-smoke.png` を確認し、録画対象、録画状態、録画なし戦績追加、環境診断、アクティビティが初期表示内に復旧していることを確認した
