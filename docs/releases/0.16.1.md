# master-duel-recorder-lite v0.16.1

初回起動時のFFmpeg導入と、EXE配置フォルダから実行時データを分離する修正リリースです。

## 主な変更

- FFmpeg未導入時にGUIセットアップを自動表示
- 配布元、GPLv3、URL、導入先を確認してからダウンロード
- 公開SHA-256、安全なZIP展開、FFmpeg・ffprobe起動の検証
- 管理対象FFmpegを`%LOCALAPPDATA%\MasterDuelRecorderLite\tools\ffmpeg`へ導入
- EXEの既定データ保存先を`%LOCALAPPDATA%\MasterDuelRecorderLite`へ変更
- FFmpeg探索タイムアウトを15秒へ延長
- LocalAppData分離とEXE隣接フォルダ非生成の実EXE回帰テスト

V0.16.0以前のEXE隣接`user_data/`は自動移動も削除もしません。既存データを継続利用する場合は、バックアップ後に新しい既定先へ移すか、`MDRL_USER_DATA_DIR`または`--user-data-dir`で旧フォルダを明示してください。
