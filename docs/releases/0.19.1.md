# master-duel-recorder-lite v0.19.1

V0.19.1は、V0.19.0のシーズン管理を基盤に、GUIの一貫性とローカル管理データの運用を改善するFixリリースです。

## 主な変更

- 主要画面の入力欄、プルダウン、文字・アイコンボタンの高さと配色を統一
- 録画履歴へデッキ名とデッキカラー指標を追加し、音声列を廃止
- シーズンの直接入力、日本語種別、カラー指標、専用レポート画面を追加
- 履歴・デッキ・タグ・シーズンのJSON入出力を追加
- 二段階確認とSQLiteバックアップを伴う対象別初期化を追加

管理データJSONには録画ファイル本体を含みません。履歴初期化も録画ファイルを削除しません。インポートと初期化の前には、`user_data/data/exports/`へSQLiteバックアップを作成します。

V1.0.0には更新していません。
