# V1.1.0: YouTube公式連携 + MP4自動アップロード

V1.1.0では、既存のMP4準備を再利用するYouTube公式連携を追加しました。OAuth資格情報はOS資格情報ストアだけに保存し、設定、manifest、queue、標準出力、ログへ保存しません。

## 主な変更

- `mdrl youtube connect/account/disconnect`を追加
- `mdrl youtube upload RECORDING_ID --title TITLE`、`upload run/list/show`を追加
- 履歴DB V15の`youtube_uploads`で投稿状態、試行回数、失敗理由、動画ID、視聴URLを保存
- `history list/show`で完了済みYouTube投稿URLを表示
- `private`既定を維持したまま、明示指定の`public`投稿に対応
- 概要欄テンプレート、投稿素材チェックリスト、投稿用クリップ出力を追加
- fake clientで成功、再試行、OAuth未接続時の失敗保存を検証
