# master-duel-recorder-lite v0.25.0

V0.25.0は、シーズンごとの結果を比較・分析し、利用者自身の振り返りと持ち運べるレポートへつなぐ「シーズンレポート」リリース候補です。

## 主な変更

- 統計ページと母集団を共有するシーズン期間レポート
- 同種別の直前シーズンと任意シーズンの比較
- デッキ別の全体・先攻・後攻・未設定クロス集計
- コイン表裏、先後、最終勝敗の独立内訳
- 重複していたコイントス勝敗項目の完全撤去とDBスキーマv13移行
- 空期間を含む日・週推移と使用デッキ比率
- 10戦未満の少数標本表示
- 目標、良かった点、課題、次期方針と既存メモの競合安全な保存
- 振り返り確認後の明示アーカイブ
- 外部依存なしの印刷可能な単一HTML出力

## 公開条件

Ruff、単体・統合テスト424件、HTML検証、2026-08-15の実戦誤判定修正後のCLI/GUI EXEビルドと両スモークはローカルで通過しました。Windows CIを通過し、V0.23.0とV0.24.0が順に公開済みであることが残る公開条件です。未達の間、この文書はRelease候補説明であり、GitHub Releaseは公開しません。

自動録画中の経過時間は、候補録画を開始したFFmpegセッションの開始時刻を起点に500msごとに更新します。監視停止による録画終了は数値診断と実戦集計CLIで中断試行として結果検出停止・検出失敗から区別します。待機中の二重待機を除去し、実効fpsは保存間引き前の全解析フレームから算出します。
