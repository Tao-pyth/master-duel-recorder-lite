# master-duel-recorder-lite v0.25.0

V0.25.0は、シーズンごとの結果を比較・分析し、利用者自身の振り返りと持ち運べるレポートへつなぐ「シーズンレポート」リリース候補です。

## 主な変更

- 統計ページと母集団を共有するシーズン期間レポート
- 同種別の直前シーズンと任意シーズンの比較
- デッキ別の全体・先攻・後攻・未設定クロス集計
- コイン表裏、先後、最終勝敗の独立内訳
- 重複していたコイントス勝敗項目の完全撤去とDBスキーマv13移行
- 空期間を含む日・週推移と使用デッキ比率
- 10戦未満の少数標本表示
- 目標、良かった点、課題、次期方針と既存メモの競合安全な保存
- 振り返り確認後の明示アーカイブ
- 外部依存なしの印刷可能な単一HTML出力

## 公開条件

Ruff、単体・統合テスト436件、HTML検証、CLI/GUI EXEビルドと両スモークはローカルで通過しました。fix340本検証で確認した召喚カットインのLOSE誤認を修正し、同じ1セッション12録画の全編2fps再生で正規結果11/11、偽陽性0/1、Precision/Recall 1.000を確認しました。追加の実戦ログは要求せず、この全編再生を正式な代替ゲートとします。push後のWindows CI、V0.23.0とV0.24.0の順序付き公開が残る条件です。未達の間、この文書はRelease候補説明であり、GitHub Releaseは公開しません。

自動録画中の経過時間は、候補録画を開始したFFmpegセッションの開始時刻を起点に500msごとに更新します。監視停止による録画終了は数値診断と実戦集計CLIで中断試行として結果検出停止・検出失敗から区別します。待機中の二重待機を除去し、実効fpsは保存間引き前の全解析フレームから算出します。

攻撃演出対策の4/5合意は維持しつつ、高特異度のウルトラワイド下段LOSEだけ短時間表示を許可します。現存する有効11戦・負例3本はサイズとSHA-256を固定した正式な超横長回帰コーパスです。追加した1920x1080ウィンドウ4本から標準16:9の正規LOSE見逃しを修正し、2fps全区間評価は超横長の開始・盤面・結果11/11、標準16:9の同イベント2/2、全負例の厳格イベント誤検出0です。16:9のコイントス、リプレイ、マッチエラー実動画は未評価です。

結果見逃し時に次対戦開始を境界として停止した場合は、境界候補を次録画へ即時引き継ぎます。境界時のスコア、合意、引継ぎ時間は数値診断へ残し、実戦集計では前対戦の結果見逃しと次対戦の開始成功を別々に評価します。
