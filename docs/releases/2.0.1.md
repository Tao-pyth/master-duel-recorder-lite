# V2.0.1 リリースメモ

## 概要

V2.0.1は、V2.0.0更新後に既存DB表示とGUI操作面が失われたように見える問題を復旧するhotfixです。通常配布GUI入口を1.x相当のTkinter GUIへ戻し、PySide6はレビュー/検証入口として残します。

## 主な変更

- `master-duel-recorder-lite-gui.exe`の通常入口を`master_duel_recorder_lite.gui`へ戻す
- GUI smokeに1.x標準機能の同等性ゲートを追加
- GUI smokeに参照中のruntime dataとSQLite DBパスを出力
- 既存DB入りruntimeを`RecorderApplicationService`で再読込できる回帰テストを追加
- PySide6全面移植で必要な標準機能一覧を`docs/architecture/pyside-feature-parity-2.0.1.md`へ固定
- PySide6シェル`master_duel_recorder_lite.pyside_gui`は通常入口ではなく検証入口として残す

## 互換性

- DB schemaはV17のまま変更しません
- 設定形式を変更しません
- 録画ファイル、YouTube投稿履歴、prepare queue、manifest、ログ、OAuth資格情報を削除、初期化、形式変更しません
- 既存`user_data`は、保存先ポインタ、`MDRL_USER_DATA_DIR`、既定保存先の既存契約に従って参照します

## 検証

検証詳細は[docs/validation/2.0.1.md](../validation/2.0.1.md)を参照してください。
