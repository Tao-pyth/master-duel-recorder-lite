# master-duel-recorder-lite v0.15.0

録画IDへ対戦イベントを関連付け、GUIとCLIから確認・操作できる対戦タイムライン基盤リリースです。

## 主な変更

- 対戦開始、ターン切り替え、対戦結果、手動マーカーのSQLite保存
- 候補、確定、却下の非削除状態管理
- 確定イベントの一意性、時系列、録画時間内制約
- 検出器ID・版・信頼度を保持する自動判定候補の受け入れ契約
- GUIの一覧・フィルター・マーカー追加・候補確認
- `timeline list/add/confirm/reject` CLIとJSON出力

既存の録画ファイルと対戦記録は変更しません。履歴DBは移行前バックアップを作成します。
