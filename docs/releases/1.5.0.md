# V1.5.0 リリースメモ

## 概要

V1.5.0は、Tkinter GUIを維持しながらPySide6レビュー画面を安全に検証するための基盤リリースです。DB schemaや設定形式を変更せず、既存の録画履歴、対戦記録、タイムライン、YouTube投稿履歴からレビュー用ViewModelを生成します。

## 主な変更

- GUI境界と保存契約を文書化
- Review ViewModel/DTOを追加
- `mdrl review show/status/launch`を追加
- PySide6レビュー画面を`pyside_review.py`へ隔離
- Tkinter GUIから別プロセスでレビュー画面を開く導線を追加
- 起動失敗時のWindows既定プレイヤーfallbackを追加
- PySide6を`review` extra、配布用`build` extraへ追加

## 互換性

- DB schemaはV17のまま変更しません
- `app.toml`の設定形式は変更しません
- 録画ファイル、exports、queue、manifest、ログの既存形式を維持します
- YouTube OAuth資格情報はOS資格情報ストアだけに保存する既存契約を維持します

## 既知制約

- PySide6レビューは限定導線です。全GUI移行ではありません
- Qt Multimediaの動画再生可否はWindows環境のコーデックとQt pluginに依存します
- 再生できない場合は`--fallback-external`または既存の録画再生ボタンでWindows既定プレイヤーを使用します
- 実動画を使った再生・シーク・マーカー・クリップ出力の手動確認はWindows配布物で行います
