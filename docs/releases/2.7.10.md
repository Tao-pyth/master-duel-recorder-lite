# V2.7.10

Preserve the selected audio input during discovery and validate settings batches as a whole before saving.

候補の再検索で選択が変わらず、有効な音声設定を一度の保存で反映できる修正版です。

## V2.7.10: 音声入力の選択保持と設定保存の修正 - 2026-09-09

- 音声候補更新時に選択中の入力と未保存状態を保持する。未検出の入力は保持して案内し、重複候補をまとめる
- 設定を全項目反映後に検証し、音声モードと入力を編集順序に依存せず保存する
- 未知キーや無効な値は保存前に拒否する。設定形式、DB、録音方式は変更しない
- 追跡: Issue #639、#640 / Milestone V2.7.10。[公開状態](https://github.com/Tao-pyth/master-duel-recorder-lite/releases/tag/v2.7.10)
