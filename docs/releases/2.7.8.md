# V2.7.8: 録画画面の表示崩れ修正

The recording page now scrolls when the window is too short, keeping recording controls, status text, and diagnostic rows readable. Recording behavior and stored data formats are unchanged.

小さい画面でも内容を潰さず、スクロールして操作できるようにした修正版です。

## 変更内容

録画画面でウィンドウの高さが足りない場合、下へスクロールして各項目を確認できるようにした。自動監視ボタンと「判定詳細」が重なる問題、録画状態帯の文字が見えなくなる問題、環境診断の行が潰れる問題を修正した。

録画開始・停止などの操作は画面上部にある。下部の診断を確認した後は上へスクロールすると戻れる。自動監視の戦績初期値は従来どおり設定できる。

## 互換性

DBや設定の移行は不要。録画、検出、初期値の開始時スナップショット、録画ファイル、queue、manifest、OAuth資格情報の扱いは変更しない。

## 検証・公開

実widgetのレイアウト回帰、Windows日本語表示、模擬100/150/200%スケール、Ruff、全631 unittest（3 skipped）、3EXEビルドとsmokeに合格した。GUI配布EXEの2.7.8表示と録画画面も確認した。

正式公開・公開asset検証の結果は、[v2.7.8 Release](https://github.com/Tao-pyth/master-duel-recorder-lite/releases/tag/v2.7.8)と、そのタグを対象とする[Windows EXE release workflow](https://github.com/Tao-pyth/master-duel-recorder-lite/actions/workflows/windows-release.yml)で追跡する。workflowは公開後のSHA256照合とダウンロード後3EXE smokeまで実行する。

詳細: [検証記録](../validation/2.7.8.md)。
