# master-duel-recorder-lite v0.16.0

Master Duel録画中に対戦開始、ターン切り替え、勝敗・対戦終了を未確認候補として記録する基本イベント自動判定リリースです。

## 主な変更

- 最大2fps、単一フレーム処理、遅延時破棄の専用ワーカー
- FFmpeg終了コード`-5`（DWORD `4294967291`）を生じる`hwnd=`入力から、対応する`title=`入力への修正
- 16:9正規化とオフラインROI特徴バックエンド
- 開始・ターン・結果の個別検出器
- 複数フレーム合意、0.70閾値、クールダウン、状態遷移
- 検出器ID・版・信頼度・理由付き`candidate`保存
- GUIの判定状態、候補件数、信頼度、確認・却下
- 設定、preflight、合成画像テスト、実画面チェックリスト

画像解析に失敗しても録画は継続します。候補は自動確定されず、ゲーム画像は保存されません。
