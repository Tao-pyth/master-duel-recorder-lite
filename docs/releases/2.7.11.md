# V2.7.11

Connect the PySide6 season report to detailed read-only statistics and HTML export. Rebuild the selected report before saving and require confirmation before overwriting an existing file.

シーズンの集計を詳しく確認し、HTMLへ保存できるようにしました。元の戦績や保存済みメモを書き換えず、既存の集計処理を利用しています。

## V2.7.11: シーズンレポートの詳細閲覧とHTML保存 - 2026-09-10

- シーズンの「レポート」から、概要・既定比較・保存済みメモ・内訳・日別/週別推移を閲覧できる
- HTML保存時にも同じシーズンを再集計し、表示と出力の内容を合わせる
- 保存先を指定し、既存ファイルは上書きを確認する。取消や失敗を成功として扱わない
- 集計式、DB/設定形式、録画方式は維持。比較対象の選択、メモ編集、他画面の入口は今回の範囲外
- 追跡: Issue #641、Milestone V2.7.11。[Release](https://github.com/Tao-pyth/master-duel-recorder-lite/releases/tag/v2.7.11)
