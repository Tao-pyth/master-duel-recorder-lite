# V2.7.20の操作と変更

YouTube認証失敗からの復旧操作を修正し、相手デッキ×自分デッキごとの勝率を確認する「デッキ相性」を追加しました。[正式配布](https://github.com/Tao-pyth/master-duel-recorder-lite/releases/tag/v2.7.20)からGUI版を取得するか、アプリの更新確認を使ってください。

起動中の旧版を閉じてから更新します。既存戦績・録画の保存先やDB/設定形式は変わらず、データ移行は不要です。

## YouTube投稿に「再連携」が必要と表示された場合

1. 「設定」の「YouTube」を開きます。
2. 「連携する」を押し、開いたブラウザでGoogleへログインしてYouTubeへの投稿を許可します。
3. アプリの連携完了表示を確認してから、戦績管理で対象動画の投稿を再試行します。

先に「切断する」を押す必要はありません。認証が失敗した場合も、以前の資格情報や準備済みのMP4は保持されます。認証中は連携・切断等の競合する操作を一時的に無効にします。

V2.7.19以前では、認証情報の失効を「入力内容を確認」と表示し、PySide6の「連携する」も認証処理を開始していませんでした。V2.7.20は失敗の種類に合った案内と、実際に認証を開始する処理を追加します。

連携情報が保存されていることと、Googleで今も有効なことは異なります。有効性は投稿時に確認します。実投稿の成功には、Google側で有効な認証・投稿権限・API利用枠が必要です。

## 相手と自分のデッキの組合せごとに勝率を見る

「統計」の「デッキ相性」を開きます。相手デッキと自分デッキが別列になり、それぞれの組合せについて対戦数・勝利数・敗北数・引分数・自分勝率を表示します。

勝率は「自分が勝った数 ÷ 勝ち・負け・引き分けの合計」です。たとえば自分の同じデッキで相手Aに3勝1敗なら75%、相手Bに1勝2敗1分なら25%となり、別々の行で比較できます。

上部の期間と対戦種別を変更すると、組合せ別の集計も変わります。デッキ未設定は「未設定」として表示し、対象0件の場合は空状態を表示します。対戦数が少ない行は、その件数も見て判断してください。

既存戦績から読み取りで集計するため、戦績の再登録やデータ移行は不要です。追跡: #658 / #659、正式公開・配布検証: #660。

## 検証と残る確認

ローカル自動テスト686件（失敗0、skip3）、Ruff、Windows日本語画面と3EXE build/smokeを確認しました。正式配布は既存Windows Release workflowで再ビルドし、公開hashと再取得3EXEの動作を検証します。

実際のGoogle再認証と動画投稿はユーザー本人の操作が必要です。実投稿成功は今回のテストでは確認していません。
