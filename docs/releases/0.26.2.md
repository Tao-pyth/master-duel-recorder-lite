# master-duel-recorder-lite v0.26.2

V0.26.2は、V1.0.0移行前に管理情報、文書、検証証拠、配布品質を整合するReleaseです。V0.26.1までの製品機能とデータ形式は変更しません。

## 主な変更

- 仕様変更後に残ったIssue・Milestoneを現行仕様へ整合
- 公開済みロードマップと検証記録の状態を修正
- V1.0.0判断範囲と既知制約を明文化
- 空の実行時ルートによる最終クリーン環境E2Eを追加

## 注意

V1.0.0への更新ではありません。V0.26.2の全ゲート完了後も、ユーザーが明示的に「V1.0.0に変更せよ」と依頼するまで`0.x`を維持します。

## 検証

Ruff、全463テスト、実FFmpeg試験2件、CLI/GUI one-file EXEビルド、両スモークに合格しました。空の実行時ルートでは初期化、戦績CRUD、CSV往復、バックアップ、整合性診断、クリーンアンインストール境界を確認しています。詳細は[検証記録](../validation/0.26.2.md)を参照してください。
