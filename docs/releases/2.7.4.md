# V2.7.4: 戦績編集とレビュー統合ワークフロー

V2.7.4では、V2.7.3公開後に確認された戦績編集、レビュー画面、クリップ出力、マーカー整理の操作課題をまとめて修正する。

## 修正内容

- 戦績管理の「一括編集」を実装し、選択済みの複数戦績に対してチェックした項目だけを反映できるようにした。
- 一括編集は対象件数と変更内容を保存前に確認する。
- 戦績編集ダイアログの自分デッキ/相手デッキを、候補付きの自由入力へ戻した。
- 戦績編集ダイアログを広くし、保存/キャンセル表記を日本語化した。
- レビュー画面に「マーカー編集」「戦績入力」タブを追加した。
- レビュー画面の戦績入力タブから、動画を見ながら戦績を保存できるようにした。
- レビュー画面で候補タイムラインイベントを確定/却下できるようにした。
- 手動マーカーは種別と説明を分けて編集できるようにした。
- 自動判定ラベルは通常のマーカー編集対象から外した。
- レビュー表では内部管理用の由来を通常列として表示しない。
- クリップ出力の範囲説明と、保存先をエクスプローラーで開く導線を追加した。
- 主要操作ボタンのアイコンを統一した線形表現へ調整した。

## 背景

V2.7.3時点では、一括編集ボタンが存在するにもかかわらず実機能が提供されていなかった。また、戦績編集のデッキ入力が候補付き自由入力ではなくなり、編集ダイアログも狭かった。レビュー画面ではマーカー、タイムライン状態、クリップ出力範囲、出力先確認の説明導線が不足していた。

ユーザー判断により、レビュー画面のタブ統合もV2.7.4に含め、V2.8.0以上へは変更しない。

## 互換性

- SQLite schemaは変更しない。
- 設定schemaは変更しない。
- 録画方式、FFmpegコマンド、保存先生成は変更しない。
- 既存録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- OBS PluginとOBS WebSocketへの依存は追加しない。
