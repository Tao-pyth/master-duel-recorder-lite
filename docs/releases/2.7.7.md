# V2.7.7: 自動監視時の戦績初期値

V2.7.7では、自動監視で連続録画する利用者が、録画後の戦績下書きへ毎回同じ自分デッキやシーズンを手入力しなくて済むようにする。

## 変更内容

- 録画画面に、自動監視用の自分デッキ、シーズン、希望先後の入力欄を追加する。
- 自動監視開始時に入力値を設定へ保存し、その監視セッションの値として固定する。
- 成功した新規自動録画で作成する戦績下書きに、自分デッキとシーズンを初期値として反映する。
- 視覚判定で検出した実際の先後を保存し、希望先後だけでは実先後を推測しない。
- 希望先後と検出先後がどちらも既知の場合だけ、希望通りなら`coin_face=heads`、希望と異なるなら`coin_face=tails`を補助入力する。
- 既存戦績がある録画IDでは、自動監視完了処理から戦績を上書きしない。

## 背景

自動監視は連続利用時に録画後モーダルを出さないため、ユーザーはあとから戦績管理で下書きを処理する。よく使うデッキや開催中シーズンが分かっていても毎回入力が必要だった。V2.7.7では、録画開始前に選んだ初期値を自動監視セッションへ固定して、録画後整理の手間を減らす。

希望先後は、Master Duel上のコイントス画像を直接認識する機能ではない。利用者の希望と検出された実際の先後を比較し、表裏の補助入力に使うだけに留める。

## 互換性

- SQLite schemaは変更しない。
- `[interaction]`設定に非シークレット項目を追加する。古い`app.toml`では既定値を補完するため手動移行は不要。
- 録画方式、FFmpegコマンド、録画保存先生成は変更しない。
- 手動録画、録画なし手動戦績、候補破棄、失敗録画、既存戦績には自動監視初期値を適用しない。
- 録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- OBS PluginとOBS WebSocketへの依存は追加しない。
