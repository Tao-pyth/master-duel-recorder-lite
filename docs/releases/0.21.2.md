# master-duel-recorder-lite v0.21.2

V0.21.2は、録画あり・なしの戦績管理をGUIで一元化し、初期画面と更新排他を改善するリリースです。

## 主な変更

- 戦績管理ページで録画あり・なしの対戦を一元表示
- 録画なし戦績の追加、対戦日時を含む後日編集、削除
- 録画有無によるフィルターと、録画なし行の録画固有操作無効化
- 初期画面への「戦績を追加」と開催中シーズン最大2件の勝率要約
- 自動監視中の新規入力禁止と、既存編集の読み取り専用表示
- 録画・自動監視中の戦績作成、更新、削除をサービス層でも拒否

DBはV0.21.1で導入したv10を維持します。V1.0.0には更新していません。
