# master-duel-recorder-lite v0.26.0

V0.26.0は、映像対象と独立したMaster Duel単体音声キャプチャと、スプレッドシートからの戦績CSV移行を追加するReleaseです。

## 主な変更

- Windows build 20348以上で、Master Duelプロセスツリーだけを録音するProcess Loopbackヘルパーを同梱
- 「Master Duelのみ（推奨）」「PC全体」「入力デバイス」「音声なし」を設定画面から選択・テスト
- 自動監視中の音声事前待機、PID変更への追従、音声障害時の映像継続と診断
- 無音区間のPCM補完、偶数映像寸法、リアルタイムエンコード、非同期停止による安定したA/V同期
- 固定11列、UTF-8 BOM、CRLFの戦績CSV出力・取込・サンプル出力
- 取込前プレビュー、未知ID再附番、未登録マスタ作成、適用前バックアップ、全件ロールバック
- 取込戦績を登録元「取込」として戦績管理へ統合

## 制約

- プロセス単体音声はWindows build 20348未満では利用できません
- マイクとゲーム音声の同時ミックスは対象外です
- CSVは戦績移行用で、録画、設定、タイムラインを含む完全バックアップではありません
- タグセルはカンマ区切りのため、タグ名自体にカンマは使用できません

## 検証

自動テスト、Windowsネイティブビルド、CLI/GUI EXEスモーク、実機音声分離、30分A/V同期の結果は[検証記録](../validation/0.26.0.md)を参照してください。
