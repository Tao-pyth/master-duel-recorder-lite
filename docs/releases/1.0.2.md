# master-duel-recorder-lite v1.0.2

V1.0.2は、戦績入力の連続処理、一括編集、戦績管理一覧の操作と表示を改善するFix Releaseです。

## 主な変更

- 未完了戦績の連続処理画面へ簡易入力を統合
- 詳細入力の保存・キャンセル後に未完了戦績の連続処理へ復帰
- 一括編集でコイントスの表、裏、未設定をまとめて更新可能に変更
- 戦績管理一覧のダブルクリック動作を「録画再生」または「戦績編集」から選択可能に変更
- 戦績管理一覧の任意列へ「相手デッキ」を追加。初期状態では非表示

## データ保護

DBスキーマは変更しません。既存の`ui-preferences.json`に新しい表示列やダブルクリック設定がなくても、既定値を補完して起動します。相手デッキは既存の対戦記録データを表示するだけで、録画、戦績、SQLite DBを移行しません。

## 検証

Ruff、全474テスト、CLI/GUI one-file EXEビルド、両スモークに合格しました。詳細とローカルSHA-256は[検証記録](../validation/1.0.2.md)を参照してください。
