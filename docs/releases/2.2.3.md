# V2.2.3: 戦績管理ハブ実操作Hotfix

Release date: 2026-08-23

## 概要

V2.2.3では、V2.2.2後に報告されたPySide6戦績管理画面の実操作品質を修正した。主要ボタンがクリック後に反応しないように見える状態、一覧セルへ内部コードが英字で出る状態、期間指定がカレンダーピックになっていない状態、操作種別の見分けにくさをHotfix範囲で改善した。

## 変更内容

- 戦績管理の主要ボタンを、実処理、確認ダイアログ、または明確な案内へ接続した。
- 再生、編集、削除、YouTube投稿など行選択が必要な操作は、未選択時に無効化し、選択時に有効化する。
- 削除は危険操作として表示を分け、確認ダイアログで同意した場合だけ削除処理へ進む。
- 戦績管理一覧の勝敗、先後、コイン、対戦種別、登録元を日本語表示へ変換した。
- 期間フィルターに、カレンダーポップアップ付きの開始日・終了日入力と解除操作を追加した。
- ツールバーの主要操作、補助操作、アイコン操作、危険操作をスタイルとツールチップで区別した。
- GUI smoke contractと回帰テストへ、ボタン接続、選択状態、日本語表示、日付ピッカー欠落を検出する契約を追加した。
- Release workflowで個別`.sha256`に加え、`SHA256SUMS-v2.2.3.txt`も公開するようにした。

## 非変更

- SQLite schemaは変更しない。
- 設定形式は変更しない。
- 録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- 戦績管理以外の大規模UI再設計は行わない。
