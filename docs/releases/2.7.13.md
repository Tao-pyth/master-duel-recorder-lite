# V2.7.13 — デッキ名・タグ・シーズンの一覧と右側編集

## Changes

Unify deck, tag and season management around a searchable list and a right-side editor. Separate creating a new entry from updating a selected entry. Preserve unsaved input through navigation and save failures, and keep existing catalog settings, season archiving and report access available.

## 初心者向けの説明

3ページとも左で対象を探し、右で内容を入力して保存する構成になりました。新規ボタンは入力欄を開き、保存時に登録します。編集中に行やページを変える場合は保存・破棄・取消を確認します。

- デッキの用途と履歴・統計の表示設定、タグのデッキ専用設定、色を維持します。
- シーズンの期間・種別・アーカイブ・レポート/HTML保存を引き続き使えます。
- 保存失敗や日付エラーでも入力が残ります。データ移行は不要です。

[操作説明](../architecture/pyside-catalog-editors.md)。追跡: #645、#646、#647。

CLI・GUI・updaterのWindows EXEとSHA-256を配布します。正式公開の検証結果はGitHub ActionsとReleaseを正本とします。
