# V2.3.0: PySide6 UI実操作回復

Release date: 2026-08-25

## 概要

V2.3.0では、V2.2.3時点で残っていたPySide6 GUIのユーザビリティ低下を修正した。固定表示になっていた左下ステータスと開催中シーズン、編集できないデッキ名・タグ・シーズン、反応しない信頼性画面、責務が混ざっていたテンプレート画面を、既存サービス層へ接続し直した。

## 変更内容

- 左下ステータスを `diagnose()` の結果へ接続し、固定「要確認」をやめた。
- 録画画面の開催中シーズンを `active_season_summaries()` から表示するようにした。
- デッキ名とタグは、一覧選択からフォームへ反映し、追加、保存、削除を実行できる。
- シーズンは、一覧選択、追加、保存、アーカイブ、レポート表示を実行できる。
- テンプレート画面から接続、切断、更新、privateテストを外し、YouTube接続管理は設定画面へ集約した。
- 信頼性画面の状態更新、初回導入確認をクリック後に結果表示するようにした。
- YouTube投稿はバックグラウンド実行し、処理中、完了、失敗をUIに戻す。
- ボタン、入力、プルダウン、日付入力の最小高さを36pxへ揃えた。
- カラー列は色コード文字を主要表示にせず、スウォッチと短いラベルで表示する。
- PySide6 smoke contractと回帰テストへ、今回の未接続・固定表示・編集不能を検出する契約を追加した。

## 非変更

- SQLite schemaは変更しない。
- 設定形式は変更しない。
- 録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- DADSのWebコンポーネントをQtへ完全移植しない。
- YouTubeアップロードの永続ジョブ管理、キャンセル、詳細再試行ポリシーは追加しない。
- GitHub Issue/Milestone操作はこのリリースでは行わない。
