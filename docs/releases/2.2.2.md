# V2.2.2: 設定画面・アプリ更新Hotfix

Release date: 2026-08-23

## 概要

V2.2.2では、V2.2.1で不足していたPySide6設定画面の機能入口をV1.x時期の構成に近い密度へ戻し、アプリ更新タブを状態表示と実行可能条件つきの操作へ復旧した。

## 変更内容

- 録画設定に、FFmpeg、音声モード/入力、録画品質、出力サイズ、自動開始/停止、自動判定、Windows通知、保存先、保存/再読込を配置した。
- YouTube連携に、状態、scope、接続、切断、接続確認、privateテスト投稿入口を配置した。
- 管理データに、書き出し、読み込み、履歴/デッキ/タグ/シーズン初期化、バックアップ、復元、整合性診断を配置した。
- CSV入出力と表示設定に、CSV書き出し/取り込み/サンプル保存、表示色、ダブルクリック動作を配置した。
- アプリ更新タブに、現在バージョン、確認中、最新、更新候補あり、確認失敗の状態表示を追加した。
- 更新候補がある場合だけ「ダウンロードして更新」を有効化する。
- GUI smokeとWindows GUI EXE smokeへ、設定画面復旧契約と更新タブ状態契約を追加した。

## 非変更

- SQLite schemaは変更しない。
- 設定形式は変更しない。
- 録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- Runtime data保存先移行はHotfixでは実行しない。

## 検証

- Ruff: `python -m ruff check .` 合格
- 全テスト: `python -m pytest` 合格
- UI確認: `build/v2.2.2-settings-smoke.png` と `docs/assets/tkinter-ui-baseline-1.5.2-rich/09-settings-rich.png` を比較し、V1.x相当の設定カテゴリと更新タブ状態契約を確認
- EXEビルド: `python scripts/build_windows_exe.py` 合格
- EXEスモーク: CLI/GUI/updater 3本すべて `2.2.2` として起動確認済み
- 公開Release asset検証: `python scripts/verify_release_assets.py v2.2.2` 合格
