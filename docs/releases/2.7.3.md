# V2.7.3: 自動監視開始直後停止不能Hotfix

V2.7.3では、V2.7.2実機検証で確認した、自動監視開始直後に停止できない問題を修正する。

## 修正内容

- `watch_starting`中に自動監視停止を許可するようにした。
- `watch_starting -> stopping -> idle`の状態遷移を正規の停止経路として扱うようにした。
- PySide6録画画面で、自動監視開始中でも停止ボタンと自動監視停止ボタンが使えるようにした。
- `stop_watch()`を自動監視開始直後に呼んでも不正状態遷移にならないようにした。

## 背景

V2.7.2公開後の実機検証で、手動録画開始・停止は復旧していた。一方、自動監視開始直後は`watch_starting`状態のまま停止操作が無効になり、直接停止しても`watch_starting -> stopping`が不正遷移として失敗していた。

## 互換性

- SQLite schemaは変更しない。
- 設定schemaは変更しない。
- 録画方式、FFmpegコマンド、保存先生成は変更しない。
- 既存録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- OBS PluginとOBS WebSocketへの依存は追加しない。
