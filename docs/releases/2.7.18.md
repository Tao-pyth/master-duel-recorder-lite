# V2.7.18 — デッキ別・先攻／後攻の統計表示修正

## Changes
Fix the statistics table to show the existing deck-by-play-order breakdown instead of the combined play-order totals. Clarify the tab and column labels. Preserve filtering, summary totals, and stored data.

## 初心者向けの説明
統計の「デッキ先後別」は、各自分デッキの先攻時・後攻時の勝率を比較するための表でした。しかし画面の接続先が誤っており、全デッキを合計した先攻・後攻だけが表示されていました。

タブを「デッキ別・先攻／後攻」に改め、「青眼 先攻時」「青眼 後攻時」のようにデッキ名と先後を表示します。上部の「先後別」カードは全デッキの合計です。どちらも期間・勝敗の条件を反映します。先後やデッキが未設定の戦績は「未設定」と表示されます。

保存済み戦績の変更やデータ移行は不要です。追跡: #655。
Windows CLI・GUI・updaterと個別/集約SHA-256を配布します。正式公開の検証結果はGitHub ActionsとReleaseを正本とします。
