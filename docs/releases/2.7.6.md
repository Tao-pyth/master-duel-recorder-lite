# V2.7.6: 戦績登録後の戦績管理表自動更新

V2.7.6では、レビュー画面で戦績を保存した後、戦績管理表が手動更新なしで反映されるようにする。

## 修正内容

- レビュー画面の `戦績入力` タブで保存成功後、親の戦績管理表へ更新を通知する。
- 戦績管理の `再生` と `編集` から開いたレビュー画面で、保存完了通知を既存の表更新処理へ接続する。
- 保存失敗時は表更新通知を出さず、既存のエラー表示を維持する。
- 戦績管理表の現在フィルター条件を維持したまま再読み込みする。
- GUI contractへ、レビュー画面保存後の親表更新契約を追加する。

## 背景

V2.7.5で、録画付き戦績の編集導線はレビュー画面の `戦績入力` タブへ直接入るようになった。一方で、通常の戦績編集ダイアログは保存後に戦績管理表を更新していたのに対し、レビュー画面内の保存はレビュー画面内部だけを更新していた。そのため、保存後に戦績管理表へ戻っても手動の `更新` が必要になる可能性があった。

## 互換性

- SQLite schemaは変更しない。
- 設定schemaは変更しない。
- 録画方式、FFmpegコマンド、保存先生成は変更しない。
- 既存録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- OBS PluginとOBS WebSocketへの依存は追加しない。
