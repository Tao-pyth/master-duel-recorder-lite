# V1.3.0: 入力削減・デッキ改善・運用管理

V1.3.0では、記録済みデータを継続利用と改善行動へつなげる入口を追加しました。タグテンプレートと練習目標はDB V16で管理し、ストレージ候補と移行パックは実行時データ保護を優先します。

## 主な変更

- `mdrl improve suggest`を追加
- `mdrl improve tag-template create/list`を追加
- `mdrl improve goals create/list`を追加
- `mdrl improve deck-view`を追加
- `mdrl improve storage`を追加
- `mdrl improve migration-export`を追加
- GUIへ「改善」ページを追加
- 履歴DB V16へ`tag_templates`と`practice_goals`を追加
