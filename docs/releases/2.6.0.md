# V2.6.0: 自動録画プリロールMVP

V2.6.0では、自動録画の開始判定が揃う前の短い映像を、利用者が明示的に有効化した場合だけ録画へ含められるようにした。初回版は「自動録画限定・短秒数・上限付き」のMVPであり、長時間バックグラウンド録画や任意クリップ保存には広げない。

## 変更内容

- `[detection]` 設定へ `preroll_enabled`、`preroll_seconds`、`preroll_max_megabytes` を追加した。
- 既存設定ではプリロールを既定無効で補完し、不正な秒数や保存上限を拒否するようにした。
- PySide6設定画面の録画設定②とCLI設定管理から、プリロールの有効化、秒数、保存上限を確認・変更できるようにした。
- 自動監視中だけ `user_data/data/preroll/` 配下へ短い一時segmentを保持し、録画開始時に凍結したsegmentを本録画停止後に結合するようにした。
- 一時segmentは秒数と容量の上限で保持し、増え続けないようにした。
- プリロール結合に失敗した場合も本録画だけを保存し、失敗理由を録画診断へ残すfallbackを追加した。
- プリロールを含む録画では、開始候補 `duel_start` を録画ファイル先頭からの経過として保存するようにした。

## 互換性

- 既存設定ではプリロールは無効のままで、従来の自動録画動作を維持する。
- SQLite schema、既存録画ファイル、YouTube投稿履歴、OAuth資格情報、prepare queue、manifestは変更しない。
- 手動録画、長時間バックグラウンド録画、任意クリップ保存、OBS Plugin、OBS WebSocket連携は対象外とする。
