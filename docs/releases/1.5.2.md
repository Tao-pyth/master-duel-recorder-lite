# V1.5.2 リリースメモ

## 概要

V1.5.2は、デッキ名の利用頻度を見ながら戦績を入力・整理しやすくするFixリリースです。あわせて、V2.0.0のPySide6全面移行前に、現行Tkinter GUIの画面と要件をbaselineとして保存します。

## 主な変更

- デッキ名ごとの使用回数を、自分デッキと相手デッキの合算値として表示
- デッキ名管理画面へ「使用回数」列を追加
- デッキ名一覧と各入力候補を使用回数降順へ統一
- 戦績管理のデッキ名列を、枠線付き四角スウォッチとデッキ名の表示へ変更
- 明るいデッキ色は黒枠、暗いデッキ色は白枠にして視認性を改善
- Tkinter主要ページ、内部ページ、ポップアップ、OS標準ダイアログ導線、データ保護要件を保存

## 互換性

- DB schemaはV17のまま変更しません
- 使用回数は既存`duel_records`から毎回集計する派生値で、保存列は追加しません
- 旧データでデッキIDが欠けている場合は、既存のデッキ名文字列も利用回数の補完に使います
- 設定形式、録画ファイル、YouTube投稿履歴、OAuth資格情報、prepare queue、manifest、ログは削除、初期化、形式変更しません

## 既知制約

- 使用回数は戦績DB内の自分デッキ・相手デッキに基づくため、録画だけで戦績未入力のデータは数えません
- Tkinter UI baselineは移行前の現状記録です。文書内の課題候補はV1.5.2では修正せず、V1.6.0以降の設計やIssueで扱います
- Windows標準のファイル選択、色選択、確認ダイアログはOS側表示のため、画像ではなく呼び出し元と要件表で保存しています
