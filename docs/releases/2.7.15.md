# V2.7.15 — 一覧の自動更新とレビュー終了時の動画解放

## Changes
Refresh recording history after recording completion and update deck/tag choices after successful catalog saves while preserving unsaved edits and filters. Release media resources when a review closes or the main window exits so recordings can be deleted after review.

## 初心者向けの説明
録画が完了すると戦績一覧に自動反映されます。戦績を編集中の場合は入力を保護し、保存または破棄した後で反映します。デッキ・タグを追加すると、他画面の選択候補にも反映されます。

レビューを閉じた後に録画ファイルが使用中のままとなり、戦績を削除できない問題を修正しました。同じ録画を複数のレビューで開いている場合は、すべて閉じてから削除してください。

データ移行は不要です。DB・設定・録画方式・削除時の復元処理は維持します。追跡: #649、#650、#651。

Windows CLI・GUI・updaterと個別/集約SHA-256を配布します。正式公開の検証結果はGitHub ActionsとReleaseを正本とします。
