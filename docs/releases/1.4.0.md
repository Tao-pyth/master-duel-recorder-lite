# V1.4.0: YouTube一般配布導線

V1.4.0では、YouTube連携を開発者向けの手動認可コード入力から、一般配布に耐えるOAuth PKCE + loopback callback導線へ移行しました。GUIから接続状態確認、連携、切断、録画履歴からの投稿を行えるようにし、投稿失敗時は利用者が次に取るべき行動へ分類します。

## 主な変更

- YouTube OAuthをPKCEと`127.0.0.1:<random port>` loopback callbackへ対応
- 配布者管理OAuth Clientを使う通常導線と、開発者向け`--client-secrets` fallbackを分離
- GUI設定へ`YouTube`タブを追加
- 戦績管理の録画履歴からYouTube投稿ダイアログを開く導線を追加
- 既定公開範囲を`private`に維持し、`public`投稿では追加確認を表示
- YouTube API失敗を再認証、quota待ち、権限確認、再試行、手動確認へ分類
- secret相当値を設定、DB、queue、manifest、ログ、移行パックへ保存しない契約を維持
- DBスキーマはV16のまま変更なし
