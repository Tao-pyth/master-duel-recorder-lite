# master-duel-recorder-lite v0.24.0

V0.24.0は、長期利用する戦績・設定を検証可能な世代として保護し、問題を自動変更せず診断・解決できる「データ保全」リリース候補です。

## 主な変更

- SQLite Backup APIとSHA-256 manifestによる原子的`.mdrl-backup`
- 移行、取込、初期化、復元、再関連付け、削除前の用途別バックアップ
- 世代数・容量上限と保護世代
- 件数差分を示す復元前プレビューと失敗時ロールバック
- 設定、DB、録画参照、未登録録画の読み取り専用統合診断
- 欠損録画ファイルの検証付き再関連付け
- 日時・戦績・録画ハッシュに基づく重複候補と比較GUI
- 設定画面のバックアップ一覧・状態・作成・診断・復元操作

## 公開条件

Ruff、全単体テスト、CLI/GUI EXE、両スモーク、Windows CIを通過し、先行するV0.23.0の実動画・実戦ゲートが完了していることが必要です。未達の間、この文書はRelease候補説明であり、GitHub Releaseは公開しません。
