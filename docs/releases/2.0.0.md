# V2.0.0 リリースメモ

## 概要

V2.0.0は、通常配布GUI入口をPySide6へ切り替えるメジャーリリースです。既存のサービス層、DB、録画ファイル、設定、queue、manifest、OAuth資格情報は変更せず、GUIの起動入口と画面シェルをQtへ移行します。

## 主な変更

- `master-duel-recorder-lite-gui.exe`の入口を`master_duel_recorder_lite.pyside_gui`へ変更
- PySide6のメインウィンドウ、左ナビ、共通状態表示を追加
- 録画、戦績管理、統計、デッキ名、タグ、シーズン、YouTube、信頼性、設定の主要ナビを追加
- 録画開始、録画停止、自動監視切替、履歴更新を既存サービス層へ接続
- `prepare`と`improve`を独立ナビへ戻さず、YouTube、戦績管理、統計、設定へ統合する方針を維持
- PySide6 GUIスモークJSONとスクリーンショット出力を追加
- 旧Tkinter GUIは互換モジュールとして残す

## 互換性

- DB schemaはV17のまま変更しません
- 設定キーや設定形式を変更しません
- 録画ファイル、YouTube投稿履歴、prepare queue、manifest、ログ、OAuth資格情報を削除、初期化、形式変更しません
- 旧Tkinter GUIは通常配布入口から外しますが、`master_duel_recorder_lite.gui`として残します
