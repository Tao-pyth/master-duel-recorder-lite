# V2.7.14 — デッキ・タグ一覧の名前可読性修正

## Changes
Keep deck and tag names readable when catalog descriptions are long. Combine the color icon, name and secondary description into one column, reserve a minimum width for names, and keep metadata columns compact. Preserve existing editing, filtering and stored data.

## 初心者向けの説明
長い説明があると名前の列が数文字まで縮む問題を修正しました。色は名前の横、説明は名前の下へまとめます。名前を優先して1行で表示し、省略される長い名前や説明はマウスを重ねるか右側編集欄で全文を確認できます。

小さい画面では横スクロールで残りの列を確認できます。絞り込みも「用途・表示：すべて」など対象が分かる表記にしました。データ移行は不要です。

[操作説明](../architecture/pyside-catalog-editors.md)。追跡: #648。

Windows CLI・GUI・updaterと個別/集約SHA-256を配布します。正式公開の検証結果はGitHub ActionsとReleaseを正本とします。
