# master-duel-recorder-lite v0.13.1

自動監視の対象固定、FFmpeg異常終了診断、出力停止検出、連続失敗の再試行制御を追加したFixリリースです。

## 主な変更

- 同一PID・HWNDを3回連続確認してから自動録画を開始
- 録画中の対象ウィンドウを固定
- Windows終了コードをDWORD、符号付き32bit、16進数で表示
- stderr末尾と監視開始情報を録画履歴へ保存
- GUI録画履歴から失敗診断を表示
- 30秒間の出力停止を検出
- 連続失敗を指数バックオフし、3回で一時遮断

対戦中かどうかの画像判定は含みません。対戦開始、ターン切り替え、勝敗の自動判定はV0.16.0で提供します。
