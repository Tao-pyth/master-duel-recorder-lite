# master-duel-recorder-lite v0.20.0

V0.20.0は、対戦記録へコイントス情報を追加する中核機能リリースです。

## 主な変更

- コインの面を表・裏・未設定で保存
- プレイヤー視点のコイントス勝敗を勝ち・負け・未設定で保存
- 先後とは独立した編集、監査、CLI操作
- 録画履歴の表示と複合フィルター
- 統計条件と表裏別・コイントス勝敗別の内訳
- DB v9移行とV0.19.x管理データJSONの後方互換

既存の記録は未設定として維持され、コイントス未設定だけを理由に戦績管理未完了にはなりません。画像による自動判定は含みません。V1.0.0には更新していません。
