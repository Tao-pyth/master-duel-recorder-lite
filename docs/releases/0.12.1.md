# master-duel-recorder-lite v0.12.1

対戦記録機能のV0.13.0からV0.16.0までを詳細化した計画更新版です。録画・GUI・CLIの実行機能はv0.12.0と同じです。

## 計画した中核機能

- V0.13.0: 録画の閲覧
- V0.14.0: 対戦記録管理
- V0.15.0: 対戦タイムライン基盤
- V0.16.0: 基本イベント自動判定

勝敗、先後、デッキ、対戦種別、タグ、メモは録画IDへ関連付け、確定後も再編集可能にします。自動判定は対戦開始、ターン切り替え、勝敗・対戦終了に限定し、利用者が確認可能な候補として保存します。

このリリースは`user_data/`、録画、履歴DB、設定、復旧結果、アップロード準備データを変更しません。
