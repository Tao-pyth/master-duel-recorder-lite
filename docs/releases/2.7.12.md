# V2.7.12 — 戦績管理の下部編集と操作整理

## Changes

Rebuild duel management around filters, a full-width record table, and an inline editor below the selected record. The incomplete filter can be toggled off without clearing other filters. Preserve unsaved input across navigation and surface save failures and revision conflicts. Existing bulk edit, review, playback, deletion, YouTube, duplicate checks and filter paths remain accessible.

## 初心者向けの説明

戦績管理を「条件で絞る → 一覧から選ぶ → 下部で入力して保存する」の順に変更しました。戦績の内容を確認するために毎回別の編集画面を開く必要がなくなります。

- 「未完了のみ」は再クリックで解除できます。期間やデッキなど、他の条件は維持します。
- 下部でデッキ・勝敗・先後・コイン・確認状態を編集し、詳細項目からシーズン・タグ・メモ等を入力できます。
- 未保存のまま移動すると「保存・破棄・取消」を確認します。保存できなかった場合も入力は残ります。
- 複数行はチェック欄から選び、一括編集できます。再生など選択行への操作は下部、重複確認や表示列は上部の「その他」にまとめました。
- 録画方式とDB/設定形式の変更はなく、データ移行は不要です。

操作説明: [戦績管理の使い方](../architecture/pyside-history-redesign.md)。追跡: #642、#643、#644。

## 配布・検証

CLI・GUI・updaterのWindows EXE、個別SHA-256、集約SHA256SUMSを配布します。全テスト、Windows画面確認、3EXEの起動確認に加え、Release workflowで公開ファイルとハッシュ、再取得後の起動を検証します。正式公開の検証結果はGitHub ActionsとReleaseを正本とします。
