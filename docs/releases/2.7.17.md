# V2.7.17 — 自動監視の対戦種別初期値

## Changes
Add a duel-type selector to automatic monitoring defaults. Persist the selection at monitoring start and snapshot it for new successful automatic recording drafts. Preserve existing records, manual recording behavior, and legacy configuration compatibility.

## 初心者向けの説明
録画画面の「自動監視の戦績初期値」で、希望先後の右に「対戦種別」を追加しました。その他・ランク戦・イベント・ルーム戦・ソロモードから選べます。

監視開始時の選択を保存し、監視中に作られる新しい戦績下書きへ反映します。開始後の変更は次の監視開始から適用されます。以前の設定は「その他」として読み込まれ、データ移行は不要です。既存戦績と手動録画の内容は変わりません。

設定保存に失敗した場合は監視を開始せず、元の設定を保持します。追跡: #654。
Windows CLI・GUI・updaterと個別/集約SHA-256を配布します。正式公開の検証結果はGitHub ActionsとReleaseを正本とします。
