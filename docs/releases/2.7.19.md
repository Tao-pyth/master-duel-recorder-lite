# V2.7.19 — 統計の開催日順・対戦種別・絞り込み改善

## Changes
Sort season statistics by descending start date, add a duel-type breakdown, and replace the ambiguous outcome selector with a duel-type filter. Apply date and duel-type filters across the statistics views while keeping the overall win-rate card as the unfiltered reference.

## 初心者向けの説明
- 「シーズン別」は開催開始日が新しい順です。同じ開始日は登録の新しい順、シーズン未設定は最後に表示します。アーカイブ済みシーズンの戦績も集計されます。
- 「対戦種別別」タブで、ランク戦・イベント・ルーム戦・ソロモード・その他の対戦数、勝利数、勝率を比較できます。
- 上部の「条件」を「集計対象」に改め、分かりにくかった「勝利のみ／敗北のみ」を「対戦種別」の選択に置き換えました。「ランク戦」を選べば、その勝ち・負け・引き分けを含めて集計します。

期間と対戦種別は、条件適用後の勝率、先後別カード、各タブに反映されます。「全体勝率」は比較用として全期間・全種別を表示します。「すべての対戦種別」と「期間を指定」の解除で全体へ戻せます。

保存済み戦績・設定の変更やデータ移行は不要です。追跡: #656 / #657。
Windows CLI・GUI・updaterと個別/集約SHA-256を配布します。公開検証結果はGitHub ActionsとReleaseを正本とします。
