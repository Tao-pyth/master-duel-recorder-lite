# V2.4.0: 通常GUI内動画レビュー統合

## 概要

V2.4.0では、PySide6通常GUIの戦績管理から録画レビュー画面を開き、動画再生とタイムライン支援操作を同じGUI内で扱えるようにした。既存のレビューViewModel、録画参照、タイムライン、クリップ出力サービスを再利用し、DB schema、設定形式、録画処理、queue、manifest、OAuth資格情報は変更しない。

## 変更点

- 戦績管理の録画再生操作を、通常GUI内レビューウィンドウ起動へ接続した。
- `.mp4`と`.mkv`のアプリ内再生、再生/一時停止、シーク、現在位置表示を追加した。
- タイムライン一覧に経過、種別、状態、ラベル、由来を表示し、イベントクリックで動画位置へシークできるようにした。
- 現在位置マーカー追加と選択位置中心のクリップ出力を既存Application Service経由で実行するようにした。
- Qt Multimedia不可、未対応形式、再生エラー時に外部プレイヤーへfallbackする契約を追加した。
- GUI smoke contract、README、設計文書、リリースノート、バージョン情報をV2.4.0へ更新した。
