# V1.4.4: YouTube OAuth client_secret同梱hotfix

V1.4.4では、V1.4.3のGUI通常連携でOAuth token交換時に`client_secret is missing`が再発する問題を修正します。ユーザーに`client_secret.json`選択やGoogle Cloud Console操作を求めず、配布EXEに同梱したOAuth `client_id`と`client_secret`でtoken交換を完了できるようにします。

## 対象Issue

- #468: GUI YouTube OAuth token交換へclient_secretを同梱して送信する

## 変更内容

- releaseビルドのYouTube OAuth asset生成で`MDRL_YOUTUBE_OAUTH_CLIENT_ID`と`MDRL_YOUTUBE_OAUTH_CLIENT_SECRET`の両方を必須化
- 配布EXEへ同梱する`assets/youtube-oauth-client.json`に`client_id`と`client_secret`を含めるよう変更
- `refresh_token`、`access_token`は引き続き配布assetへ含めない検証を維持
- token交換リクエストで`client_secret`設定済みclientの場合に`client_secret`を送る回帰テストを追加
- README、アップロード準備設計、リリースノートで、V1.4.4以降の配布方針を`client_id + client_secret`同梱へ更新
