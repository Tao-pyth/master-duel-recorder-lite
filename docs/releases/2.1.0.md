# V2.1.0: PySide6標準機能移植

Release date: 2026-08-23

## 概要

V2.1.0では、PySide6 GUIを通常配布GUI入口へ戻し、V2.0.1/V2.0.2で定義した15標準機能ゲートをPySide6側で満たすようにした。目的は、現行機能をPySide6 UIで管理・表示できる状態にすることである。

## 変更内容

- PySide6 smoke contractへ、標準機能充足、標準操作チェック、録画後ワークフロー、データ保全表示契約を追加した。
- 要求widget 51個をPySide6側で登録し、`failed_standard_operation_checks` が空になるようにした。
- 録画、戦績管理、手動戦績、履歴フィルター、統計、デッキ名、タグ、シーズン、YouTube、MP4準備、信頼性、設定、データ保全、CSV/更新、主要ダイアログの入口をPySide6 UIへ追加した。
- 実アプリ起動時は、既存サービス層から履歴、カタログ、シーズン、YouTubeテンプレート、MP4準備、バックアップ、統計を読み込む。
- 統計の推移単位を「勝利数・勝率推移」内の条件として配置し、既定値を日単位にした。
- `master-duel-recorder-lite-gui.exe`の通常入口を `master_duel_recorder_lite.pyside_gui` へ戻した。

## 非変更

- SQLite schemaは変更しない。
- 設定形式は変更しない。
- 録画ファイル、queue、manifest、OAuth資格情報は削除、初期化、形式変更しない。
- OBS Plugin / OBS WebSocket依存は追加しない。
- Tkinter互換モジュールは削除しない。
