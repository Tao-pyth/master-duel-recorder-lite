# master-duel-recorder-lite v0.17.0

録画・対戦情報の統合管理を提供するマイナーリリースです。既存の録画・復旧・準備機能を維持しながら、デッキ・タグ管理、音声入力、Master Duel固有UI判定、録画履歴GUIを一体化しました。

## 主な変更

- デッキ名とタグを個別管理し、説明、タグカラー、安定ID、参照中アーカイブを追加
- GUIからWindows音声入力を選択・テストし、AAC録音と履歴状態へ接続
- 日本語UIのコイントス、盤面、先後、ターン、勝敗、マッチエラー、リプレイを状態機械で判定
- 録画履歴を勝敗・先後・対戦種別中心へ変更し、行内に再生・編集・Explorer・削除アイコンを追加
- 提供動画14本を外部送信せず評価できるローカル台帳と回帰評価器を追加
- SQLiteをスキーマ版6へ安全に移行

## 対応範囲と制約

- 画面判定はMaster Duel日本語UIの1920x1080ウィンドウと3440x1440フルスクリーンを対象とする
- ボーダーレス表示はゲームに設定がないため対象外
- 音声はDirectShow入力を1つ選択し、システム音とマイクの同時ミックスは対象外
- 判定画像、テンプレート、提供動画はEXEとリポジトリへ含めない
- V1.0.0への更新は行わない

詳細は[リリースノート](../release-notes.md)を参照してください。
