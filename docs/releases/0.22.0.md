# master-duel-recorder-lite v0.22.0

V0.22.0は、対戦後の入力時間を短縮し、未完了戦績を継続的に整理できる「戦績入力体験」リリースです。

## 主な変更

- 録画終了後と初期画面に簡易戦績入力を追加
- 直近値、開催中シーズン、使用頻度に基づく根拠付き候補を追加
- 未完了戦績の日時順キューと連続処理を追加
- 戦績一覧の複数選択と一括編集を追加
- 複合フィルターの保存、呼出し、上書き、削除を追加
- DBをv11へ更新し、保存済みフィルターを管理データJSONへ追加

録画、自動監視、再生、統計などV0.21.3までの機能は維持されます。V1.0.0には更新しません。
