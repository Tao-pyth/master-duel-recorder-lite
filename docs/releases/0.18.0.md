# master-duel-recorder-lite v0.18.0

確定済みの対戦記録を分析する統計ページと、Material 3に基づくGUI刷新を提供するマイナーリリースです。

## 主な変更

- 全体勝率と条件適用後の勝率を並列表示
- 期間、デッキ、タグ、先後の単独・複合フィルター
- 日・週・月単位の勝利数と勝率推移チャート
- デッキ別・先後別の対戦数、勝敗、引分、勝率
- Material 3のカラーロール、情報階層、ナビゲーション、操作状態をGUI全体へ適用

## 集計範囲

正常完了し、対戦記録が確認済みで、勝敗が設定された対戦だけを集計します。引分は対戦数へ含みます。未確認・未入力・録画失敗は統計へ含めません。タグは安定IDで追跡するため、後から名称を変更しても過去の対象関係を維持します。

## データ影響

SQLiteスキーマ、既存録画、設定、対戦記録は変更しません。統計は既存DBの読み取り専用機能です。

詳細は[リリースノート](../release-notes.md)を参照してください。
