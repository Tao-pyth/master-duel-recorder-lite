# V1.2.0: 自動録画の信頼性と後解析

V1.2.0では、自動録画を任せる前に状態を確認する`reliability`入口を追加しました。録画環境、導入状態、既存動画後解析、ホットキー・トレイ設定を、録画ファイルやDBを壊さない境界で確認できます。

## 主な変更

- `mdrl reliability check`を追加
- `mdrl reliability wizard`を追加
- `mdrl reliability analyze PATH --mode replay`を追加
- `mdrl reliability hotkeys`を追加
- GUIへ「信頼性」ページを追加
- `[interaction]`の非シークレット設定を追加
- DBスキーマ、録画ファイル、YouTube資格情報、prepare queue、manifest形式は変更なし
