# V1.6.0 リリースメモ

## 概要

V1.6.0は、V2.0.0のPySide6全面移行前に、録画後の整理、振り返り、投稿準備を情報設計として固定するリリースです。利用者向けの大きなUI実装変更ではなく、次のメジャー更新で画面を作り替えるための前提を整理します。

## 主な変更

- 戦績管理を録画後ハブとして定義
- 未入力、下書き、録画欠損、確認済み未投稿、投稿済み、録画なし手動戦績の状態優先度を整理
- MP4準備内部ページをYouTube投稿、診断、CLIへ分解する方針を記録
- 改善内部ページを戦績管理、統計、設定へ吸収する方針を記録
- 設定画面を通常設定、外部連携、データ保護、危険操作、診断へ分ける前提を記録
- 戦績入力、未完了処理、タイムライン、レビュー、YouTube投稿、診断のダイアログ導線をワークフロー単位で整理
- V2.0.0のスクリーンショット回帰と操作スモーク要件を整理
- Master Duel単体音声で録画した出力に音声ストリームがない場合、履歴へ音声警告を残す
- 音声設定GUIで、Master Duel単体音声ではDirectShow入力欄を使わないことを明示

## 互換性

- DB schemaはV17のまま変更しません
- 設定キーや設定形式を変更しません
- 録画ファイル、YouTube投稿履歴、prepare queue、manifest、ログ、OAuth資格情報を削除、初期化、形式変更しません
- このリリースは情報設計と単体音声の誤読防止が主目的で、Tkinter GUIまたはPySide6 GUIの大規模実装変更は含みません

## 既知制約

- V1.6.0ではPySide6全面移行そのものは実装しません
- `prepare`と`improve`の内部ページ統合は方針確定までで、実際の画面変更はV2.0.0側で扱います
- DB schemaや設定形式の変更が必要になった場合は、V2.0.0作業へ黙って含めず、追加Issueで移行設計を先に行います
- 無音そのものはゲーム状態やWindows音量でも起こるため、無音だけを理由に録画ファイルは失敗扱いにしません
