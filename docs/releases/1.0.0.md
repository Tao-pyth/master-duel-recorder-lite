# master-duel-recorder-lite v1.0.0

V1.0.0は、Master Duelの録画と戦績管理を一つのWindowsアプリケーションとして提供する最初の正式版です。

## 提供機能

- FFmpegの導入・診断と手動・自動録画
- Master Duelの対戦開始、盤面、ターン、勝敗の画面判定
- 録画再生、保存場所表示、戦績・タイムラインの後編集
- デッキ、タグ、シーズン、勝率統計、シーズンレポート
- 録画なし戦績、CSV入出力、バックアップ、整合性診断
- Master Duel単体音声、MP4・アップロード準備
- 実行時データと任意のポータブルEXEを対象とするクリーンアンインストール

## 既知制約

自動画面判定の対応範囲、Process LoopbackのWindows要件、コード署名されていないEXE、YouTube直接アップロード対象外は[検証記録](../validation/1.0.0.md)を確認してください。

## 検証

Ruff、全463テスト、実FFmpeg試験2件、CLI/GUI one-file EXEビルド、両スモークに合格しました。空の実行時ルートでは初期化、戦績CRUD、CSV往復、バックアップ、整合性診断、クリーンアンインストール境界を確認しています。詳細は[検証記録](../validation/1.0.0.md)を参照してください。
