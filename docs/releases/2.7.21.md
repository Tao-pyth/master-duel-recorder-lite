# V2.7.21の操作と変更

統計の数値・日付表示、上部の配置、デッキ相性の絞り込みを改善しました。既存戦績・録画・設定の移行は不要です。起動中の旧版を閉じてから更新してください。

## 数値を見比べる

件数と勝率を右揃えにし、勝率へ短い補助バーを追加しました。列見出しを押すと数値として並び替えます。初期表示のシーズン開催順・推移の時間順は維持し、選んだ並び順は条件変更後も保ちます。

対戦数が10戦未満の行は「参考」列に「少数」と表示します。少ない対戦で100%でも、対戦数の多い100%と同じ確かさとは限りません。「少数」は目安であり、勝率の確かさを保証する基準ではありません。0戦の勝率は「-」で表示します。

推移グラフの日付は、文字が欠けない幅で表示します。期間が長い場合は読みやすい間隔へ減らし、開始と終了の日付を残します。棒は期間別勝利数、線は累積勝率で、計算は従来と同じです。

## 広くなった一覧と共通条件

上部は「条件適用後の勝率」を中心に配置し、全体勝率は全期間・全種別の比較値として残しました。カードと条件欄をコンパクトにして、表・グラフへ表示面積を戻します。期間指定と対戦種別は全タブへ反映し、条件変更時に自動更新します。

## 相性を絞り込む

1. 「統計」→「デッキ相性」を開き、自分デッキを選びます。
2. 相手デッキ名を入力すると部分一致で絞れます。英字の大小・全角半角を正規化して検索します。
3. 「相手未設定も表示」を外すと、空欄の相手デッキを折り畳みます。必要なら最低対戦数も指定します。
4. 「解除」で相性の条件だけを戻します。上部の期間・対戦種別は維持します。

相性の絞り込みは、この一覧だけに適用します。上部の勝率や他タブの集計は変わりません。「表示」は現在見えている件数、「共通条件」は期間・対戦種別を適用した母集団です。「相手未設定」は自分デッキ・名称検索後、最低対戦数の適用前の件数です。

実際に「未設定」というデッキ名を付けた記録は「未設定（デッキ名）」と区別し、空欄を折り畳んでも残します。長い名前はマウスを置くと全文を確認でき、列幅変更と表の横スクロールも使えます。

勝率は従来どおり勝利数÷対戦数（敗北・引分を含む）。未確定・勝敗未入力・失敗録画は対象外です。相性条件はセッション内だけに保持し、DBや設定を変更しません。
