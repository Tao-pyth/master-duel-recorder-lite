# master-duel-recorder-lite v1.0.1

V1.0.1は、正式版で確認された不具合を修正し、保存先、MP4準備、統計、戦績表示、更新、アプリアイコンを改善するFix Releaseです。

## 主な変更

- 手動入力した戦績を関連タグ・変更履歴と一緒に安全に削除し、外部キー制約エラーを解消
- FFmpegの既存実行ファイル選択と、空の指定フォルダへの導入に対応
- 全実行時データの保存先変更を、事前バックアップ、複製、SQLite検査、失敗時非切替で実装
- MP4準備対象を録画IDではなく録画情報から選択可能に変更
- 統計へシーズン別集計を追加
- 戦績管理のコイン、対戦種別、時間、サイズを表示・非表示にする設定を追加
- 勝敗、先後、コイン、登録元の背景色設定を追加。既定色は白
- 録画ページの表記を「戦績を追加（録画なし）」へ変更
- GitHub正式Releaseの更新確認、SHA-256検証、明示適用、起動失敗時復元を追加
- GUI、タスクバー、EXEへMaster Duel Recorder Lite専用アイコンを適用

## データ保護

DBスキーマは変更しません。保存先変更では元データを自動削除せず、切替失敗時は従来の保存先を継続利用します。アンインストール時は選択中の保存先と保存先ポインターを削除対象へ含めます。

## 検証

Ruff、全474テスト、実FFmpeg試験2件、ネイティブ音声ヘルパー、CLI/GUI one-file EXEビルド、両スモーク、GUI目視確認に合格しました。詳細とローカルSHA-256は[検証記録](../validation/1.0.1.md)を参照してください。
