# master-duel-recorder-lite v1.0.3

V1.0.3は、カレンダー表示と戦績入力の固定択一項目を改善するFix Releaseです。

## 主な変更

- カレンダーピッカーのヘッダーを7列グリッドへ整理
- 年月タイトルを大きくし、火・水・木列にまたがる配置へ変更
- 「今月へ」を金・土列上に配置し、当月表示中の無効状態を維持
- 曜日ラベルと日付セルを等幅化し、土曜日列だけ歪む表示を修正
- 勝敗、先後、状態、コインの面、対戦種別をボタン選択へ変更
- 一括編集の「変更しない」と「未設定」を視覚的に分離
- V1.1.0からV1.3.0までのロードマップをローカル文書へ追加

## データ保護

DBスキーマ、CSV形式、CLI契約、設定、`ui-preferences.json`、録画ファイル、実行時データ形式は変更しません。既存の戦績、録画、履歴、統計、CSV入出力は従来の内部値をそのまま利用します。

## 検証

Ruff、全単体テスト、CLI/GUI one-file EXEビルド、両スモークで検証します。詳細とローカルSHA-256は[検証記録](../validation/1.0.3.md)を参照してください。
