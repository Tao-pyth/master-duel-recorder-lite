# V2.7.1: PySide6実操作UI Hotfix

V2.7.1では、V2.7.0公開直後の実操作レビューで確認されたPySide6 GUIの視覚品質問題を修正した。対象はボタン、表、統計グラフ、色設定、シーズン入力に限定し、保存データや設定schemaは変更しない。

## 変更内容

- 主要操作ボタンのQt標準アイコンを、アプリ内で描画する線画アイコンへ置き換えた。
- 統計画面の勝利数・勝率推移グラフで、上部ラベル、日付ラベル、凡例が重ならないようにした。
- 戦績管理などの表で、選択や操作後に行高が変わらないよう固定行高へ変更した。
- 設定の戦績表示色テーブルに「変更」列を追加し、色選択ダイアログから既存UI設定へ保存できるようにした。
- シーズン入力を、名前1行、種別・開始日・終了日1行へ整理し、3入力の幅を揃えた。
- シーズン一覧の種別を `ranked` / `event` / `custom` ではなく「ランク戦」「イベント」「カスタム」で表示するようにした。

## 互換性

- SQLite schema、設定schema、既存録画ファイル、YouTube投稿履歴、OAuth資格情報、queue、manifestは変更しない。
- 既存の戦績管理、統計、シーズン管理、戦績表示色設定の保存先は維持する。
- 外部アイコンパッケージや画像アセットは追加しない。
