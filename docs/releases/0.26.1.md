# master-duel-recorder-lite v0.26.1

V0.26.1は、ポータブル配布にクリーンアンインストールを追加するReleaseです。

## 主な変更

- 現在のアプリ保存領域を、内容と容量の確認後に一括削除
- 設定、戦績、録画、ログ、キュー、バックアップ、エクスポート、導入済みFFmpegを対象化
- GUIの確認語・最終確認とCLIの二重確認
- 録画・自動監視中の実行拒否と危険パス・境界外削除の防止
- Windows one-file版の起動EXEを任意で終了後削除

## 注意

この操作は元に戻せません。必要な戦績はCSVまたは管理データとして、必要な録画は別フォルダへ事前に保存してください。外部FFmpeg、別フォルダへ移動した動画、旧版の別保存領域は削除しません。一時クリーナーはWindows再起動まで残る場合があります。

## 検証

Ruff、全463テスト、CLI/GUI one-file EXEビルド、両スモーク、配布CLIの終了後削除E2Eを実施しました。詳細は[検証記録](../validation/0.26.1.md)を参照してください。
