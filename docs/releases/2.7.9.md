# V2.7.9

Fix the eight GUI audit findings: live statistics and filters, reachable recording controls, shared settings actions, incomplete-record navigation, and readable charts.

表示された値と実際のデータ・操作を一致させ、小さい画面でも主要な操作を見つけられるようにした修正版です。

## V2.7.9: GUI監査で確認した表示・操作の修正 - 2026-09-09

- 統計の全体/条件適用後/先後別カードを実集計へ接続し、期間・勝敗・日/週/月を反映する。対象0件では空状態を表示する
- 録画状態と開始/停止/監視を狭い画面でも同時表示し、長い選択肢による横見切れを防ぐ
- 設定の保存/再読込をタブ共通に配置し、未保存表示、画面間の変更保持、終了時の保存/破棄/取消を追加する
- 戦績管理の操作を2行へ整理し、余った高さを表へ配分する。未完了ボタンで対象を絞り、状態列で編集中/確認済み/未作成を区別する
- 統計グラフに軸目盛りと推移の数値表を追加し、通常画面の開発向け文言と設定タブ名を整理する
- DB/設定形式、録画方式、認証情報、録画ファイルは維持する
- 追跡: Issue #631〜#638。公開と配布検証は[v2.7.9 Release](https://github.com/Tao-pyth/master-duel-recorder-lite/releases/tag/v2.7.9)で確認する


通常起動と実widgetによる検証はdocs/validation/2.7.9.mdへ記録。正式公開はGitHub Releaseを正本とする。
