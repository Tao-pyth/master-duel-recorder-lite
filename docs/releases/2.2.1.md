# V2.2.1: アプリ更新Release選択hotfix

Release date: 2026-08-23

## 概要

V2.2.1では、配布資産がないReleaseが存在してもアプリ内更新が壊れないようにした。更新確認はGitHubの`latest` 1件だけに依存せず、Release一覧からGUI EXE、updater EXE、SHA-256が揃った最新安定版だけを選ぶ。

## 変更内容

- GitHub Release一覧から、draft/prerelease、現在以下のバージョン、配布資産不足のReleaseを除外する。
- GUI EXE、updater EXE、各SHA-256が揃ったReleaseだけを更新候補にする。
- 配布可能Releaseが存在しない場合は、更新確認をエラーにせず「利用可能な更新なし」と扱う。
- 資産なしReleaseをスキップする単体テストを追加した。
- `v2.2.0` は資産なし通常Releaseとして公開されていたため、応急処置としてpre-releaseへ変更した。

## 非変更

- SQLite schemaは変更しない。
- 設定形式は変更しない。
- 録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- UI機能は追加しない。

## 検証

- Ruff: `python -m ruff check .` 合格
- 重点テスト: `python -m pytest tests/test_app_update.py tests/test_release_tooling.py tests/test_version.py` 合格
- 全テスト: `python -m pytest` 587 passed, 3 skipped
- EXEビルド: `python scripts/build_windows_exe.py` 合格
- EXEスモーク: CLI/GUI/updater 3本すべて `2.2.1` として起動確認済み
- UI確認: GUI smokeでアプリ更新タブ、統計チャート、日付ピッカー、主要テーブル契約を確認済み
- 公開Release asset検証: Release公開後に `python scripts/verify_release_assets.py v2.2.1` で確認する
