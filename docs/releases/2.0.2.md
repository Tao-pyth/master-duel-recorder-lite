# V2.0.2 リリースメモ

V2.0.2は、V2.0.1で復旧した1.x相当のTkinter通常配布GUIを前提に、15標準機能をユーザー操作レベルで確認できるようにするFixリリースです。

## 主な変更

- GUI smokeに標準機能ごとの実操作チェック結果を追加
- 戦績管理を録画後ハブとして確認するsmoke契約を追加
- データ保全表示で、バックアップ/復元が録画ファイル、queue、manifest、OAuth資格情報を変更しないことを明示
- PySide6通常入口化ゲートを、widget存在だけではなく実操作確認へ拡張
- V1.4.x open Issueを棚卸しし、V2.0.2のBackward Compatibilityを妨げないことを確認

## 互換性

- PySide6は通常配布入口へ戻しません
- DB schema、設定形式、録画ファイル、YouTube投稿履歴、OAuth資格情報、prepare queue、manifestは変更しません
- 通常配布GUI入口は引き続きTkinter GUIです

## 検証

検証結果は[docs/validation/2.0.2.md](../validation/2.0.2.md)を参照してください。
