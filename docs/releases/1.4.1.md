# V1.4.1: YouTube一般配布導線hotfix

V1.4.1では、V1.4.0検証で見つかったGUI回帰とYouTube配布導線の不足を修正しました。YouTube OAuth client_idを配布EXEへ同梱できるようにし、未設定ビルドでは連携開始を無効化します。MP4準備は独立した主要ナビではなく、録画履歴からのYouTube投稿フロー内で投稿前処理として扱います。

## 主な変更

- 改善ページの`list_history()`引数不整合を修正
- 配布EXEへYouTube OAuth client_idを同梱するビルド経路を追加
- releaseビルドでOAuth client_id未設定を検出
- OAuth client_id未設定時のGUI状態表示と操作可否を整理
- `MP4準備`と`改善`をGUI主要ナビから外し、必要機能は既存導線へ統合
- 投稿ダイアログで投稿用MP4準備状態を表示
- `client_secret`なしのPKCE/desktop OAuth資格情報を保存、読み戻し、refreshできるように調整
