# master-duel-recorder-lite v0.12.0

Windows向けGUIと録画対象の明示選択を追加したリリースです。

## ダウンロード

- `master-duel-recorder-lite-gui.exe`: 通常利用向けGUI
- `master-duel-recorder-lite.exe`: 自動化・詳細操作向けCLI
- 各EXEに対応する`.sha256`

GUI版を起動し、録画対象を選択して「環境を診断」を実行してください。診断後、「録画開始」で手動録画、「自動監視」でMaster Duelの可視状態に応じた録画を開始できます。

## 主な変更

- Master Duel、任意ウィンドウ、モニター、デスクトップ全体から録画対象を選択可能
- 録画、履歴、復旧、アップロード準備、設定を扱うWindows GUI
- CLI版とGUI版のone-file EXE、SHA-256、build provenance

FFmpeg 6.0以上は別途必要です。EXEはコード署名されていないため、Releaseの公開元とSHA-256を確認してください。既存の`user_data/`は削除・上書きしません。
