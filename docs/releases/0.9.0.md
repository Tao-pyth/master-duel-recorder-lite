# master-duel-recorder-lite v0.9.0

Windows向けの単一EXE配布を追加しました。Pythonのインストールは不要です。

## ダウンロード

- `master-duel-recorder-lite.exe`: Windows 10/11 x64向けコンソールアプリ
- `master-duel-recorder-lite.exe.sha256`: EXEのSHA-256確認用

## 初回確認

PowerShellでEXEを保存したフォルダへ移動し、次を実行してください。

```powershell
.\master-duel-recorder-lite.exe --version
.\master-duel-recorder-lite.exe config init
.\master-duel-recorder-lite.exe doctor
```

FFmpegはEXEへ同梱していません。録画にはFFmpeg 6.0以上を別途導入し、PATHまたは設定へ登録する必要があります。

このEXEはコード署名されていません。Windows SmartScreenが警告した場合は、公開SHA-256とダウンロードしたEXEのハッシュが一致することを確認してから実行してください。
