# master-duel-recorder-lite v0.16.10

V0.16.9の対戦記録入力・デッキ名とタグ管理・前回値引継ぎ・録画履歴削除を含み、Windows短縮パス環境のCI検証を修正したFixリリースです。

## 修正内容

- Windows runnerの8.3短縮パスと正規化済みパスを同一の削除対象として検証
- 録画保存先配下の正規化済みパスを返す製品契約を維持
- SQLite、録画ファイル、設定、GUI動作への追加変更なし

## 含まれるV0.16.9機能

- 対戦記録の日本語選択肢
- 選択・自由入力に対応する自分デッキ、相手デッキ、複数タグ
- サイドメニューのデッキ名・タグ一覧編集
- 対戦種別、両者のデッキ、タグの前回値引継ぎ
- 録画履歴、元録画、復旧成果物、対戦記録、タイムラインの一括削除
