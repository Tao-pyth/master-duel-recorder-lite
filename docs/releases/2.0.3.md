# V2.0.3 リリースメモ

V2.0.3は、V2.0.1で復旧したTkinter通常配布GUIを前提に、戦績管理、統計、シーズンレポートの読み取り品質を改善するFixリリースです。

## 主な変更

- 戦績管理のデッキ名列で、色スウォッチと長い日本語デッキ名が重なりにくい余白へ調整
- 統計の勝利数・勝率推移を、期間ごとの勝利数と累積勝率へ変更
- シーズンレポートの推移表でも、期間ごとの対戦・勝敗と累積勝率を分けて表示
- シーズンレポートの内訳に全体行を追加
- 0件の未設定行と、勝敗列に重複する最終勝敗軸を標準表示から除外

## 互換性

- PySide6は通常配布入口へ戻しません
- DB schema、設定形式、録画ファイル、YouTube投稿履歴、OAuth資格情報、prepare queue、manifestは変更しません
- 通常配布GUI入口は引き続きTkinter GUIです
