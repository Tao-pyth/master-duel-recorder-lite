# V2.7.2: 録画画面操作Hotfix

V2.7.2では、V2.7.1公開後に報告された録画画面の致命的な操作不整合を修正した。手動録画開始、停止、自動監視開始・停止について、画面表示と内部状態が一致するようにする。

## 修正内容

- 録画画面をサービスの録画状態、操作状態、自動判定状態へ500ms間隔で同期するようにした。
- 手動録画中は録画開始ボタンを無効化し、停止ボタンを有効化するようにした。
- 自動監視中は自動監視ボタンを「自動監視停止」へ切り替えるようにした。
- 停止ボタンを、手動録画中は手動録画停止、自動監視中は自動監視停止へ振り分けるようにした。
- 録画状態詳細で`recording`などの内部値を表示せず、「録画中」「停止中」などの日本語表示へ統一した。

## 背景

ユーザー報告では、録画画面でステータス帯が「停止中」のまま残っている一方、詳細には録画中の内部状態と録画IDが表示され、再度録画開始を押すと「録画はすでに実行中です」と表示されていた。

内部サービスは二重録画防止として正しく録画中を判定していたが、PySide6録画画面の状態同期が不足していたため、利用者には開始、停止、自動監視開始が壊れて見える状態になっていた。

## 互換性

- SQLite schemaは変更しない。
- 設定schemaは変更しない。
- 録画方式、FFmpegコマンド、保存先生成は変更しない。
- 既存録画ファイル、queue、manifest、OAuth資格情報は変更しない。
- OBS PluginとOBS WebSocketへの依存は追加しない。
