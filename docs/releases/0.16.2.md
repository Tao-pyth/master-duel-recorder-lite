# master-duel-recorder-lite v0.16.2

自動監視の録画開始を、Master Duelウィンドウの存在ではなく対戦開始の視覚判定へ変更するリリースです。

## 主な変更

- メニュー、デッキ編集、設定画面の表示だけでは自動録画しない
- 開始演出から5秒以内の盤面遷移を、同一PID・HWNDの複数フレームで確認
- 待機中は最大2fpsで判定し、フレームはメモリだけで処理
- 対象変更、最小化、ウィンドウ消失、取得失敗で途中の合意を破棄
- 自動監視の本録画対象をMaster Duelウィンドウへ固定
- 録画前の開始候補を録画タイムラインの0ミリ秒へ保存
- 録画開始後の停止確認、クールダウン、FFmpeg失敗時バックオフを維持

視覚判定の合意後に録画を開始するため、開始直前の数秒は動画に含まれません。プリロールは本リリースの対象外です。既存録画、履歴DB、設定を削除・移行しません。
