# master-duel-recorder-lite v0.16.9

対戦記録の日本語入力、デッキ名・タグ候補の管理、前回値引継ぎ、録画履歴の関連ファイル一括削除を追加するFixリリースです。

## 変更内容

- 状態、勝敗、先後、対戦種別を日本語の選択肢で表示
- 自分デッキ・相手デッキを共通候補から選択、または日本語で自由入力
- 複数タグを候補から追加、または日本語で自由入力
- サイドメニューの一画面でデッキ名・タグ候補を追加・名称変更・削除
- 最後に保存した対戦種別、自分デッキ、相手デッキ、タグを次の新規記録へ引継ぎ
- 録画履歴、元録画、復旧成果物、対戦記録、変更履歴、タグ、タイムラインの一括削除
- 履歴SQLiteをスキーマ版5へ安全に移行し、既存のデッキ名・タグを候補へ取込み

## 注意

- 候補一覧の名称変更・削除は過去の対戦記録を書き換えません。
- 録画履歴の削除は恒久操作です。確認後、関連ファイルとデータを削除して元に戻せません。
- 録画または自動監視の実行中は履歴を削除できません。
- V1.0.0への更新はユーザーの明示指示を待ちます。
