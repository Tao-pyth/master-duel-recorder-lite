# master-duel-recorder-lite v0.23.0

V0.23.0は、自動監視の状態、判定、診断、通知を一貫した契約で管理する「自動監視信頼性」リリース候補です。

## 主な変更

- 録画・自動監視の単一状態機械と操作許可表
- イベント別の開始・盤面・ターン・結果検出契約
- ライブ監視とオフライン評価の共有解析契約
- 表示プロファイル別の適合率・再現率・遅延JSON
- 画像を含まない数値診断ZIP
- 利用者状態と折りたたみ可能な判定詳細
- Windows通知と通知無効設定
- 数値診断から初期3戦・調整後10戦の連続成功を判定する実戦集計CLI
- 敗北結果の4/5フレーム合意と、結果停止後の盤面継続を早期停止として検出する実戦ゲート

旧提供動画14本は復元困難なため、現存する有効11戦・負例3本をSHA-256で固定した超横長回帰コーパスへ置き換えました。最新検出器の2fps評価は開始・盤面・結果11/11、負例の同イベント誤検出0で合格しています。1920x1080の最新実動画評価がない点は既知リスクです。残る公開条件はV0.23.0以降の最新候補GUI EXEによる初期3戦・調整後10戦連続試験です。2026-08-15の旧初期3戦は第3戦を決着前に敗北と誤認して不合格となり、Issue #332と#337で修正しました。fix337 GUIで初期3戦からやり直します。未達の間、この文書はRelease候補説明であり、GitHub Releaseは公開しません。
