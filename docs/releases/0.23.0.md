# master-duel-recorder-lite v0.23.0

V0.23.0は、自動監視の状態、判定、診断、通知を一貫した契約で管理する「自動監視信頼性」の実装・検証履歴です。後続修正とともにV0.25.0へ統合したため、単独タグ・GitHub Releaseは作成しません。

## 主な変更

- 録画・自動監視の単一状態機械と操作許可表
- イベント別の開始・盤面・ターン・結果検出契約
- ライブ監視とオフライン評価の共有解析契約
- 表示プロファイル別の適合率・再現率・遅延JSON
- 画像を含まない数値診断ZIP
- 利用者状態と折りたたみ可能な判定詳細
- Windows通知と通知無効設定
- 数値診断から初期3戦・調整後10戦の連続成功を判定する実戦集計CLI
- 敗北結果の4/5フレーム合意と、結果停止後の盤面継続を早期停止として検出する実戦ゲート

## 統合条件

旧提供動画14本は復元困難なため、現存する有効11戦・負例3本をSHA-256で固定した超横長回帰コーパスへ置き換えました。さらに1920x1080ウィンドウの対戦2本・負例2本を固定し、標準16:9の正規LOSE見逃しをIssue #338で修正しました。最新検出器の2fps評価は超横長の開始・盤面・結果11/11、標準16:9の同イベント2/2、全負例の厳格イベント誤検出0で合格しています。保存済み本検証セッション12録画の全編再生でも正規結果11/11、既知偽陽性0/1を確認しました。16:9のコイントス、リプレイ、マッチエラー実動画は未評価としてV0.25.0へ明記します。
