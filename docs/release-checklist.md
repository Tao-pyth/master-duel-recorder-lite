# リリース確認チェックリスト

この文書は、各リリースで更新時変更ログの表示判断と固有確認項目を残すために使う。強制モーダルは、DB移行、設定形式変更、録画ファイル操作、秘密情報、後方互換を壊す可能性がある場合だけrequiredにする。通常のGUI改善や操作変更は、更新情報表示をrequiredにし、強制モーダルはnot-requiredとして扱う。

## V2.6.0

- 更新情報表示: required。自動録画の録画開始前映像を含める新しい設定が追加されるため、通常の変更ログとして表示する
- 強制モーダル: not-required。既定無効で、DB schema、既存録画、OAuth資格情報、queue、manifestを変更しない
- プリロール: 自動録画限定で、設定画面またはCLIから明示的に有効化した場合だけ動作する
- 上限: 秒数と容量上限が検証され、一時segmentは `user_data/data/preroll/` 配下で増え続けない
- 失敗時: プリロールバッファまたは結合に失敗しても本録画を可能な範囲で残し、診断へ理由を記録する
- タイムライン: `duel_start` はプリロールを含む録画ファイル先頭からの経過として保存される
- 配布確認: Ruff、全単体テスト、PySide6 GUIスモーク、CLI/GUI/updater EXEビルド、3 EXEスモーク、GitHub Actions、公開asset検証、ダウンロード後EXEスモークを確認する

## V1.5.1

- 更新情報表示: required。戦績管理、YouTube投稿、簡易入力の見た目と入力体験が変わるため、通常の変更ログとして表示する
- 強制モーダル: not-required。DB schema、既存設定、録画ファイル、YouTube投稿履歴、OAuth資格情報を破壊的に変更しない
- タグ管理: 「デッキ名登録でのみ使用」と表示され、deck_onlyの保存・候補除外が維持される
- 戦績管理: 上部操作が1行で、「未完了を処理」「一括編集」「手動追加」の順に表示される
- 戦績管理: フィルター未適用時の解除ボタンが無効、条件適用後に有効になる
- 戦績管理: デッキ色がデッキ名列先頭の色付きドットで表示され、旧カラーラインと二重表示されない
- YouTube投稿: テンプレート画面でタイトル、概要欄、タグを1件だけ保存でき、「一覧」で変数が確認できる
- YouTube投稿: 投稿済み録画では「Youtubeリンク」欄に保存済みURLが表示され、投稿欄が無効化され、「リンクを開く」になる
- 録画診断: 閉じるボタンの文字が読める
- 録画レビュー: 起動失敗時に利用者へ通知され、既存GUIが固まらない
- 簡易入力: コイントスと相手デッキを入力でき、自分デッキとシーズン欄は表示しない
- 前回値: 簡易入力と詳細入力で、前回入力した対戦種別、自分デッキ、シーズンを候補値にする
- 配布確認: Ruff、全単体テスト、Python GUIスモーク、CLI/GUI/updater EXEビルド、3 EXEスモーク、バージョン表示、SHA-256を確認する

## V1.0.3

- 更新情報表示: required。カレンダー表示と戦績入力UIが日常操作へ影響するため、利用者へ通常の変更ログとして表示する
- 強制モーダル: not-required。DB、CSV、CLI、設定、録画ファイル、実行時データ形式を変更しない
- カレンダー: 前月、年月、今月へ、翌月が7列グリッドの1:3:2:1で表示される
- カレンダー: 当月表示中は「今月へ」が無効で、前月・翌月移動後は有効になる
- カレンダー: 月曜から日曜までの曜日と日付セルが等幅で揃う
- 戦績入力: 簡易入力と未完了処理で勝敗、先後をボタンから選べる
- 戦績入力: 詳細編集で状態、勝敗、先後、コインの面、対戦種別をボタンから選べる
- 一括編集: コイントスと対戦種別で「変更しない」と「未設定」を区別できる
- 互換性: 既存の戦績、録画、CSV入出力、統計集計、設定、履歴表示に回帰がない
- 配布確認: Ruff、全単体テスト、CLI/GUI/updater EXEビルド、3 EXEスモーク、バージョン表示、SHA-256を確認する
