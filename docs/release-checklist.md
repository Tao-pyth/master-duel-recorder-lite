# リリース確認チェックリスト

この文書は、各リリースで更新時変更ログの表示判断と固有確認項目を残すために使う。強制モーダルは、DB移行、設定形式変更、録画ファイル操作、秘密情報、後方互換を壊す可能性がある場合だけrequiredにする。通常のGUI改善や操作変更は、更新情報表示をrequiredにし、強制モーダルはnot-requiredとして扱う。

## V1.0.3

- 更新情報表示: required。カレンダー表示と戦績入力UIが日常操作へ影響するため、利用者へ通常の変更ログとして表示する
- 強制モーダル: not-required。DB、CSV、CLI、設定、録画ファイル、実行時データ形式を変更しない
- カレンダー: 前月、年月、今月へ、翌月が7列グリッドの1:3:2:1で表示される
- カレンダー: 当月表示中は「今月へ」が無効で、前月・翌月移動後は有効になる
- カレンダー: 月曜から日曜までの曜日と日付セルが等幅で揃う
- 戦績入力: 簡易入力と未完了処理で勝敗、先後をボタンから選べる
- 戦績入力: 詳細編集で状態、勝敗、先後、コインの面、対戦種別をボタンから選べる
- 一括編集: コイントスと対戦種別で「変更しない」と「未設定」を区別できる
- 互換性: 既存の戦績、録画、CSV入出力、統計集計、設定、履歴表示に回帰がない
- 配布確認: Ruff、全単体テスト、CLI/GUI/updater EXEビルド、3 EXEスモーク、バージョン表示、SHA-256を確認する
