# 自動録画の信頼性と後解析

## 目的

V1.2.0では、開発者向けの数値診断とは別に、利用者が対戦前に「自動録画を任せてよいか」を判断できる入口を追加します。録画、DB、設定、元動画を勝手に変更しないことを優先し、変更が必要な操作は既存の録画サービスや設定保存を明示的に通します。

## 30秒事前チェック

`auto_check`は`PreflightReport`、Master Duelウィンドウ状態、任意の`FrameAnalysis`サンプルから`ready`、`warning`、`failed`を返します。利用者向け理由には画像、BMP、絶対パス、秘密情報を含めません。CLIの`mdrl reliability check`は既定30秒の設定値を使い、現時点では録画環境とMaster Duelウィンドウを中心に判定します。画面サンプルが取得できない場合は、その事実を理由として表示します。

## 初回導入ウィザード

`setup_wizard`はFFmpeg、保存先、録画対象、音声、事前チェック、テスト録画、再生確認を固定ステップとして扱います。V1.2.0では状態モデルとGUI/CLI入口を追加し、完了状態は`[interaction].setup_wizard_completed`で既定値補完します。既存設定を自動移動・削除しません。

## 後解析

`offline_analysis`は既存動画またはリプレイ録画を読み取り専用で検証します。ffprobe検証の前後でサイズと更新時刻を確認し、処理中に元動画が変わった場合は失敗にします。結果のJSONにはファイル名だけを含め、絶対パスは出しません。候補保存が必要になった場合は、別IssueでDB保存範囲と移行を定義します。

## ホットキーとトレイ

`hotkey_actions`は実際のWindows登録処理から独立した操作許可表です。停止中、録画中、監視中、処理中ごとに実行できる操作を分け、禁止操作は既存状態機械と同じ考え方で拒否します。V1.2.0では設定、許可表、GUI/CLI入口を追加し、OS登録失敗時も録画機能を継続できる境界にします。

## データ影響

- DBスキーマ変更なし
- 録画ファイル変更なし
- YouTube資格情報、prepare queue、manifest変更なし
- 設定は`[interaction]`の非シークレット項目だけを追加し、既存設定は既定値で読み込む
