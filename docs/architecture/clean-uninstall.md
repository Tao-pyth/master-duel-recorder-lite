# クリーンアンインストール設計

## 目的

V0.26.1では、ポータブルEXEを削除するだけでは残る設定、SQLite DB、録画、ログ、キュー、バックアップ、エクスポート、導入済みFFmpegを、利用者の明示操作でまとめて削除できるようにする。

## 削除対象

- 現在のプロファイルが使用する実行時ルート全体
  - 既定のEXEでは`%LOCALAPPDATA%\MasterDuelRecorderLite`
  - Python実行ではプロジェクト直下の`user_data`
  - `MDRL_USER_DATA_DIR`または`--user-data-dir`で明示した場合はそのルート
- GUI/CLIの起動EXE。PyInstaller版で利用者が個別に選択した場合だけ、終了後に削除する

実行時ルート内にある設定、DB、録画、スクリーンショット、ログ、キュー、エクスポート、バックアップ、導入済みFFmpegはすべて削除対象になる。外部に手動導入したFFmpeg、実行時ルート外へ利用者が移動した動画、旧版の別プロファイル、Windowsの設定やレジストリは削除しない。

## 安全境界

- 録画、自動監視、開始・停止処理、他の管理処理中は開始できない
- 削除前に対象ルート、ファイル数、フォルダ数、合計サイズ、EXE削除の有無を表示する
- GUIは確認語`アンインストール`の入力と最終確認、CLIは`--yes --confirm アンインストール`を必須にする
- ドライブ直下、ホーム、`LOCALAPPDATA`そのもの、浅すぎるパスは拒否する
- 既定名でない任意ルートは、既知のアプリ用サブディレクトリを持つ場合だけ許可する
- シンボリックリンクとジャンクションの参照先をたどらず、リンク自体だけを削除する
- 削除処理は別プロセスが親プロセス終了を待ってから実行する

## Windows one-file EXE

実行中のWindows EXEは自分自身を削除できないため、EXEを一時フォルダへ複製し、その複製を終了後クリーナーとして起動する。クリーナーは実行時ルートと元EXEを削除し、最後に自身を次回再起動時の削除対象へ登録する。アプリ本体と使用領域は当該操作で削除され、一時クリーナーだけがWindows再起動まで残る場合がある。

## 失敗時

クリーンアンインストールは利用者が全削除を選択する操作なのでバックアップを自動作成しない。削除開始後のロールバックも行わない。必要な戦績はCSVまたは管理データ、必要な録画は別フォルダへ事前に書き出す。削除失敗時は一時フォルダへ結果JSONを残し、削除できなかったパスと理由を確認できるようにする。
