# 戦績管理の上下配置と下部編集（V2.7.12）

## 目的と採用案

ユーザーが採用した3案目に基づき、「上部で絞り込み → 全幅一覧で選択 → 下部で編集・保存」の順に再構成する。全体操作と行単位の操作を分け、既存戦績の比較と未完了確認の両方を扱う。

## 操作方法

- 上部: 「更新」「手動追加」「その他」。その他から重複候補、列の説明、表示列を開く。
- 絞り込み: 期間・自分デッキを常設し、「詳細条件」で保存済み条件、シーズン、タグ、コイン、登録元を開く。選択は即時適用し、「適用」でも再適用できる。期間指定時だけ開始日・終了日を表示する。
- 保存済み条件の選択中は、その条件がデッキ等を定義するため個別条件を無効化する。保存済み条件を解除すると個別条件を使用できる。
- 「未完了のみ」は押すたびにオン/オフ。ラベルを変更せず、オンを緑色で示す。他の絞り込み条件は維持する。「条件をクリア」は全条件を解除する。
- 未完了は既存仕様の「未作成または編集中」。確認済み戦績に未設定項目があっても未完了へ戻さない。
- 一覧の行を選ぶと下部編集欄が開く。左端のチェック欄、Ctrl/Shiftによる複数選択も利用できる。未選択時には編集欄を畳み、複数選択時は件数と「一括編集」を表示する。
- 下部に自分デッキ・勝敗（引き分けを含む）・先後・コイン・確認状態を表示する。自分デッキは候補から選ぶか自由入力。「詳細項目」から相手デッキ・対戦種別・シーズン・タグ・メモを編集する。
- 「保存」は現在の入力を保存する。確認状態は利用者が選ぶため、保存だけで確認済みへ強制変更しない。
- 「次の未完了へ」は現在の条件に含まれる別の未完了戦績へ移る。日時が後ろの候補を優先し、末尾なら先頭へ戻る。別候補がなければ案内する。保存と移動は別操作。
- 下部の「再生」は録画レビューを開く。「その他」から詳細・レビュー、YouTube、削除を開く。複数選択時に単一行の削除等を実行しない。
- 標準表示は選択・日時・デッキ・勝敗・先後・コイン・種別・状態。時間・サイズ・相手デッキ・登録元は「表示する列」で表示可能。表示列の変更は現在の画面内に適用する。
- 小さい画面や詳細展開時は縦にスクロールできる。表内は独立してスクロールでき、必要な列を増やした場合は表内の横スクロールを使う。

## 未保存と失敗時の扱い

別行、複数選択、条件適用/解除、未完了切替、更新、次へ、別画面、終了時に、変更があれば「保存・破棄・取消」を表示する。取消は入力・選択・適用済み条件を維持する。書込失敗、録画等による書込禁止、revision競合では入力を保持して案内する。

背景更新やレビュー側の保存通知で未保存入力を上書きしない。更新が保留されたことを表示し、保存または破棄後に再読み込みする。保存済み行は識別子により再選択し、表のスクロールを維持する。条件から外れた場合は選択を解除する。

## 実装の責務

`pyside_history_editor.py`はQtの入力、値のスナップショット、既存サービスへの保存を担当する。`pyside_gui.py`はフィルター、一覧、行選択、画面遷移を制御する。録画付き/手動/未作成を既存`DuelRecordValues`と`expected_revision`で扱い、SQLをUIへ追加しない。

## 影響・移行・復元

録画、DB schema、設定形式、API/CLI、認証、録画ファイルは変更しない。データ移行は不要。既存の削除確認・バックアップ・保存時競合検出を維持する。従来の個別編集/レビューは詳細操作から到達可能。全アプリのナビ再設計は含まない。

## 検証

`tests/test_pyside_history_redesign.py`で隔離DBと通常GUIを組み合わせ、複合/保存済み条件、再クリック解除、0件、全値保存、保存失敗/競合、全遷移取消、実マウスによる複数チェック、録画付き未作成、次へ、980/1180/1440pxの配置と操作到達性を確認する。通常Windowsの日本語表示と高DPI相当も確認する。実ユーザーデータは検証に使用しない。
