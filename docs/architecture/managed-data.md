# 管理データの入出力・初期化

V0.19.1では、録画履歴、対戦記録、デッキ、タグ、シーズンを`mdrl-managed-data-v1`形式のJSONとして一括入出力します。JSONには録画ファイル本体を含めません。テーブル名と全列を検証し、現在のDBスキーマと一致しないファイルは取り込み前に拒否します。

インポートは現在の管理データを置き換える操作です。操作前に`user_data/data/exports/`へSQLiteバックアップを作成し、トランザクション内で参照順に取り込みます。外部キー検査または書き込みに失敗した場合はバックアップを復元します。

初期化は履歴、デッキ、タグ、シーズンを個別に指定できます。GUIでは確認ダイアログに加え、「対象名を初期化」という確認文字列の入力を必須とします。各操作の前にSQLiteバックアップを作成します。履歴初期化はDB上の履歴・対戦記録・タイムラインだけを削除し、録画保存先の動画ファイルは削除しません。デッキ、タグ、シーズンを初期化する場合は、対戦記録の該当参照を解除してから管理項目を削除します。

録画中または自動監視中は、インポートと初期化を拒否します。
