# FFmpeg初回セットアップ

## 目的

FFmpegがない状態は初回起動として正常です。GUIは環境診断でFFmpegを利用できない場合にセットアップ画面を1回表示し、利用者の明示許可後だけFFmpegを導入します。CLIは対話ダイアログを出さず、従来どおり診断と手動設定を提供します。

## 配布元と同意

- 配布元はFFmpeg公式ダウンロードページがWindows buildとして案内するGyan FFmpeg Buildsとする
- `ffmpeg-release-essentials.zip`と同名の`.sha256`をHTTPSで取得する
- 画面に配布元、ダウンロードURL、GPLv3、導入先を表示する
- 最終確認で「インストール」が選ばれるまで通信もファイル作成も行わない
- キャンセル後もGUIは利用でき、設定画面から再度セットアップを開ける

## 導入先

既定先は`%LOCALAPPDATA%\MasterDuelRecorderLite\tools\ffmpeg`です。利用者は導入前に別の専用フォルダを選択できます。EXE配置フォルダとPyInstaller一時展開先は使用しません。

既存の空でないフォルダは上書きしません。導入は同じ親フォルダの一時ステージへ`ffmpeg.exe`と`ffprobe.exe`だけを展開し、検証成功後に確定します。失敗時はステージだけを削除し、既存ファイル、設定、録画、履歴を変更しません。

## 検証

1. SHA-256本文が64桁の16進値であることを確認する。
2. ZIPをOSの一時ディレクトリへストリーム保存し、公開SHA-256と照合する。
3. ZIPエントリの絶対パス、親ディレクトリ参照、サイズ上限超過を拒否する。
4. `ffmpeg.exe -version`を実行し、FFmpeg 6.0以上またはlibavutil 58以上を確認する。
5. `ffprobe.exe`の存在と起動を確認する。
6. 検証済みパスだけを`recorder.ffmpeg_path`へ原子的に保存する。

探索時の`-version`は初回ディスク展開やセキュリティ検査を考慮して15秒待ちます。明示設定、PATH、既知配置先の順で探索し、管理対象FFmpegは既知配置先の先頭候補にします。各候補の失敗理由は診断へ残します。

## 更新と制約

V0.16.1は初回導入だけを対象とし、自動更新や無人導入は行いません。配布URLの内容が更新された場合も毎回その時点の公開SHA-256を照合します。ネットワーク、証明書、ハッシュ、ZIP、実行確認のいずれかが失敗した場合は導入失敗として利用者へ表示します。
