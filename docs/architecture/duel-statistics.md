# 戦績統計設計

## 目的

確定済みの対戦記録を再利用し、全体勝率、条件付き勝率、時期ごとの勝利数・勝率推移をGUIから確認できるようにする。統計は録画・対戦記録を変更しない読み取り専用機能とする。

## 集計対象

次の条件をすべて満たす対戦だけを統計へ含める。

- 録画状態が`completed`
- 対戦記録状態が`confirmed`
- 勝敗が`win`、`loss`、`draw`のいずれか

未確定、勝敗未設定、録画失敗、開始中、録画中の履歴は除外する。引分は対戦数へ含め、勝率は`wins / matches`で計算する。0件時の勝率は0%とせず「データなし」として扱う。

## 条件

- 期間: `recordings.started_at`を優先し、ない場合だけ`created_at`を使う。利用者のローカル日付へ変換し、開始日・終了日の両端を含める
- デッキ: 対戦記録の自分デッキをNFKC正規化・大文字小文字非依存で完全一致する
- タグ: `duel_record_tag_links.tag_entry_id`の安定IDで一致する。名称変更とアーカイブは過去集計を変えない
- 先後: `first`または`second`の完全一致とする

4条件は同時に適用できる。最上部の全体勝率は条件の影響を受けず、条件適用後の値を別に表示する。

## 時系列

日、週、月の3単位を提供する。週は月曜日開始、月は1日開始とする。指定期間または対象データの最小・最大日を範囲とし、対戦がない区間も0件として返す。GUIは勝利数を棒、勝率を線として同じ期間軸へ描画する。

## GUI

統計ページは全体・条件付きサマリー、条件フィルター、推移・デッキ別・先後別タブで構成する。日付形式エラーと開始日が終了日より後の条件は集計前に拒否する。0件は空の表と「表示できる確定済み対戦がありません」で表現する。

GUI全体は[Material 3](https://m3.material.io/)の色ロール、タイポグラフィ階層、状態表現、ナビゲーション原則を適用する。Tkの制約内で通常、ホバー、押下、選択、無効状態を揃え、色だけに依存せず文字と選択面でも現在状態を示す。

## データ影響

V0.18.0ではSQLiteスキーマを変更しない。既存録画、対戦記録、タグ、設定を更新・削除せず、`history.sqlite3`を読み取るだけとする。
