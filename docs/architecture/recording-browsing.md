# 録画の閲覧

## 目的と範囲

V0.13.0では録画履歴からローカル動画へ到達する操作を提供します。動画は既に`user_data/data/recordings/`へ保存されているため、ダウンロードではなくWindows既定プレイヤーでの再生とExplorerでの保存場所表示を扱います。内蔵プレイヤー、別名保存、ファイル移動、削除は対象外です。

## 安全な録画参照

すべての閲覧操作は録画IDから履歴を取得し、履歴の相対パスを`recordings/`配下へ解決します。利用者入力の絶対パスを直接開きません。解決後の実パスが録画保存領域内であることを再検証し、次を区別して拒否します。

- 履歴が存在しない
- パスが保存領域外またはシンボリックリンク経由で領域外を指す
- ファイルが欠損している
- ファイルが空である
- 拡張子が`.mkv`または`.mp4`ではない

閲覧前検証はファイルを変更しません。履歴とサイズが異なる場合は警告を表示しますが、実ファイルが安全な場所に存在する場合は利用者が再生を選択できます。

## Windows操作

再生はWindowsのファイル関連付けを利用し、既定プレイヤーへ安全な絶対パスを渡します。保存場所表示は`explorer.exe`へ引数列を渡し、対象ファイルを選択した状態で親フォルダを開きます。シェル用のコマンド文字列は生成しません。

OS関連付けがない、プロセスを開始できない、対象が実行直前に消えた場合は処理失敗として表示します。失敗しても履歴、録画、設定を変更しません。

## GUIとCLI

GUIの録画履歴へ「再生」「保存場所を開く」を追加します。履歴のダブルクリックも再生として扱い、履歴更新後は同じ録画IDの選択を可能な限り維持します。操作可能なのは選択済みで安全な録画だけです。

```powershell
mdrl history play RECORDING_ID
mdrl history reveal RECORDING_ID
```

成功は終了コード0、履歴欠損やファイル不整合など利用者確認が必要な状態は4、Windows起動処理の失敗は3とします。

## 完了条件

- GUIとCLIが同じ録画参照・エラー契約を利用する
- 有効なMKV・MP4を既定プレイヤーで再生できる
- Explorerで対象ファイルを選択して表示できる
- 領域外、欠損、空、未対応ファイルを開かない
- CLI版とGUI版の実EXEで閲覧操作の入口を検証する
