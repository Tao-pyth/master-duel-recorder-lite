# 戦績入力ワークフロー

## 簡易入力

簡易入力は勝敗、先後、自分デッキ、シーズンを主項目とします。録画終了後と初期画面の「戦績を追加」から開き、保存、後回し、詳細入力への遷移を選択できます。保存は`confirmed`、後回しは`draft`として記録します。詳細入力ではコイントス、相手デッキ、対戦種別、タグ、メモを編集できます。

候補値は直近の確認済み戦績、前回入力、開催中シーズン、デッキ・タグの使用回数と最終使用日時から計算します。候補は自動確定せず、根拠を簡易入力画面へ表示します。非表示デッキと相手専用デッキは自分デッキ候補から除外します。

## 未完了処理

完了済み録画に戦績がない状態、`draft`の録画付き戦績、`draft`の手動戦績を未完了として扱います。未完了キューは対戦日時の古い順に並べ、前後移動、後回し、入力を提供します。1件の保存が終わるたびに一覧と未完了件数を再取得します。

## 一括編集

戦績管理一覧は複数選択に対応します。一括編集はシーズン、自分デッキ、対戦種別、タグ追加、タグ削除を対象とし、適用前に件数を確認します。全対象を事前検証し、途中失敗時は保存済み対象を元の値へ戻します。各変更と補償更新は対戦IDごとの監査履歴へ記録します。録画・自動監視中は使用できません。

## 保存済みフィルター

複合フィルターへ名称と安定IDを付け、SQLiteへ保存します。保存、呼出し、上書き、削除ができ、管理データJSONの入出力対象です。過去版JSONに保存済みフィルターが含まれない場合は空として取り込みます。参照先のデッキ、タグ、シーズンが削除・非表示になってもIDを保持し、結果0件として安全に扱います。
