# 音声入力

## 対応範囲

V0.17.0はWindowsのFFmpeg `dshow`入力を1つ選択し、映像と同じMKVへAAC音声を保存します。ゲーム・システム音またはマイクのどちらか一方を対象とし、複数入力の同時ミックス、アプリ単位音声キャプチャ、ノイズ除去は対象外です。

## 選択と事前テスト

GUIはFFmpegが列挙した音声入力をシステム系、マイク系、その他に分類し、設定画面で選択・更新・保存します。表示名とは別にFFmpegへ渡す識別子を保持します。「テスト」は短時間入力を開き、次を区別します。

- `active`: 音声サンプルを取得できた
- `silent`: 入力は開けたが測定区間が無音だった
- `unavailable`: 入力を開けない、タイムアウト、またはFFmpegエラー

無音は設定ミスと断定できないため警告として扱います。選択なしは音声無効で、映像のみ録画できます。

## 録画と同期

FFmpegコマンドには画面入力と選択した音声入力を別入力として渡し、音声はAAC、既定192kbps、48kHz、2chです。音量は`audio_gain_db`で調整できます。壁時計タイムスタンプと`aresample=async=1:first_pts=0`を使い、入力開始差と長時間のドリフトを補正します。

設定値は`audio_input`、`audio_gain_db`、`audio_sample_rate`、`audio_channels`です。履歴には設定した入力、実際に音声付きで完了したか、失敗理由を保存し、録画IDと同じライフサイクルで確定します。

## 安全性

デバイス名は引数配列としてFFmpegへ渡し、シェル文字列として実行しません。列挙結果にない入力、範囲外のゲイン・サンプルレート・チャンネル数は拒否します。音声入力失敗を映像のみ成功へ暗黙に変更せず、利用者が音声を無効化するか別入力を選ぶまで具体的な理由を表示します。
