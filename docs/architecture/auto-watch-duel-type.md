# 自動監視の対戦種別初期値（V2.7.17）

録画画面の「自動監視の戦績初期値」で対戦種別を選択します。その他・ランク戦・イベント・ルーム戦・ソロモードを既存の戦績編集と同じ値で扱います。希望先後の右側に配置します。

監視開始時に他の初期値とまとめて保存し、開始時点の値を監視セッション中は固定します。開始後に初期値を変えても、次回の監視開始まで適用されません。成功した新規自動録画の戦績下書きだけに反映します。既存戦績・手動録画・失敗録画の扱いは維持します。シーズンからの種別推定は行いません。

## 保存・互換・失敗時の復元

設定の `[interaction]` に `auto_watch_default_duel_type = "other"` を追加します。値は `other/ranked/event/room/solo`、欠落時は既存動作と同じ `other` です。旧設定の自動書換やDB移行は不要です。

既存の設定保存経路を使用し、全値を検証してから元の設定を `app.toml.previous` へ退避し、一時ファイルから原子的に置換します。不正値や置換失敗では元の設定を維持し、監視を開始しません。必要な場合はアプリ停止後、previousまたはバックアップから設定を復元できます。旧版は追加キーを無視して読めますが、旧版で再保存するとこの追加値は失われます。

`AppConfig` → `AutoWatchDuelDefaults` → 監視開始時snapshot → 新規draftの既存 `duel_type` の順に渡します。設定CLIの既存更新キーにも登録します。実利用データは検証に使用せず、テストごとの一時領域で保存・失敗時保護を確認します。
