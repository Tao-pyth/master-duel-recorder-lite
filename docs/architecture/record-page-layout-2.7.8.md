# 録画ページの高さ不足への対応

対象: [Issue #630](https://github.com/Tao-pyth/master-duel-recorder-lite/issues/630)、V2.7.8。

録画ページだけスクロール領域で包まれていないため、初期サイズ1180×760では操作と「判定詳細」が重なり、状態帯や診断表が潰れていた。初期値の入力欄を維持したまま、他ページと同じ縦スクロール構造を使って内容に必要な高さを確保する。

固定の巨大なウィンドウ最小サイズには変更しない。状態帯、操作、初期値の必要高さはQtレイアウトへ委ねる。診断表は内容に合った高さを要求し、ページが狭いときはページ全体をスクロールして読む。録画・検出・停止の状態遷移、設定、初期値の開始時スナップショットは変更しない。DBや実行時データの変更・移行はない。

検証ではQtの実widgetを生成し、初期・最小サイズ、状態別の矩形非交差、親領域内包含、状態帯の高さ、診断行の表示、スクロール後の操作到達性を確認する。固定のsmoke契約値だけでは合格にしない。日本語フォントと複数スケールの描画は別途確認する。
