# 映像中心のレビュー画面（V2.7.16）

## 目的と操作

録画レビューを開くと、左に映像と再生操作、右に「戦績入力」が表示されます。右の「マーカー編集」へ切り替えても映像の位置とサイズは変わりません。再生/一時停止、外部で開く、シーク、現在時刻、視覚タイムラインは左の映像直下にあります。

右の入力欄は縦に並びます。高さが足りない場合は右側をスクロールしてください。「戦績を保存」はスクロールの外側、右下に表示されます。デッキ名は候補選択と自由入力の両方を使えます。マーカーの追加・編集、候補の確定・却下、クリップ出力・保存先を開く機能は右のマーカー編集タブにあります。

長い録画名や戦績概要は省略表示し、マウスポインターを置くと全文を確認できます。録画名のツールチップには録画IDとフルパスも表示します。

## レイアウトの判断

- `QHBoxLayout` の左だけを伸縮させ、右のタブを400論理pxに固定する。QtのDPIスケーリングには追従する。
- `QVideoWidget` の最大高さ420pxを除去し、`KeepAspectRatio` を明示。空き領域内で縦横比を維持した最大表示とする。映像比率と領域の差は黒帯になる。
- 両タブは同じ外側寸法に収まり、内部の縦スクロールがフォームの最小高さによるウィンドウ拡大を防ぐ。
- 選択ボタン群は項目ごとの行、種別・シーズン・デッキ・タグは1項目1行。長い候補名でcomboの最小幅が増えない方針を設定する。
- ファイル名と概要は省略ラベルで最小幅に影響させない。マーカーの表は必要に応じて横スクロールし、説明を確認できる。
- 既定タブを戦績入力へ変更する。内部呼出しの明示 `initial_tab="marker"` は互換維持。

## 検証と比較

Windows / PySide6 6.10.3、100%表示で測定。旧版は1120×780を要求しても1120×966へ拡大され、16:9映像は約462×260に制約された。新画面は1120×780で収まり、映像領域696×554内で16:9映像を696×391.5まで表示できる。同じ1120×966でも同幅になり、実効映像面積は約2.27倍。

ウィンドウ幅1120→1440で左映像幅696→1016、右は400のまま。960×640でも操作・保存へ到達できる。100/150/200%相当の寸法回帰、16:9/4:3合成動画、タブ切替、長いデッキ名、全戦績項目の保存・再読込、マーカー操作、外部起動/クリップ導線を検証する。

これは幅と高さが限られた従来画面との比較であり、あらゆる映像比率・画面サイズで同じ倍率になる保証ではない。

## 保存と互換性

戦績・マーカーの保存サービス、SQLite schema、設定形式、録画方式は変更しない。データ移行は不要。既存の保存通知とレビューclose時のメディア解放を維持する。実利用データはテストに用いず、一時領域にDBと合成動画を作る。
