# PySide6 UI情報設計Hotfix V2.4.1

## 目的

V2.4.1では、PySide6通常GUIで利用頻度の低い診断表示と内部処理表示を主要導線から下げ、録画、戦績管理、設定の役割を利用者に分かりやすく整理する。DB schema、設定形式、録画処理、YouTube投稿処理、queue、manifest、OAuth資格情報は変更しない。

## 画面責務

- テンプレート画面はYouTube投稿テンプレートの編集だけを扱う。
- MP4準備、remux、投稿前処理キューはYouTube投稿時の内部処理として扱い、テンプレート画面では機能として露出しない。
- 信頼性確認は主要ナビから外し、設定内の「録画診断・信頼性」タブへ統合する。
- 録画画面には環境診断から「録画診断・信頼性」へ移動する導線を残す。
- 設定の表示系項目は「戦績表示設定」として、戦績管理のセル色とダブルクリック動作に責務を絞る。

## 戦績管理フィルター

PySide6戦績管理では、フィルターバーの選択値を`DuelManagementQuery`へ直接変換する。対象は期間、シーズン、自分デッキ、タグ、コイン、登録元とする。

タグの直接選択は単一タグとし、複数タグ条件は既存の保存済み条件を選択した場合に`SavedDuelFilter.criteria.tag_entry_ids`から復旧する。この方針により、画面の密度を増やさずに1.x相当の保存済み複合条件を維持する。

## 表示ルール

- デッキ名、タグ、戦績表示設定のカラー列は、セル文字ではなくスウォッチで表示する。
- カラー列の主要表示に色コードや「色」という文字を出さない。
- 戦績表示設定の対象名は`coin_face.heads`などの内部キーではなく、「コイン: 表」のような日本語名に変換する。
- 左下ステータスは正常時に「準備OK」と表示し、注意/要確認の根拠はツールチップに持たせる。
- 録画画面のシーズン表示は、未確認、なし、開催中、取得失敗を短い状態名で区別する。
- カタログ系テーブルは選択や再読込で高さが不自然に変わらないよう、最小高さと最大高さを持たせる。

## 検証方針

- `smoke_contract`で主要ナビから信頼性が外れたこと、設定タブへ診断導線があることを確認する。
- `smoke_contract`でテンプレート画面にMP4準備UI、バックグラウンド処理表示、進捗表示が露出しないことを確認する。
- `tests/test_application.py`でシーズン、デッキ、タグ、コイン、登録元フィルターが履歴一覧へ反映されることを確認する。
- PySide6 GUI smokeで録画、戦績管理、デッキ名、タグ、テンプレート、設定画面の表示崩れがないことを確認する。
