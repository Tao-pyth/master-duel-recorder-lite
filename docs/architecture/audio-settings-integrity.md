# V2.7.10 音声設定の整合性

## 利用手順
設定の「録画設定」で音声モードと入力を選び、「設定を保存」を押す。「候補更新」は入力一覧の再検索だけを行い、現在の選択と未保存状態を保つ。入力が一時的に見つからなくても選択文字列を残し、未検出と案内する。接続を確認して再検索するか、利用可能な入力を明示的に選ぶ。

## 原因と修正
従来は候補のclear後に先頭を選択していた。現在の文字列を退避し、列挙後の一覧へ復元する。消失した選択は一覧末尾へ保持する。更新中のsignalを抑制し、元の設定スナップショットと比較して保存状態を表示する。検索失敗時は一覧と選択を維持する。

一括保存は音声モードと入力の各項目を逐次検証していたため、最終値が有効でも途中の不完全な組合せで失敗した。全項目を既存parserで変換し、最終AppConfigを検証した後、既存のatomic保存へ渡す。単項目updated_configも同じ関数を利用し、全体検証を維持する。

## データ保護と互換性
設定形式、DB、録画方式は変更しない。不正な入力・未知キー・無効な最終状態では保存を呼ばず、現ファイルと.previousを保持する。書込時の失敗処理は既存save_app_configに従う。保存前に現設定を.previousへ退避するため、最終ファイル置換に失敗した場合は現設定とその有効なバックアップが残る。新しいトランザクション方式は導入しない。

検証は専用の一時設定とQt widgetで行い、利用者の設定・録画・資格情報を変更しない。
