# PySide6シーズンレポートの閲覧・出力

シーズン一覧で選択して「レポート」を押すと、既存SeasonReportを閲覧専用dialogで表示する。概要（期間/母集団/既定比較/保存済みメモ）、デッキ先後、コイン先後、日別/週別推移を表示する。0件は勝率未算出、10戦未満は既存の少数標本フラグに従う。メモ文字列はplain textで扱う。

HTML保存は同じシーズンIDで再集計し、表示もその結果へ更新する。QFileDialogで出力先を明示し、存在するファイルは別途上書きを確認する。保存取消や失敗では成功表示せず、既存のSeasonReportHtmlExporterの保存規則を利用する。

DB/設定形式と集計式を変更しない。比較対象選択、メモ編集、他画面からの入口は今回の範囲外。表示処理を専用モジュールへ分離し、通常GUIの既存ボタンから呼び出す。参照仕様はseason-reports.md。
