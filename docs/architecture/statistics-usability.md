# 統計表示と相性の局所絞り込み（V2.7.21）

統計サービスの母集団と計算を維持したまま、Qtの表・Chart・レイアウトだけを改善する。対象Issueは #661 / #662 / #663、公開は #664。

## 母集団と条件

上部は条件適用後を主表示し、全体勝率は従来の全期間・全種別を比較基準として残す。期間・対戦種別の共通条件は全タブへ適用する。

自分デッキ・相手名検索・相手未設定表示・最低対戦数は、相性一覧だけの局所条件。元のDashboardを再集計せず、読み取り結果の表示を絞る。入力変更でカードや他タブは変わらない。表示件数と共通条件の母集団を分け、折り畳む未設定の件数も残す。未設定数は自分デッキ・検索条件を適用した後、最低対戦数を適用する前の件数である。

自分デッキ選択肢は正規化名と未設定フラグの組。共通条件変更で候補が0件になっても選択を保持し、解除で全件に戻す。検索はNFKC・trim・casefold後の部分一致。

## 未設定と実名の区別

既存の集計は空名と実名「未設定」を別グループとしている。表示名だけでは区別できないため、StatisticsMatchupにopponent_deck_unassignedとown_deck_unassignedを末尾の既定値Falseで追加した。既存3引数constructorは互換。サービスが正規化キーからフラグを設定する。GUIで実名側は「未設定（デッキ名）」と表示し、未設定折り畳みは空名だけを対象にする。

## 数値と描画

統計表だけに右揃え・数値ソート・補助勝率バーを適用。初期は従来の開催日順/集計順を保ち、見出し選択後に並び替える。更新中はソートを停止し、全セルを設定後に選択順を復元する。これで名前と勝敗が別行へ移動するのを防ぐ。0戦の勝率「-」と0%を区別する。

対戦数は勝率のそばに残し、0<対戦数<10には「参考」列で「少数」と表示する。閾値は既存シーズンレポートと合わせた目安であり、統計的信頼性の保証ではない。

Chartの日付用矩形は文字幅から決め、両端を優先して枠内へ配置し、中間を重ならない間隔へ減らす。描画のみの変更で、期間別勝利数と累積勝率の意味・値は変わらない。

## 保存と保護

局所条件はセッション内のUI状態だけに保持。DB/設定schema・録画・queue・OAuth資格情報の変更や移行はない。実運用データを使った書込みテストはせず、一時フォルダーに合成戦績を作成する。長い名前はツールチップと表の横スクロールで確認する。

タブ統合、先後の1行化、マトリクス、ドリルダウン、期間プリセット・シーズン条件の追加は別の範囲。
