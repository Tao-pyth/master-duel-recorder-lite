# PySide6視覚タイムラインMVP V2.7.0

## 目的

V2.7.0では、アプリ内レビュー画面に視覚タイムラインMVPを追加し、録画内の現在位置、選択位置、重要イベントを動画の流れに沿って把握できるようにする。V2.4.0で完了した動画再生、表形式タイムライン、マーカー、クリップ出力は再実装せず、既存の安全なサービス境界の上に表示と選択同期だけを追加する。

## データ境界

- `ReviewViewModel.visual_timeline` は既存タイムラインから作る派生表示データである。
- GUIは`elapsed_ms`、録画長に対する`ratio`、表示種別、tooltipを受け取り、描画と選択だけを行う。
- SQLite、録画ファイル、FFmpeg、設定ファイルはGUIから直接操作しない。
- 視覚タイムライン上のイベント選択は、既存の動画シークと表形式タイムライン選択へ接続する。

## 表示種別

- `duel_start`: 対戦開始位置。
- `manual_marker`: 利用者が追加したマーカー。
- `clip_candidate`: 自動判定候補など、確認対象になり得る位置。
- `timeline_event`: その他の通常タイムラインイベント。

## 例外状態

- 録画長が不明または0の場合、比率は0として扱い、保存データを変更しない。
- イベント時刻が録画範囲外の場合、端にclampし、範囲外であることを表示データに残す。
- イベントが空でもレビュー画面は開ける。
- Qt Multimediaが利用できない場合や再生エラー時は既存の外部プレイヤーfallbackへ戻す。

## 対象外

- クリップ範囲エディタ。
- 開始/終了ハンドル。
- 波形またはサムネイル生成。
- 実録画codec差異の網羅検証。
- DB schema変更、設定形式変更、OAuth、queue、manifest変更。

## 検証

- `build_visual_timeline_items` の単体テストで、比率計算、種別分類、範囲外event、録画長不明を確認する。
- PySide6 smoke contractで、`review_visual_timeline`、表示種別、選択同期契約、fallback安全性を確認する。
- 既存のレビューViewModel、クリップ出力、GUI smokeテストと合わせて回帰を確認する。
