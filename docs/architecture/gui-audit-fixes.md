# V2.7.9 GUI監査修正

現行画面の監査F1〜F8を修正する。統計カードは既存の全体/条件適用後集計から描画し、期間指定（任意・両端含む）、勝敗、日/週/月を同じ集計へ渡す。勝敗条件は母集団を絞るため「勝利のみ」の条件適用後勝率は100%になる。全体勝率は条件に依存しない。

録画操作は最小幅980pxでも状態と同時に表示する。長いパス・対象名は表示幅を広げず折返しまたは選択欄内に収める。戦績表の行高を維持し、余った高さを表へ配分する。未完了表示は既存の未完了抽出を利用し、状態列を文字で表示する。

録画設定は明示保存を維持する。保存操作をタブ共通にし、未保存状態を示す。別ページへ移っても編集中の値を保持し、再読込で保存済みの値へ戻す。終了時は保存・破棄・取消を選べる。保存失敗時は変更を保持して終了しない。

DB、設定ファイル形式、録画方式、キュー、認証情報は変更しない。統計の結果条件は任意のメモリ内フィルターとして追加する。確認は隔離した検証データと実Qtウィンドウで行い、ゲーム素材やキャプチャをコミットしない。
