# PySide6 Operational Quality 2.5.0

## Purpose

V2.5.0では、PySide6通常GUIの主要画面について、利用者が押せる、選べる、編集できる操作を棚卸しし、次のいずれかへ分類する。

- 実処理へ接続する
- 状態に応じて無効化する
- 具体的な案内を表示する
- 不要な操作として非表示または削除する

この版ではDB schema、設定形式、録画ファイル、YouTube投稿履歴、OAuth資格情報、prepare queue、manifestは変更しない。

## Regression Contract

`smoke_contract()` は `operational_quality_audit_contract` を返し、監査対象画面、主要操作widget、未接続操作なし、危険操作ガード、レビュー表示の日本語化を確認する。

PySide6の画面起動smokeだけではクリック先の品質を検出しにくいため、V2.5.0ではユニットテストで以下を固定する。

- 主要操作widgetが `SMOKE_WIDGETS` に含まれること
- 監査対象操作の欠落が `missing_action_widgets` に出ないこと
- レビュータイムラインの主要列が日本語表示になること
- クリップ出力などの外部プロセス失敗がFFmpeg生ログだけで表示されないこと
