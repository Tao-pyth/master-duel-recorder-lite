# デッキ名・タグ・シーズンの管理

V2.7.13では3ページを「左で検索して選択、右で編集」に統一します。

1. 名前・説明を検索し、用途または状態で絞り込みます。検索と条件は各ページ内で保持します。
2. 一覧の行を選ぶと右側へ入力欄が開きます。新規ボタンは空の入力欄を開き、「追加して保存」で登録します。
3. 既存行は「変更を保存」で更新します。「取消」は編集中の変更を破棄します。
4. 未保存の行移動、条件変更、新規追加、ページ移動、終了は保存・破棄・取消を確認します。保存失敗時は入力を残します。

デッキの使用回数は参照専用です。「相手デッキのみで使用」と「履歴・統計で非表示」は独立した設定です。タグにはデッキ名登録専用の設定があります。色は色選択ボタンから変更します。

シーズンは名前、説明、種別、開始日、終了日を編集します。レポートとHTML保存は従来のレポート画面へ接続します。アーカイブは確認後に行い、戦績を保持します。アーカイブ済みシーズンを保存すると再び有効になる既存仕様は右側で案内します。レポートメモは通常編集で保持します。

## 実装と安全性

`pyside_catalog_editor.py`にQt専用共通画面を置き、`pyside_gui.py`から3種類の設定で作成します。CRUDは既存サービスを使用し、DB/schema/設定形式は変更しません。識別子と入力snapshotで編集中の対象を固定し、背景更新は未保存フォームの再充填を避けます。

デッキの新規作成と用途設定の保存は既存サービスの2段階です。後段が失敗した場合は作成したIDを保持し、保存の再試行で重複作成しません。エラーを成功とは表示しません。

左右幅は仕切りをドラッグして調整でき、右側は縦スクロールできます。狭い画面で表の全列が入らない場合は横スクロールで到達します。検索、表示条件、左右幅はセッション内のUI状態であり、設定形式へ追加しません。

実ユーザーデータを検証に使用せず、隔離DBでCRUD、失敗、取消、アーカイブ、レポート接続と拡大表示を確認します。
