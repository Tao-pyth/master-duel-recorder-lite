# 入力削減・デッキ改善・運用管理

## 目的

V1.3.0では、戦績を記録した後に継続利用しやすくするため、入力候補、タグテンプレート、目標、デッキ改善集計、ストレージ候補、移行パック、軽量レビュー入口を追加します。録画ファイルは自動削除・移動・上書きせず、利用者が判断できる候補提示に留めます。

## DB

履歴DBはV16へ更新し、`tag_templates`と`practice_goals`を追加します。既存の履歴、戦績、タイムライン、YouTube投稿状態は変更しません。既存の初期化処理により、移行前バックアップ、単一トランザクション、失敗時ロールバックを維持します。

## 入力候補とタグテンプレート

`suggest_duel_inputs`は最近の戦績から自分デッキ、相手デッキ、タグを頻度順に返します。候補は暗黙確定せず、利用者が選択して保存する契約です。タグテンプレートはDBへ保存し、戦績入力やミニ入力から再利用する前提です。

## デッキ改善と目標

`deck_improvement_rows`は自分デッキと相手デッキを軸に、勝敗、先後、コインを集計します。少数標本でも分母を表示し、外部データやカード単位の提案は行いません。`practice_goals`は期間や条件を拡張できる形で、まずタイトル、指標、目標値、対象デッキ、対象対面、シーズン、状態を保持します。

## ストレージ候補

`storage_candidates`は失敗録画と戦績未入力録画を候補として提示します。重要タグや出力済み判定の拡張余地を残しつつ、V1.3.0では削除・移動・圧縮を自動実行しません。

## 移行パック

`export_migration_pack`は`config/app.toml`と履歴DBをZIPへ格納し、manifestへSHA-256、サイズ、録画ファイル非同梱、OAuth資格情報非同梱を記録します。OAuth token、client secret、OS資格情報はエクスポートしません。
