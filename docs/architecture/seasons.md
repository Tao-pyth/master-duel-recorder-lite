# シーズン管理

## データモデル

`seasons`は一意な名前、種別、対象対戦種別、開始日、終了日、説明、従来レポートメモ、目標、良かった点、課題、次期方針、レポートrevision、アーカイブ状態、作成・更新日時を持ちます。期間は両端を含み、ランクとイベントなど異なるシーズンの期間重複を許可します。対戦記録はNULL許容の`season_id`を1つだけ保持し、自動割り当てしません。

## 編集規則

新規・既存の対戦記録からシーズンを選びます。録画日が期間外なら警告し、利用者が確認した場合だけ保存します。参照されていないシーズンだけを削除できます。参照中シーズンはレポート画面で振り返りを確認・保存した後、明示操作でアーカイブします。アーカイブ後も既存記録、編集時の現在値、統計は維持します。

V0.25.0の比較、分析、振り返り、HTML出力は[シーズンレポート設計](season-reports.md)を参照してください。

## レポート

シーズン画面は確定済み対戦を都度集計し、勝率、対戦数、勝ち、負け、引分、先攻・後攻、デッキ別、日・週・月の推移区間を表示します。統計値は保存せず、利用者が作成するプレーンテキストのレポートメモだけを永続化します。統計ページではシーズン単位とシーズン未設定を絞り込めます。
