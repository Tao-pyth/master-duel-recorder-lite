# 戦績CSV入出力

## 目的

V0.26.0はスプレッドシートで管理していた戦績を、録画あり・手動・取込を統合した戦績管理へ移行します。CSVは戦績の移行・編集用であり、設定や録画ファイルを含む完全バックアップではありません。完全保全には設定画面のバックアップ機能を使用します。

## 固定列

列名と順序は`ID,開始日時,自分デッキ名,相手デッキ名,勝敗,先後,コイン,対戦種別,シーズン,タグ,メモ`です。UTF-8 BOM、CRLF、標準CSV引用規則を使用します。タグはセル内でカンマ区切りです。タグ名自体にカンマを含めることはできません。開始日時はISO 8601形式、日本語の選択値はGUI表示と同じ値を受け付けます。

## 取込規則

- 既存IDはCSV対象項目を更新し、録画との関連と元の登録元を維持する
- 空IDまたは未知IDは入力IDを採用せず、新しいUUIDを発行して登録元`import`、表示「取込」で作成する
- 未登録の自分・相手デッキ、タグは既定属性で追加する
- 未登録シーズンはCSV内の同名行から開始日・終了日を算出し、カスタムシーズンとして追加する
- 不正ヘッダー、ID重複、不正日時・選択値、上限超過が1件でもあれば適用しない
- 適用直前に検証済みDBバックアップを作成し、マスタ追加と戦績更新を単一トランザクションで実行する

取込前プレビューは、新規、更新、未知ID再附番、追加マスタ、警告、エラーを表示します。確認をキャンセルした場合は変更しません。CSV先頭が`=`,`+`,`-`,`@`となる文字列は、表計算ソフトの式実行を避けるため出力時にアポストロフィを付与し、再取込時に復元します。

## GUI

設定画面の「CSV入出力」タブから、全戦績CSV出力、CSV取込、実データを含まないサンプルCSV出力を実行します。取込戦績は戦績管理の登録元フィルターで「取込」として確認でき、手動戦績と同様に編集・削除できます。
