# 一覧同期とレビューの終了処理（V2.7.15）

録画完了の通知をアプリケーションサービス内の単調増加する変更番号として保持し、既存GUI timerで比較する。手動停止・自然終了・自動録画停止で更新し、timer間に完了した録画を取りこぼさない。GUI側は編集がなければ履歴を再取得し、未保存内容がある間は番号を未消化のまま保持する。DBと設定形式は変更しない。

カタログ保存成功後は関連選択候補を更新する。候補差替え中はシグナルを抑止し、選択値と自由入力、検索・用途条件を保持する。既存の管理一覧loadを使用する。

レビューはプレーヤーと音声出力を子として所有する。close時はプレーヤー停止、source解除、出力切断、親の保持参照除去を行い、windowを破棄する。メイン終了が受理された場合だけ全レビューを閉じる。実行中の外部プレーヤーは操作しない。

録画削除の退避・DB更新・失敗時復元の順序は維持する。同じ動画を別レビューが開いていれば、そのレビューも閉じる必要がある。Windowsの隔離合成動画でファイルロックと削除成功を検証する。
